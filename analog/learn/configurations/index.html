MODULE 06

三种组态

Three Configurations

同一个三极管，换一个“接地端”，就得到电压放大、电流缓冲、高频放大三种性格。

进阶约 35 分钟1 个实验
LEARNING GOALS · 学习目标
  • 用“输入接哪个极、输出从哪个极取”判断共射/共集/共基。
  • 记住三种组态的电压增益、输入电阻、输出电阻、相位与典型用途。
  • 会算射极跟随器的增益、输入电阻与输出电阻，解释它为什么适合做缓冲。
  • 能根据系统需求选择组态，而不是只看“增益越大越好”。

先修：放大电路基础

生活比喻同一个人，三种岗位

共射像“电压放大器”：把小幅电压放大成大幅电压，但输出电阻高、带负载能力一般；共集像“前台接待”：电压几乎不变，却能把高阻信号源接到低阻负载；共基像“高频接线员”：输入电阻很低，但速度很快，适合高频与电流缓冲。

为什么重要 / 用在哪里

  • 同一只三极管，不同接法直接决定增益、阻抗、相位与频率特性。
  • 多级放大通常用“共射提供增益 + 共集做缓冲 + 共基/差分处理高频”的组合。
  • 运放内部的输入级、增益级、输出级，本质上也是不同组态的组合。

三种组态：看输入和输出接在哪

组态由“交流信号从哪个极输入、从哪个极输出”决定，另一个极交流接地。共射：基极输入、集电极输出；共集：基极输入、发射极输出；共基：发射极输入、集电极输出。注意“共”指的是交流接地的那一端。

关键结论记忆抓手：谁接地，谁就是“共”

共射是发射极交流接地，共集是集电极交流接地，共基是基极交流接地。画交流通路时，先把直流电源与旁路电容视为短路，再找“哪个极没有交流信号”。

共射：增益担当，但输出电阻偏高

共射的输入在基极、输出在集电极，发射极交流接地。它是三种组态里电压增益最高的，输出与输入反相；输入电阻中等（约 r_be 与偏置电阻并联），输出电阻约等于 Rc，带低阻负载时增益会明显下降。

  • 优点：电压增益高、电路简单、应用最广。
  • 缺点：输出电阻高、反相、频率特性受密勒效应影响。
  • 典型组合：共射增益级 + 共集缓冲级，兼顾增益与驱动能力。

共集：电压不放大，专门做“缓冲”

共集把输出从发射极取出，集电极交流接地。发射极电压跟随基极电压，所以又叫射极跟随器。电压增益略小于 1 且同相，但输入电阻高、输出电阻低，能把高阻信号源“接力”给低阻负载。

射极跟随器：输出从发射极经耦合电容取出，RL 是外部负载。

当前步骤解说

输入瞬时值 0 V，发射极电压被“抬着”跟随：输出瞬时值 0 V（相对静态点）。 输出与输入几乎同相，幅度略小——这就是射极跟随器。

它不放大电压，却能提供电流增益、把高阻信号源与低阻负载隔开：输入电阻高、输出电阻低，是典型的缓冲级。

观察问题：为什么射极跟随器的电压增益总小于 1？把负载 RL 从 5 kΩ 降到 200 Ω，增益和输出电阻怎么变？输入 3 V 峰值时，输出为什么会被削平？

结论提示（先自己想一想再展开）

发射极电压跟随基极，但 r_be 与 (1+β)(Re||RL) 分压，所以增益略小于 1；RL 越小，交流负载越小，增益下降、输出摆幅受限；输入过大时，发射极电压会撞到 0 V（截止）或 VCC（饱和），输出被削平。

小技巧缓冲级不是“多余的一级”

前级输出电阻高、后级输入电阻低时，直接连接会严重分压。加一级射极跟随器，输入电阻高、输出电阻低，信号几乎无损失地传给后级，这就是缓冲的价值。

共基：输入电阻低，但高频特性好

共基把输入加在发射极、基极交流接地、输出从集电极取。输入电阻很低（约 r_e），电压增益高且同相，电流增益略小于 1。因为基极接地，密勒效应弱，高频特性通常优于共射，常用于高频放大、电流缓冲与 Cascode 结构。

共基的电压增益可以很高，但输入电阻低，前级必须能提供较大电流；它不放大电流，适合做“电流接力”和高频电压放大。

适用边界共基不是“把三极管倒过来接”

共基仍然是发射结正偏、集电结反偏，只是交流输入的位置不同。不要把它与“发射极与集电极对调”的倒置工作混淆；后者 β 很小，通常不用于放大。

怎么选：从系统需求倒推组态

  1. 01
    先看负载

    负载很低 → 需要低输出电阻，优先共集缓冲；负载较高、追求电压增益 → 共射。

  2. 02
    再看信号源

    信号源内阻高 → 需要高输入电阻，优先共集或带发射极负反馈的共射；源内阻低、要高频 → 共基。

  3. 03
    最后看频率与相位

    高频、怕密勒效应 → 共基/Cascode；需要反相 → 共射；需要同相且增益≈1 → 共集。

  4. 04
    核算余量

    用实际负载算增益，检查输出摆幅、失真、功耗与带宽，再决定是否需要多级。

快速选择表

常见错误与排查

现象常见原因怎么排查
把“共集”说成“集电极输入”把“共”理解为输入/输出共用，而不是交流接地共集是基极输入、发射极输出、集电极交流接地；先画交流通路再判断。
用射极跟随器去放大电压只看到“跟随”二字，忽略增益小于 1共集用于缓冲/电流驱动，不提供电压增益；需要电压增益时用共射或运放。
共基电路接上前级后信号大幅衰减忽略共基输入电阻只有约 r_e前级要有足够电流驱动能力，或加共集缓冲后再接共基。
认为输出电阻越小越好忽略功耗、稳定性与增益的取舍输出电阻要与负载和系统需求匹配；过低可能带来稳定性与功耗问题。

记住这三句话

  1. 三种组态的区别在“输入接哪、输出从哪取、哪个极交流接地”，不在器件本身。
  2. 共射高增益反相、共集缓冲同相、共基高频低输入电阻；没有全能选手。
  3. 工程上常用组合：共射提供增益，共集提供驱动，共基/Cascode 改善高频。
