MODULE 03

双极型晶体管 BJT

Bipolar Junction Transistor

用小电流控制大电流，是电流控制型器件的代表。

进阶约 40 分钟3 个实验
LEARNING GOALS · 学习目标
  • 说清 NPN 三极管“发射—基区—集电”的结构与放大过程。
  • 能用 I_C = βI_B、I_E = I_B + I_C 计算工作点，并判断截止 / 放大 / 饱和区。
  • 会画直流负载线，理解 Q 点、β 离散与温度漂移为什么让固定偏置不可靠。
  • 能区分直流偏置与小信号模型，知道 r_be 只在 Q 点附近有效。

先修：PN 结与二极管

生活比喻用小水流控制大水流的阀门

基极电流像一股很小的“先导水流”，它本身不直接推动负载，却控制着阀门开度；集电极电流是真正流过负载的大水流。阀门不是线性的：开得太小会关断（截止），开得太大就到底了（饱和），只有中间一段，先导水流与主水流近似成比例。

为什么重要 / 用在哪里

  • BJT 是最经典的放大与开关器件，理解它才能读懂大量分立电路与运放内部结构。
  • β 离散、温度漂移、饱和压降这些“非理想”决定了偏置电路怎么设计。
  • 共射、共集、共基三种组态是后续多级放大、差分对与电流源的基础。

结构：两个 PN 结，一个很薄的基区

NPN 三极管由两个背靠背的 PN 结构成：发射区（N+，重掺杂）、基区（P，很薄且轻掺杂）、集电区（N）。放大时发射结正偏、集电结反偏：发射区大量电子注入基区，少部分在薄基区复合形成基极电流，大部分扩散到集电结边缘，被反向电场扫入集电区。

发射区负责“发射”载流子，薄基区让大部分载流子来不及复合，集电区负责“收集”。

β 不是常数：同一型号不同个体可能相差数倍，且随电流、温度变化。设计偏置时不能把 β 当成精确已知量。

关键结论“放大”是控制，不是凭空造能量

集电极电流的能量来自 VCC，基极电流只负责控制。输出功率可以大于输入功率，但总功率仍由电源提供；三极管本身不是能源。

饱和时 V_CE 只有约 0.1–0.3 V（小功率管），集电极电流由 Rc、Re 和电源决定。继续增大 I_B 只会让基极存储电荷更多、退出饱和更慢，并不会让 I_C 再增大。

负载线与纵轴交点约 5.5 mA，与横轴交点 12 V。Q 点越靠近两端，可用的不失真摆幅越小。

当前步骤解说

Q 点由直流偏置决定：I_B = (VCC − 0.7)/Rb，I_C ≈ βI_B，再由 Rc 把电流变化变成 V_CE 变化。 负载线斜率为 −1/Rc，Rc 越大线越陡；VCC 越大，横轴截距越远。

最大不失真摆幅受两端限制：向上不能超过 VCC（截止），向下不能低于 V_CE(sat)（饱和）。Q 点应尽量放在负载线中段。

观察问题：增大 Rb，Q 点沿负载线往哪边跑？增大 Rc，负载线怎么转、最大集电极电流怎么变？把 Q 点推到饱和区后，输出还能正常放大吗？

结论提示（先自己想一想再展开）

Rb 增大 → I_B 减小 → I_C 减小 → Q 点向 V_CE 增大的方向移动；Rc 增大 → 负载线更陡，纵轴截距 VCC/Rc 减小，饱和电流变小；Q 点进入饱和区后，输出正半周先被削平，增益明显下降。

β·I_B = 2.4 mA；Rc 限制的最大电流约 3.9 mA。当前 I_C 取二者较小值。

当前步骤解说

I_C ≈ β·I_B = 100 × 24 µA = 2.4 mA，V_CE = 4.79 V。基极的小电流在“指挥”集电极的大电流，这就是电流放大。

放大区：I_C = βI_B；饱和区：I_C ≈ (V_CC − V_CE(sat))/R_C，此时 β 不再决定电流。判断“能不能放大”先看 Q 点是否落在放大区。

观察问题：把 β 从 100 调到 300，I_C 是否一定变成 3 倍？把 Rc 增大到 5 kΩ，Q 点会先进入哪个区？

结论提示（先自己想一想再展开）

只有在放大区，I_C 才近似与 β 成正比；一旦 βI_B 超过 Rc 允许的饱和电流，I_C 被 Rc 和电源电压限制，继续增大 β 只会让 V_CE 更低。Rc 越大，饱和电流越小，Q 点越容易进入饱和。

特性曲线：输入像二极管，输出是一族曲线

输入特性是 I_B 与 V_BE 的关系，形状与二极管正向特性相似：V_BE 超过约 0.5 V 后电流指数上升，常用 0.7 V 估算。输出特性是不同 I_B 下 I_C 与 V_CE 的关系：放大区近似水平，饱和区迅速下弯，截止区贴近横轴。实际曲线还会因 Early 效应略微上翘。

r_be 不是万用表测出来的电阻，而是 Q 点处的动态电阻；I_C 越大，r_be 越小。小信号模型只在信号幅度远小于 V_T 量级时成立。

小技巧先直流，后交流

先算 I_B、I_C、V_CE 确定 Q 点，再把三极管换成 r_be 与受控电流源 βi_b，最后算增益和输入/输出电阻。不要拿直流 β 直接当交流增益。

偏置：让 Q 点对 β 和温度不敏感

固定偏置只用一只 Rb 从 VCC 取基极电流，结构简单，但 I_C=βI_B 对 β 和温度非常敏感。工程上更常用分压偏置 + 发射极电阻：Rb1、Rb2 固定基极电位，Re 把 I_E 的变化转成 V_E 变化，自动调节 V_BE，形成直流负反馈。

分压偏置共射电路：Rb1/Rb2 定基极电位，Re 稳定工作点，C1/C2 负责输入输出耦合。

当前步骤解说

温度升高 → V_BE 下降（约 −2 mV/°C）、β 上升 → 同样的 Rb 下 I_B 增大、I_C 进一步增大。固定偏置没有直流负反馈，Q 点会明显向饱和区移动，严重时热失控。

固定偏置：I_B = (VCC − V_BE)/Rb；发射极偏置：I_B = (VCC − V_BE)/(Rb + (1+β)Re)。分母里的 (1+β)Re 就是稳定来源。

观察问题：同样从 −40°C 升到 125°C，两种偏置方式的 Q 点轨迹长度差多少？为什么发射极电阻能稳定 Q 点，却会牺牲一部分电压增益？

结论提示（先自己想一想再展开）

固定偏置的 I_C 近似与 β 成正比，温度升高时轨迹很长；发射极电阻引入直流负反馈，使 I_C 对 β 和 V_BE 不敏感，轨迹明显缩短。代价是 Re 也引入交流负反馈，降低电压增益（可用旁路电容解决）。

常见坑热失控是正反馈

I_C↑ → 功耗↑ → 结温↑ → β↑、V_BE↓ → I_C 再↑。固定偏置与散热不良叠加时，Q 点会一路滑向饱和。Re、电流源、散热与温度补偿都是打破这个正反馈的手段。

hFE 随电流、温度、批次变化很大；设计偏置时不要把它当精确常数。

同一批 2N3904 的 h_FE 可能相差两三倍；数据手册通常给出最小值、典型值与最大值，并注明测试电流。开关应用还要看饱和压降、存储时间与结电容；高频应用要看特征频率 f_T 与 Cob。

适用边界不要把“β=100”写死进设计

如果电路性能强依赖某个具体 β，量产时一定出问题。正确做法是：用负反馈降低对 β 的敏感度，按 β 的最小/最大值分别核算 Q 点与增益，并留足余量。
