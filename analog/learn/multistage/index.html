MODULE 07

多级与差分放大

Multistage & Differential

一级不够就级联；怕漂移就用差分对，让“共同的东西”互相抵消。

综合约 40 分钟1 个实验
LEARNING GOALS · 学习目标
  • 理解级联后增益相乘、但后级输入电阻会加载前级。
  • 会拆分差分信号的差模分量与共模分量，解释差分对为什么抑制共模。
  • 会计算差分增益、共模增益与 CMRR，并说明提高 CMRR 的工程手段。
  • 理解有源负载与 Cascode 如何提高增益、改善高频。

先修：放大电路基础

生活比喻两个温度计一起测，差值才有意义

如果两个温度计同时受到环境温度上升的影响，它们的读数会一起漂；但把两个读数相减，环境温度的“共同部分”就抵消了，只剩两个测点之间的真实温差。差分放大器做的就是这件事：放大差值，抑制共同漂移。

为什么重要 / 用在哪里

  • 运放的输入级几乎都是差分对；理解它才能理解失调、共模范围与 CMRR。
  • 传感器信号常叠加在很大的共模干扰上，差分放大是抗干扰的第一道防线。
  • 有源负载、Cascode 与多级级联是高增益、宽频带模拟设计的常用组合。

级联：增益相乘，但每一级都会被“加载”

多级放大把多个单级电路串起来：前一级的输出接后一级的输入。总电压增益是各级增益的乘积，但每一级的增益必须在“带实际负载”的条件下计算——后级的输入电阻会与前级的输出电阻分压，空载增益只是上限。

关键结论级联不是简单把增益乘起来

前级输出电阻与后级输入电阻构成分压；后级输入电容还会与前级输出电阻形成极点。工程上先做阻抗规划，再分配增益与带宽。

差分对：把“差值”和“共同部分”分开

差分对由两只匹配的晶体管组成，发射极连在一起，由尾电流源 I0 供电。两个输入分别加在基极，输出从两个集电极取出。差模输入让两侧电流一增一减；共模输入让两侧电流同向变化。理想对称时，共模变化在差分输出中互相抵消。

尾电流源越接近理想恒流源（输出电阻越大），共模抑制越好。

小信号近似下，差模分量让两侧电流反向变化；共模分量在理想恒流尾源下不改变总电流，因此每侧电流同向变化很小。

差模输入

  • v1 与 v2 一正一负
  • 两侧电流一增一减
  • 差分输出最大
  • 所需信号

共模输入

  • v1 与 v2 同向变化
  • 两侧电流同向变化
  • 理想对称时差分输出为零
  • 干扰/漂移

共模抑制比：差分放大器的“抗干扰成绩”

差分对的差模增益高、共模增益低。共模增益主要来自尾电流源有限的输出电阻：尾电阻越小，共模电流越容易流过，共模增益越大。CMRR 定义为差模增益与共模增益之比，常用 dB 表示。

当前步骤解说

两输入各含“差模 + 共模”：v1 = v_d/2 + v_c，v2 = −v_d/2 + v_c。差模让一侧电流增大、另一侧减小，输出反相； 共模让两侧一起变化，理想对称时差模输出为零，只留下很小的共模增益。

共模抑制比 CMRR = |A_vd/A_vc|。提高尾电流源输出电阻 R_EE、改善两侧匹配，都能提高 CMRR；这是运放输入级设计的关键。

观察问题：把共模输入从 0 V 加到 5 V，两侧集电极电压如何变化？把尾电流源等效电阻从 10 kΩ 提到 1 MΩ，CMRR 提高多少？

结论提示（先自己想一想再展开）

共模输入使两侧集电极电压同向移动，理想对称时差模输出不变；尾电流源电阻越大，共模增益越小、CMRR 越高。实际电路还要靠器件匹配、版图对称与共模反馈进一步提高。

小技巧提高 CMRR 的三条路

提高尾电流源输出电阻（电流源/Cascode）、改善两管与电阻匹配、采用共模反馈或仪表放大器结构。只靠“挑两只 β 一样的管子”远远不够。

有源负载与 Cascode：用电流源换增益

共射/差分对的增益与负载电阻成正比，但电阻太大会占用电压余量、增加噪声与面积。用电流源做有源负载，其交流等效电阻很高，可以在较低电源电压下获得高增益。Cascode 再把共射与共基级联，既提高输出电阻，又抑制密勒效应。

有源负载的增益可以很高，但输出摆幅受电流源合规电压限制；Cascode 提高输出电阻的同时也占用更多电压余量。

适用边界高增益不等于高性能

增益太高会让闭环稳定性、噪声与输出摆幅更紧张。实际设计要在增益、带宽、摆幅、噪声、功耗与面积之间折中，并用负反馈把“多余的增益”换回带宽与线性度。

常见错误与排查

现象常见原因怎么排查
把各级空载增益直接相乘忽略后级输入电阻对前级的加载在带实际负载的条件下计算每级增益，或把后级输入电阻并入前级负载。
差分对两侧输出“应该”完全对称，但实测有偏差只考虑理想匹配，忽略电阻容差、V_BE 失配与版图不对称按最坏失配估算失调与 CMRR；高精度场合用 trimming、匹配版图或仪表放大器。
增加尾电流源电阻后 CMRR 没怎么提高失配或寄生路径主导了共模增益先测量/仿真共模增益来源，改善匹配与电源/地回流，再优化尾电流源。
有源负载增益很高，但输出摆幅很小电流源合规电压占用了电压余量降低尾电流、改用低压电流源或折叠 Cascode，重新分配摆幅。

  1. 级联增益相乘，但每一级都要按实际负载计算；级数越多，带宽与稳定性越紧张。
