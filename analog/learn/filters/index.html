MODULE 13

有源滤波

Active Filters

用运放和 RC 做出“筛子”：让需要的频率过去，把不需要的挡下来。

综合约 35 分钟1 个实验
LEARNING GOALS · 学习目标
  • 理解低通、高通、带通的幅频/相频特性与截止频率。
  • 会计算一阶 RC 有源滤波器的 f_c 与通带增益。
  • 理解二阶 Sallen-Key 的 ω0、Q、滚降与峰值/振铃之间的关系。
  • 能根据抗混叠、工频抑制、传感器带宽等需求选择滤波器。

先修：运算放大器、频率响应

生活比喻筛子与门卫

低通像只放“慢的人”过去的门卫，高通只放“快的人”，带通只放中间一段。一阶滤波器是一个门卫，二阶是两个门卫串联，挡得更狠；但门卫太严格（Q 太高）会在门口挤出一堆人（峰值/振铃）。

为什么重要 / 用在哪里

  • ADC 前必须有抗混叠滤波，传感器信号要抑制工频/高频噪声。
  • 音频、通信、电源环路补偿都依赖频率选择性。
  • 有源滤波器不需要大电感，便于集成与调参，是模拟前端的主力。

滤波器的三个关键词：截止、阶数、Q

滤波器让某些频率通过、另一些频率衰减。截止频率 f_c 通常定义为幅频下降到通带（或最大值）的 −3 dB 点；阶数决定过渡带斜率（一阶 −20 dB/dec，二阶 −40 dB/dec）；Q 决定截止频率附近的峰值/振铃与相位变化。

一阶有源滤波：一个极点，−20 dB/dec

最常用的一阶有源低通是在反相/同相放大器反馈电阻上并联电容。低频时电容近似开路，增益由电阻比决定；高频时电容容抗下降，反馈减弱，增益下降。一阶高通则把输入耦合电容与电阻组成高通网络，再配合运放缓冲/放大。

f_c = 1/(2πR2C)，低频增益 = R2/R1。这里是反相一阶低通；二阶 Sallen-Key 可提供更陡的滚降，但需要额外考虑 Q 与稳定性。

当前步骤解说

当前频率 10 Hz。低于 f_c：电容容抗大，反馈以 R2 为主，增益接近 A0。

低通滤波器的“筛子”作用来自电容对不同频率的容抗差异：频率越高，越容易被旁路到输出/地。

观察问题：把 C 从 10 nF 增大到 100 nF，f_c 往哪边移？把 R2/R1 从 1 提到 10，低频增益与 f_c 怎么变？

结论提示（先自己想一想再展开）

C 增大使 f_c 降低（低通更早开始衰减）；R2/R1 增大提高低频增益，同时 R2 增大会降低 f_c。增益与带宽再次形成取舍，设计时要先确定截止频率与通带增益。

小技巧先确定 f_c，再分配 R 与 C

f_c 只由 RC 乘积决定，但 R 太大易受偏置电流/漏电影响，C 太大会有体积/ESR 问题。工程上在合理范围内选 R（几 kΩ 到几百 kΩ），再算 C。

二阶 Sallen-Key：更陡的滚降，更高的 Q

二阶低通由两级 RC 加运放反馈组成，高频滚降约 −40 dB/dec。Sallen-Key 用同相放大器提供增益 K，Q 与 K 相关：K 越接近 3，Q 越大，截止频率附近越容易出现峰值甚至振铃。

设计流程：从需求到元件值

  1. 01
    定指标

    通带范围、阻带衰减、允许纹波、过渡带宽度、输入/输出阻抗。

  2. 02
    选阶数/拓扑

    根据滚降需求选一阶/二阶/高阶；有源低通常用 Sallen-Key 或多重反馈。

  3. 03
    算元件

    先定 f_c 与 Q，再选 R/C 组合；核对运放 GBW 至少为 f_c 的 10–50 倍。

  4. 04
    仿真与实测

    检查峰值、相位裕度、噪声、失真与元件容差；PCB 布局注意反馈路径与地。

常见坑滤波器不是“加了电容就完事”

源阻抗、负载阻抗、运放带宽、电容介质吸收都会改变实际响应。高频/高 Q 滤波器尤其要仿真与实测，不能只靠手算。

常见错误与排查

现象常见原因怎么排查
按 f_c=1/(2πRC) 设计后，实测截止频率偏低很多忽略源阻抗/负载阻抗、运放带宽与元件容差把前后级阻抗纳入计算，选低容差电容，核对运放 GBW，必要时仿真。
二阶低通在 f_c 附近出现大峰值/振铃Q 过高（Sallen-Key 的 K 接近 3）降低 K/Q，选巴特沃斯 Q≈0.707，或改用更高性能运放并留相位裕度。
抗混叠滤波器没有效果截止频率选得太高，或采样率/阶数不足按采样定理与 ADC 混叠要求选 f_c 与阶数，给过渡带留余量。
高阻传感器接滤波器后信号变小/失真滤波器输入阻抗不够高，加载了信号源前级加同相缓冲/仪表放大器，或提高输入电阻并核算偏置电流。
