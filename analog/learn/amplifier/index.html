MODULE 05

放大电路基础

Amplifier Basics

放大不是“无中生有”，而是用直流电源的能量，复制并放大输入的变化。

进阶约 40 分钟1 个实验
LEARNING GOALS · 学习目标
  • 把同一张放大电路拆成直流通路与交流通路，分别求 Q 点与动态指标。
  • 会算分压偏置共射电路的 I_C、V_CE，并在负载线上标出 Q 点。
  • 会算中频电压增益、输入电阻、输出电阻，并解释相位为什么反相。
  • 能判断截止失真、饱和失真与最大不失真摆幅，知道 Q 点该放在哪里。

先修：双极型晶体管 BJT、场效应管 MOSFET

生活比喻跷跷板的支点与两端

静态工作点 Q 就像跷跷板的支点：支点太低，一端先碰地（饱和）；支点太高，另一端先碰天（截止）。交流信号只是在支点附近来回摆动，摆幅不能超过两端余量。放大器的任务不是把跷跷板抬得更高，而是让支点稳定、两端留够空间。

为什么重要 / 用在哪里

  • 所有放大电路的分析都遵循“先直流、后交流”的顺序；顺序错了，方程就没有意义。
  • 增益、输入电阻、输出电阻是级联与接口匹配的三个基本指标。
  • 失真与动态范围决定了“能放大”与“能不失真地放大”之间的差距。

一张图，两张网：直流通路与交流通路

放大电路里同时存在直流与交流：直流电源建立静态工作点，交流信号叠加在 Q 点附近。分析时把两者分开：直流通路中，耦合电容视为开路、电感视为短路；交流通路中，耦合/旁路电容视为短路、直流电源视为交流接地。最后把交流结果叠加回 Q 点。

关键结论“先直流，后交流”不是口号，是计算顺序

没有 Q 点，就不知道 r_be、g_m、饱和边界；没有交流通路，就不知道增益。两个模型不能混在一张图里同时套公式。

静态工作点：先让管子站在该站的位置

以分压偏置共射电路为例：Rb1、Rb2 把基极电位固定在 V_B，Re 把发射极电位抬到 V_B−V_BE，从而确定 I_E；I_C≈I_E，再由 Rc 与 Re 上的压降得到 V_CE。Q 点必须落在放大区，并给交流摆幅留出上下余量。

分压偏置共射电路：先算 V_B → V_E → I_E → I_C → V_CE，再画交流通路。

小技巧Q 点不是越低越省电，也不是越高越有劲

Q 点太低，负半周先截止；Q 点太高，正半周先饱和。最佳位置通常在负载线中段，并根据输入/输出摆幅与失真要求微调。

中频增益、输入电阻与输出电阻

把三极管换成小信号模型：基极—发射极之间是 r_be，集电极是受控电流源 βi_b。发射极旁路电容把 Re 交流短路时，增益高但稳定性差；不旁路时，Re 引入交流负反馈，增益降低但线性更好。

动态范围与失真：输出不是想摆多大就摆多大

输出只能在 V_CE(sat) 与 VCC 之间摆动。Q 点偏低时，负半周先截止，输出正峰被削平（共射反相）；Q 点偏高时，正半周先饱和，输出负峰被削平。输入幅度过大时，即使 Q 点居中，也会双向削波。

当前步骤解说

当前输入瞬时值 0 mV，晶体管处于“放大”区，输出瞬时偏移 0 V。

先确定 Q 点，再看输入摆幅：Q 点太低 → 先截止；Q 点太高 → 先饱和。把 Q 点放在负载线中段，并留出 20%–30% 余量，才能兼顾增益与动态范围。

观察问题：固定输入幅度 10 mV，增大 Rb 到 1 MΩ，输出先出现哪种失真？把输入幅度从 10 mV 调到 150 mV，Q 点没变，为什么也会失真？

结论提示（先自己想一想再展开）

Rb 增大使 I_B、I_C 减小、V_CE 升高，Q 点靠近截止，负半周先被削顶（截止失真）；输入幅度增大时，即使 Q 点在中段，摆幅也会碰到 VCC 或 V_CE(sat)，产生双向削波。线性放大只在小信号、Q 点合适时成立。

常见坑“增益不够就加大输入”是最常见的失真来源

输入幅度超过线性范围，输出会被电源轨或饱和压降削平。正确做法是检查 Q 点、交流负载与电源余量，而不是一味加大前级增益。

从单级到多级：增益、阻抗与带宽的取舍

单级共射的增益有限，输入电阻不高、输出电阻偏高。多级放大可以把增益相乘，但每一级都会带来新的输入/输出电阻、频率极点与噪声。级联时要先解决阻抗匹配，再谈总增益；否则前级被后级加载，算出来的增益只是空想。

每级增益必须在“带下一级输入电阻”的条件下计算；空载增益会高估总增益。级数越多，带宽通常越窄、相位滞后越大。

适用边界增益不是唯一指标

噪声、失真、带宽、输入/输出电阻、功耗与成本一起决定方案。一个增益很高但输入电阻很低、输出失真很大的放大器，在真实系统里可能完全不能用。

常见错误与排查

现象常见原因怎么排查
把直流电源直接短路到地来画交流通路忘记“直流电源对交流视为短路”只适用于理想电压源交流通路中电源端视为接地，但仍要保留电源内阻；实际电源的内阻与去耦会影响低频/高频特性。
用空载增益计算级联总增益忽略后级输入电阻对前级的加载每一级都按实际负载计算增益，或把后级输入电阻并入前级交流负载。
Q 点算对了，但输出一加大就失真只看 Q 点，没看最大摆幅与交流负载用 V_om 估算上下余量，留 20%–30% 裕量；必要时降低增益或提高电源电压。
换了 β 更大的管子，增益反而偏离设计旁路共射增益强依赖 β 与 r_be需要稳定增益时让 Re 不旁路，或用负反馈/运放结构。

记住这三句话

  1. 放大电路的分析顺序永远是：直流通路定 Q 点 → 交流通路算增益/阻抗 → 回到时域看失真。
  2. 共射反相、增益高、输出电阻约 Rc；Re 旁路提高增益但牺牲稳定性。
  3. 输出摆幅受 VCC 与 V_CE(sat) 限制，Q 点与输入幅度共同决定失真类型。
