ADC / DACAnalog to Digital / Digital to Analog

ADC 把连续变化的电压切成一个个数字刻度，DAC 反过来把数字码还原成电压。

1 个交互实验 3 道小测验默认 STM32F407 / STM32G474（Cortex‑M4F）

学习目标

  • ·说清“采样 → 保持 → 量化 → 编码”四步，并指出每一步会引入什么误差
  • ·用 LSB 公式算出一个码代表多少电压，解释 ±0.5 LSB 量化误差从哪来
  • ·遇到“读数偏低 / 跳变 / 通道错位”时，能按参考电压、采样时间、源阻抗、DMA 顺序逐项排查
  • ·能用 HAL 配出“两通道扫描 + DMA 循环”的连续采样

一句话解释

ADC 把连续变化的电压切成一个个数字刻度，DAC 反过来把数字码还原成电压。

生活化比喻

ADC 像一把带刻度的尺子

水位在慢慢涨，尺子却只能告诉你“到第几格”——ADC 干的正是这件事：把连续的水位（电压）读成有限的刻度（数字码）。刻度越密（位数越高）读得越细，可尺子本身有厚度、手还会抖（噪声、参考漂移），读数不可能无限精确。量水位时要等水面平静（采样保持），水太急就会量错——这就是采样时间。

为什么重要 / 用在哪里

  • 01现实世界是模拟的：温度、光照、压力、电池电压、电机电流，传感器输出的都是连续电压，进 CPU 之前必须先变成数字。
  • 02闭环控制离不开它：电机电流环、电源环路、电池管理，都要靠 ADC 把“现在到底是多少”读回来；读错了，整个环就跟着错。
  • 03精度直接决定产品体验：同样是 12 位，参考电压稳不稳、采样时间够不够，做出来的秤可能差 1 g，也可能差 50 g。
  • 04它是数字世界唯一的“耳朵”：DAC 是唯一的“嘴”——波形发生、音频输出、模拟量控制都靠它。

从电压到数字：四步

ADC 内部只有四步，任何“读数不准”都能顺着这四步往回找。

ADC（Analog-to-Digital Converter，模数转换器） 把连续变化的模拟电压切成有限个数字码；DAC（Digital-to-Analog Converter，数模转换器） 反过来。MCU 里最常用的是逐次逼近型（SAR，Successive Approximation Register）：内部用一个小 DAC 不断“猜”，猜一次逼近一步，猜 n 次就得到 n 位结果。

  1. 采样（Sample）：在某个时刻把输入电压“抓”进来。抓的时机由触发源决定——软件写 SWSTART、定时器 TRGO、外部引脚，都可以当节拍。
  2. 保持（Hold）：采样开关断开，内部采样电容把那一刻的电压记住。转换期间输入怎么变都不影响结果——所以“保持”是 ADC 能测准的前提。
  3. 量化（Quantize）：把电压归到最近的刻度上。12 位就是 2^12 = 4096 个刻度，归到哪个刻度由 SAR 的 12 次比较决定。
  4. 编码（Encode）：把刻度号写成二进制，放进数据寄存器 DR，CPU 读一次就拿到结果。

为什么这么多传感器都要“过一遍 ADC”：电位器、热敏电阻、光敏电阻、称重传感器、电流采样电阻，输出的都是电压或电阻分压；只有变成数字，CPU 才能比较、存储、显示和上报。

一句话记住整条链路
传感器 → 分压/放大 → RC 抗混叠 → ADC 采样 → 数字滤波 → 使用。链路上任何一环不稳，最后都会算到 ADC 头上；所以怀疑 ADC 之前，先看前面几环。

转换时间：12 位 SAR 要比较 12 次，所以 F4 的转换时间 = 采样时间 + 12 个 ADC 周期（12 位模式，见 RM0090；G4 见 RM0440）。采样时间越长读数越稳，但采样率越低——这是 ADC 最核心的权衡，后面所有配置都在平衡这件事。

分辨率、LSB 与量化误差

一个数字码到底代表多少电压？答案是 LSB——所有 ADC 计算都从它开始。

分辨率（Resolution） 是输出位数 n，刻度总数是 2^n。LSB（Least Significant Bit，最低有效位） 是相邻两个码之间的电压差，也就是“尺子上最小一格的宽度”；码值 k 对应的电压约等于 k × LSB（忽略失调与增益误差，见手册）。

代入数字：VREF+ = 3.3 V、n = 12 时，LSB = 3.3 V / 4096 ≈ 0.81 mV（示意），量化误差最大约 ±0.4 mV。也就是说，12 位 ADC 在 3.3 V 量程上“看得见”的最小变化是 0.8 mV 量级——想测 1 mV 的变化，光靠它不够，得先放大信号或换更高分辨率。

分辨率 ≠ 精度
12 位只说明“刻度有 4096 格”，不代表每个码都准到 0.8 mV：参考电压的噪声与温漂、INL/DNL、源阻抗、地线干扰都会吃掉有效位（ENOB）。看到“标称 12 位”就以为“精确到 0.8 mV”，是最常见的误解。
关于对齐与差分
F4 的 ADC 结果默认右对齐，DR 低 12 位有效（CR2 的 ALIGN 位可改左对齐，见手册）；G4 的 ADC 还支持差分输入，正负端各自量程减半，细节见 RM0440。

参考电压、输入范围与采样时间

读数准不准，八成取决于这三件事——而且它们大多在芯片外面。

参考电压从哪来：F4 的大封装（LQFP100 及以上）有独立的 VREF+ 引脚，可以外接精密基准；小封装内部把 VREF+ 与 VDDA 连在一起，参考电压就等于供电电压——供电有纹波，读数就跟着抖。G4 同样有 VREF+ 引脚，具体接法见数据手册引脚定义。

输入范围：ADC 只能测 0 ~ VREF+ 之间的电压，任何一路输入都不能超过这个范围。电压超过上限或低于 0 V 时，靠内部保护二极管钳位，电流一大就会损坏引脚或把 VDDA 拉高。要测更高的电压，先分压或加运放衰减，再串限流电阻并加钳位保护。

采样时间与源阻抗：采样开关合上的瞬间，内部采样电容 C_ADC 要通过“源内阻 + 开关电阻”充电；源内阻越大，充到目标电压越慢。采样时间不够，电容还没充满就开始比较，读数会系统性偏低，通道之间还会互相“串味”。

采样定理（Nyquist）：采样率 fs 必须大于信号最高频率的两倍，否则高频会“折”到低频，变成根本分不清的假信号（混叠）。测电机电流、音频这类快变信号时，模拟前端的 RC 低通和采样率要一起设计，不能只顾软件。

绝不能用 ADC 引脚直接测高压
ADC 输入范围只有 0 ~ VREF+。把 12 V 电池或市电直接接上去，超范围电压会通过内部保护二极管灌电流，轻则读数饱和、重则损坏芯片。正确做法是“分压 + 限流 + 钳位”，高压场景还要加隔离。另外，万用表读的是有效值或平均值，ADC 采的是某一瞬间的电压，两者不能直接对照。

四种模式与配置步骤

同样是“采一个电压”，模式不同，代码结构完全不同。

  • 单次（Single）：触发一次只转一个通道，结果进 DR，CPU 轮询 HAL_ADC_PollForConversion 或等中断后 HAL_ADC_GetValue。适合“偶尔测一下”的场景。
  • 连续（Continuous）：CR2 的 CONT 置位后，转换结束立刻自动开始下一轮，CPU 只要及时取走结果。适合持续监控。
  • 扫描（Scan）：CR1 的 SCAN 置位 + 序列长度大于 1，按 SQR1 里排好的顺序依次转换多个通道。多个结果都写进同一个 DR，必须配合 DMA 或中断逐次取走。
  • 不连续（Discontinuous）：把序列拆成小组，每次触发只转一组，组与组之间等下一次触发。用于“多通道但想按需分组采样”的场合（细节见手册 ADC 章节）。

规则组（Regular）与注入组（Injected）：规则组是常规序列，结果都进 DR；注入组可以“插队”打断正在进行的规则组转换，并有独立的结果寄存器，常用来做紧急或与 PWM 同步的采样（电机、电源里常见）。

  1. 开时钟：ADC1 挂 APB2、DMA 挂 AHB1，用 __HAL_RCC_ADC1_CLK_ENABLE() 和 __HAL_RCC_DMA2_CLK_ENABLE() 打开；漏了时钟，后面全是空写。
  2. 配引脚：模拟输入脚设为 GPIO_MODE_ANALOG，断开数字输入缓冲，减少漏电与干扰。
  3. 配 ADC 基础参数：分辨率、扫描/连续、触发源、数据对齐；F4 还要用 ADC->CCR 的 ADCPRE 确定 ADC 时钟，别超过手册上限。
  4. 配序列与采样时间：每个通道用 Rank 决定在序列里的位置，用 SMPR1/SMPR2 决定采样多久；源阻抗高就选更长档。
  5. 配 DMA：外设地址固定为 ADC1->DR、内存地址自增、半字宽、循环模式；HAL_ADC_Start_DMA 会把 DMA 句柄挂到 ADC 上。
  6. 校准：启动前做一次 ADC 自校准（HAL_ADCEx_Calibration_Start），补偿内部失调；校准期间不要触发转换。
  7. 启动：单次用 HAL_ADC_Start + 轮询/中断，多通道连续用 HAL_ADC_Start_DMA，在回调里处理整块数据。

DMA 为什么是多通道的标配：扫描模式下每个通道的结果都写同一个 DR，CPU 慢一步就被下一个通道覆盖，读到的顺序全乱。DMA 在每次转换完成（EOC）时自动把 DR 搬到数组，数组下标正好对应 Rank 顺序——顺序错了，数据就张冠李戴。

采样率上限怎么估
单通道最高采样率约等于 f_ADC / (采样周期数 + 12)（12 位、F4，示意）。ADC 时钟上限见数据手册（F4 常见 36 MHz 量级）；多通道扫描时，这个采样率还要再除以通道数。

回调真的会进吗？
HAL_ADC_Start_DMA 只负责启动。要让 HAL_ADC_ConvCpltCallback 生效，还必须在 NVIC 里打开 DMA2_Stream0_IRQn，并在 DMA2_Stream0_IRQHandler 里调用 HAL_DMA_IRQHandler(&hdma_adc1)。漏了这两步，ADC 与 DMA 都在正常干活，回调却永远不触发。
同一件事（两通道扫描采样）的三种写法

三种写法操作的是同一组寄存器，区别只在“谁帮你算位域”。LL 的函数名在不同系列/固件版本略有差异，以你工程里的 stm32f4xx_ll_adc.h 为准。

噪声与滤波：ADC 读数天生带噪声，最简单的办法是均值滤波——连续采 N 次求平均，白噪声按 √N 下降，N 取 8/16/32 这种 2 的幂时除法还能换成移位；遇到尖峰（电机换向、继电器动作）改用中值滤波——取 N 次采样的中间值，直接把离群点丢掉。要求更高时上滑动平均、一阶低通，或者用硬件过采样：把 2^k 次采样累加后右移 k 位，等效多出几位分辨率（硬件是否支持、怎么配见对应参考手册的 ADC 章节，软件累加平均同样有效）。

反方向：DAC 与模拟输出

ADC 是耳朵，DAC 是嘴：把数字码变成电压，用来驱动、发声、做基准。

DAC（Digital-to-Analog Converter） 把数字码还原成电压：F407 有 2 路 12 位 DAC（通道数等细节以数据手册为准），输出范围 0 ~ VREF+，分辨率与 LSB 的算法和 ADC 完全一样。

从写到输出的路径：软件写 DAC->DHR12R1（12 位右对齐数据保持寄存器），硬件在触发事件到来时把它搬到 DAC->DOR1 再送输出；没有触发时写入即生效。DAC->CR 里的 EN 使能通道、TEN 选择触发、BOFF 控制输出缓冲器（具体位定义见手册）。

常见错误与排查

错误现象怎么查 / 怎么改
参考电压或模拟地不干净读数整体跳动、同一电压重复测差好几个码；用手摸板子或旁边电机一转，读数就变先查 VDDA/VREF+ 的去耦电容与走线，模拟地与功率地单点连接；有独立 VREF+ 引脚就外接精密基准，别拿开关电源的 3.3 V 当基准。
采样时间太短，或源阻抗太高读数系统性偏低；换到下一个通道时，前一个通道的电压“残留”影响新通道（串扰）按 t_s ≥ (R_AIN + R_ADC)·C_ADC·ln(2^(n+1)) 估算所需采样时间（示意），选更长档；源阻抗高就加运放缓冲或在输入端并小电容，别指望软件滤波救回来。
多通道扫描不用 DMA，只读一次 DR两个通道读出来几乎一样，或者拿到的总是最后一个通道的值；通道顺序和接线对不上扫描模式的结果都写同一个 DR，必须用 DMA（或每次 EOC 中断读一次）；数组下标 = Rank 顺序，搬运长度 = 通道数，三处必须一致。
输入电压超出 0 ~ VREF+ 范围读数饱和在 4095 或 0；输入接 12 V / 负压时芯片发热、甚至整片损坏先分压或运放衰减到量程内，再串限流电阻并加钳位保护；上电前用万用表确认每路输入电压都在范围内。
跳过校准，或上电就高速连续采样零点有固定偏差（输入接地也读几十个码）；不同板子偏差还不一样初始化后、启动转换前调用一次 HAL_ADCEx_Calibration_Start；校准期间不要触发转换，校准完成后再启动 DMA。

记住这三句话

  1. 01ADC 的本质是“采样 → 保持 → 量化 → 编码”：LSB = Vref / 2^n 决定一格多宽，量化误差最大 ±0.5 LSB，这是原理性误差，分辨率不等于精度。
  2. 02读数准不准由“参考电压稳、采样时间够、源阻抗低、地干净”共同决定；多通道扫描必须靠 DMA 按 Rank 顺序搬走结果，否则数据会被覆盖或错位。
  3. 03DAC 是 ADC 的逆过程：12 位数字码写进 DHR，硬件搬到 DOR 输出；配定时器触发和 DMA 送表就能产生三角波、正弦等模拟波形。
