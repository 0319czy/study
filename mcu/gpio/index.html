一句话解释

GPIO 是能被软件定义成输入、输出、复用或模拟的引脚，一切外设信号最终都从这些引脚进出。

生活化比喻

GPIO 像每个房间门边的“万能开关面板”

每个孔既能接成开关（输入：你按它，它才变），也能接成灯（输出：你写 1，它才亮）。输出还分两种接法：推挽是两个方向都主动，能推能拉；开漏只有一根往下的线，只能拉低，高电平得靠外面的上拉电阻“拉”回来。面板出厂默认是悬空的——你不去定义它，它就不代表任何意思，读回来的值纯看外面接了什么。

为什么重要 / 用在哪里

  • 01一切外设都从这里出门：UART 的 TX、SPI 的 SCK、TIM 的 PWM 输出，本质都是“某个引脚先被配成复用功能”，再交给外设。
  • 02调试最常见的一类故障：点不亮、读不到按键、波形不对，八成出在时钟没开、模式配错、开漏没上拉这三件事上。
  • 03电气边界决定电路怎么画：能不能直连 5V 器件、要不要加三极管、上拉取多大，答案都在数据手册的 GPIO 章节里。
  • 04面试与实测都会问：推挽与开漏的区别、线与、按键上拉还是下拉，是最常被追问的基础题。

GPIO 到底是什么

先把“引脚”和“电平”这两件事分开看，后面所有配置都是在改这两者。

GPIO（General-Purpose Input/Output，通用输入输出）：芯片上一组可以被软件定义用途的引脚。它本身不做协议，只做两件事——读引脚上的电平（输入）和把引脚拉到某个电平（输出）。正因为“通用”，它才既能点灯、读按键，也能临时用软件“模拟”出一段 I²C 时序（俗称软件 I²C）。

引脚看到的永远是电平，不是数字。以 3.3 V 系统为例：高电平接近 VDD（3.3 V 量级），低电平接近 0 V；但“多高才算高”由数据手册里的输入阈值（VIH / VIL）规定，并不是严格的 3.3 V 与 0 V。所以逻辑电平以 VDD 为参考——换到 1.8 V 或 5 V 供电的系统，同一套代码的行为要重新核对。

  • 输出：LED、继电器控制、片选 CS、蜂鸣器、使能脚——只需“高/低”两种状态。
  • 输入：按键、拨码开关、传感器开关量输出、模块的 READY / INT 脚。
  • 复用：引脚交给片上外设（USART / SPI / TIM / I²C 等），这时你不再直接写 ODR，而是让外设驱动它。
  • 模拟：引脚直连 ADC / DAC 的模拟通道，数字输入输出电路被断开。
三条必须先记住的事实
① 复位后引脚默认是高阻输入（MODER = 00、PUPDR = 00），谁都没在驱动它；② 输出电平由 ODR 这个“软件想输出的值”决定，而 IDR 反映的是引脚实际电平，两者可能不一致；③ 只有 MODER 配成 10 复用之后，这个引脚才归外设管，此时再写 ODR 没有意义。

四种模式与 MODER

一个引脚干什么，先由 MODER 里属于它的 2 位决定——这是所有 GPIO 配置的第一道岔路。

GPIOA->MODER 里每个引脚占 2 位：00 = 输入、01 = 通用输出、10 = 复用功能、11 = 模拟。所以 PA5 这 2 位在第 10、11 位（5 * 2 = 10），PA0 在第 0、1 位。改模式时的标准写法是“先清零这 2 位，再写入目标编码”，否则会把上一位的残留值带上。

选完模式，还有三个寄存器要一起看：`OTYPER` 选推挽（0）还是开漏（1）；`PUPDR` 每引脚 2 位，00 无上下拉、01 上拉、10 下拉（11 保留）；`OSPEEDR` 每引脚 2 位，选输出边沿速度档位（大致分低速/中速/高速/超高速几档，具体编码与命名见参考手册 GPIO 章节，各系列略有差异）。

  • 施密特触发（Schmitt trigger）：输入路径上通常带整形电路，把缓慢爬升的边沿整成干净的高低电平，并带一点迟滞来抗抖动；它对“噪声”有帮助，但不能替代按键去抖。
  • 输入浮空的风险：MODER = 00 且 PUPDR = 00 就是浮空输入——引脚像一根天线，电平由漏电和干扰决定，读到的值可能每次都不一样，还会让输入级来回翻转、抬高功耗。按键不接上下拉是新手最常见的坑。
  • 上拉还是下拉，看开关怎么接：按键一端接地，就配上拉（松开为高、按下为低）；按键一端接 VDD，就配下拉。逻辑方向反了，程序就会“按下没反应、松开一直触发”。
  • 模拟模式不等于输入：11 会断开数字输入缓冲器，ADC 才能准确采样；用成 00 输入去接模拟信号，既读不准模拟量，也可能白白多耗电。

推挽、开漏与线与

同样是“写 1”，推挽是芯片主动输出高电平，开漏只是“放手”——这是两套完全不同的电路行为。

输出级的核心是两只 MOS 管：上面一只 PMOS 接 VDD，下面一只 NMOS 接 GND，中间就是引脚。推挽（Push-Pull） 让两只管子成对工作：写 1 时 PMOS 导通把引脚“推”到 VDD，写 0 时 NMOS 导通把引脚“拉”到 GND——能推能拉，驱动强、边沿快。开漏（Open-Drain） 里 PMOS 不参与：写 1 只是关掉 NMOS（相当于放手），写 0 才把引脚拉到 GND。所以开漏的“高电平”必须由外部上拉电阻提供。

线与（wired-AND） 是开漏最有价值的特性：多个设备把输出接在同一根线上，各自只负责“拉低”或“放手”，线上电平 = 所有设备都放手时为高、任意一方拉低就为低。I²C 的 SDA/SCL 就是这么工作的，它还要靠这套机制做时钟同步和多主机仲裁。代价是上升沿由“上拉电阻 × 总线电容”这个 RC 决定，上拉越大越省电但越慢，所以 I²C 的上拉阻值要按总线速率和电容来选。

推挽Push-Pull
上下两管成对工作，写 1 主动输出高、写 0 主动拉低，驱动强但不能并联。
开漏Open-Drain
只有下管参与，写 1 等于放手，高电平靠外部上拉；可以多设备共线做线与。
线与Wired-AND
多路开漏输出接在同一根线上，任一路拉低则整条线为低，等价于“全部为高才为高”。
灌电流Sink Current
外部电流经负载流入引脚、再经 NMOS 入地；GPIO 拉低时点灯最可靠的方式。

复用功能与配置步骤

复用模式下引脚归外设管，但“这根脚到底接哪个外设”要你查手册填 AFR，这一步最容易配错。

把 MODER 写成 10（复用功能）只是说“这根脚交给片上外设”，还要告诉芯片交给哪一个。答案在 GPIOA->AFR[0] / AFR[1] 里：每个引脚占 4 位，取值 0–15 对应 AF0–AF15；引脚 0–7 在 AFR[0]，引脚 8–15 在 AFR[1]。同一根引脚在不同芯片上可能对应不同外设（甚至同一芯片的不同封装也不同），所以AF 编号不能背、不能跨型号抄。

  1. 查表：打开你自己芯片的数据手册（Datasheet），找到 Alternate function mapping 表。
  2. 定位引脚：在表里找到你板子上实际连出去的那个引脚（比如 PA9），确认当前封装里它存在。
  3. 找外设那一列：在你需要的那个外设（如 USART1_TX）那一列里，读出对应的 AF 编号。
  4. 写进 AFR：把这 4 位写进 AFR[引脚/8] 中 (引脚 % 8) * 4 的位置（先清零再写）。
  5. 交叉验证：和 CubeMX 生成的 HAL_GPIO_Init 代码对一眼——两者不一致时，以手册和实际板子为准。

速度档位（OSPEEDR）不是越快越好：档位越高，输出边沿越陡，能跑更高频率的信号，但 EMI 和瞬时功耗也更大。点灯、按键这类慢信号用最低档；SPI、高速 PWM 才需要高档。本页举例时只给“低速/中速/高速/超高速”这个量级说法，具体编码与档位数量以你芯片的参考手册为准。

不要编 AF 编号
不同系列、不同封装的 Alternate function mapping 表都不一样，同一个 AF 编号在另一颗芯片上可能是完全不同的外设。本页不给出任何具体引脚的 AF 号——你需要时以你自己芯片的手册为准，并在上板前用示波器或 CubeMX 配置交叉确认。
  1. 使能端口时钟：GPIOA 挂在 AHB1 上，写 RCC->AHB1ENR 对应位（或调 __HAL_RCC_GPIOA_CLK_ENABLE()）。时钟没开，后面所有寄存器写入都进不了门。
  2. 先写初值：需要“上电即高”的场合，先写 ODR / BSRR 把电平定好，再去切模式——否则切到输出的瞬间 ODR 复位值 0 会把引脚拉低。
  3. 选模式：MODER 清零那 2 位后写 00/01/10/11，决定输入、输出、复用还是模拟。
  4. 定电气属性：输出选 OTYPER（推挽/开漏）、OSPEEDR（速度）；输入按外部接法定 PUPDR（上拉/下拉/不拉）。
  5. 复用补 AFR：MODER = 10 之后，再把外设编号写进对应 AFR 的 4 位。
  6. 读写与触发：输入读 IDR；输出用 BSRR（原子置位/复位）或 ODR；接下来交给中断、DMA 或主循环处理。

关于 5V 容忍，两个最常见的误解
① FT 指的是输入可以容忍 5 V，不代表这个引脚能输出 5 V 高电平——输出高电平仍然是 VDD，驱动 5 V 器件需要电平转换。② 即使在 FT 引脚上，一旦配成模拟模式或某些复用功能，5 V 容忍通常不再保证，而且不同封装的 FT 标注可能不同。以数据手册引脚定义表里的 I/O 结构那一栏为准，别按“STM32 都抗 5V”去做电路。
  • 点 LED 必须串限流电阻：330 Ω 量级是常见教学取值（示意），实际按 VDD、LED 压降和目标电流算，别直接用引脚硬怼 LED。
  • 感性负载（继电器、电机、蜂鸣器）不能直连：要加三极管 / MOS 管 / 驱动芯片，线圈两端加续流二极管，否则关断瞬间的反电动势会打穿引脚甚至复位芯片。
  • 不要用 GPIO 给模块供电：引脚是信号脚，不是电源；模块的 VCC 走电源轨，只把使能/通信脚接到 GPIO。
  • 长线、插座引出的信号要考虑上拉与保护：悬空的长线等于天线，加串阻、上拉或 RC 滤波，必要时加 TVS。

下一页进入 中断与 NVIC：本页的按键是“主循环里反复读 IDR”，CPU 一直在空转等；中断则让按键变化主动打断 CPU。理解了 GPIO 的输入路径和上下拉，才能看懂外部中断为什么要选边沿、为什么浮空输入会误触发。

常见错误与排查

错误现象怎么查 / 怎么改
忘记使能 GPIO 端口时钟代码编译通过、初始化函数也不报错，但引脚电平纹丝不动；单步调试时能看到寄存器写入“没生效”先确认 `RCC->AHB1ENR` 对应位（或调 `__HAL_RCC_GPIOx_CLK_ENABLE()`）。F4 上所有 GPIO 都在 AHB1，时钟没开时写 MODER 等于写进空气。
复用功能的 AF 编号抄错或漏配 AFR外设初始化返回成功，但引脚上没有任何波形；或者波形出现在完全不相干的另一个引脚上按自己芯片数据手册的 Alternate function mapping 表逐脚核对 AF 编号，再用 CubeMX 生成的配置交叉验证；不要跨型号、跨封装照抄。
开漏输出没有接上拉写 1 后万用表给不出稳定高电平，读回的值随机；示波器上看到缓慢爬升的斜坡甚至一直上不去开漏必须靠上拉才能得到高电平：加外部上拉（阻值按速率与总线电容选），验证阶段也可先开内部上拉。I²C 一定要外部上拉。
按键没有去抖，或上下拉方向配反按一下灯连闪好几次、计数乱跳；或者“松开一直触发、按下没反应”先确认按键接法：一端接地就配上拉（按下为低）。再去抖——延时二次确认够用，要求高时用定时器采样或中断 + 定时器。
用 GPIO 直接驱动大电流负载引脚电压被拉低、芯片发烫；带电机/继电器时一动作就复位或死机引脚只做控制信号：加三极管/MOS/驱动芯片，感性负载加续流二极管；电流上限与总限额见数据手册，不要靠“能亮就行”去试。
