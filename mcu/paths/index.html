学习路径 3 条路线

选一条路线，按顺序走

不知道自己该从哪开始？先看目标：想入门选零基础，要做项目选硬件/驱动，要面试选复习路线。每一步都落到具体页面。

1

零基础路线

约 3–4 周，每天 1 小时

从“MCU 是什么”到能点亮第一颗 LED、发出第一帧串口数据

适合：刚接触单片机 / 电子相关专业低年级 / 想转嵌入式的同学

从第一步开始
  1. 1
    MCU 基础概念

    先分清 MCU / MPU / SoC，理解冯诺依曼与哈佛结构、指令集。

  2. 2
    内核与存储器概念

    看懂 Cortex‑M 的寄存器、栈、Flash 与 SRAM 的分工，理解程序怎么跑起来。

  3. 3
    时钟与复位基础

    晶振 → PLL → 时钟树，为什么先配时钟再配外设。

  4. 4
    GPIO动手

    推挽/开漏/上下拉，第一个实验：按键点灯。

  5. 5
    UART通讯

    约定语速说话：帧格式、波特率、printf 重定向。

  6. 6
    实战案例 · 按键中断点灯综合

    把 GPIO + 中断串起来，做一个完整的可观察现象。

走这条路要注意

  • 不要一上来就啃参考手册，先建立“数据流”直觉：配置 → 使能 → 触发 → 中断/DMA → 处理。
  • 每个外设至少亲手改一个参数（比如波特率、占空比），看现象怎么变。
  • 遇到问题先分三类：没使能时钟 / 引脚复用错 / 电平与接线错。
2

硬件 / 驱动开发路线

约 6–8 周，配合实际开发板

从“会点灯”到能读写传感器、驱动屏幕、调试总线故障

适合：要做项目、参加竞赛、准备嵌入式岗位的同学

从第一步开始
  1. 1
    中断与 NVIC核心

    抢占/子优先级、ISR 里能做什么不能做什么、延迟处理。

  2. 2
    DMA核心

    让数据自己搬家：串口收发的 DMA 配置与半传输中断。

  3. 3
    定时器 / PWM核心

    PSC/ARR/CCR 三个数决定频率与占空比，输入捕获测频率。

  4. 4
    ADC / DAC核心

    采样、分辨率、参考电压，配合 DMA 做连续采集。

  5. 5
    I²C 与 SPI通讯

    两根线/四根线的世界：地址、ACK、CPOL/CPHA 四种模式。

  6. 6
    调试与测量工具

    逻辑分析仪抓时序、示波器看电平、SWD 单步排错。

  7. 7
    实战案例 · 8 个完整案例综合

    温湿度、屏幕、CAN 节点、DMA 串口搬运等，逐个打通。

走这条路要注意

  • 每个协议都按“电气层 → 时序层 → 帧层 → 应用层”四层去拆，排错时才能定位到层。
  • 先让逻辑分析仪跑通再写驱动：能看到波形，比读十遍手册更有效。
  • 驱动代码要能被别人复用：把“初始化”和“业务”分开。
3

面试复习路线

约 1 周，每天 2 小时

用最短路径把高频考点和“能讲清楚”的时序图装进脑子

适合：准备嵌入式/单片机岗位面试、需要快速复盘的同学

从第一步开始
  1. 1
    内核与启动流程高频

    复位向量、栈顶地址、启动文件做了什么、链接脚本怎么排布。

  2. 2
    中断机制高频

    NVIC 优先级分组、中断响应过程、尾链、为什么要清标志位。

  3. 3
    通讯协议对比高频

    UART/I²C/SPI/CAN 的线数、速率、拓扑、典型应用一张表说清。

  4. 4
    时序细节高频

    I²C 的 ACK 与时钟延展、SPI 的四种模式、CAN 的仲裁与位定时。

  5. 5
    DMA 与低功耗加分

    DMA 通道/请求/循环模式，低功耗三种模式与唤醒源。

  6. 6
    测验中心自测自测

    用单选/多选/判断题把薄弱点暴露出来，再回页面对应补。

走这条路要注意

  • 面试表达公式：它解决什么问题 → 电气/时序关键点 → 配置步骤 → 常见坑。
  • 能手画时序图（I²C 一帧、SPI 四线、CAN 仲裁）比背寄存器名更有说服力。
  • 被问到不会的，先讲清“我会怎么查”：数据手册哪一章、逻辑分析仪怎么抓。

怎么用这个站

每页固定结构：学习目标 → 一句话解释 → 生活化比喻 → 为什么重要 → 核心概念 → 代码 → 动画 → 常见错误 → 小测验 → 记住三句话。
