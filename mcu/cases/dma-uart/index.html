DMA 串口搬运

把串口收发交给 DMA：CPU 只写起始地址和长度，剩下的搬运全由硬件完成。

5 件硬件 8 步默认 STM32F407 / STM32G474（Cortex‑M4F）

目标

  • 说清 __HAL_LINKDMA 做了什么，为什么发送挂 hdmatx、接收挂 hdmarx
  • 写出 USART1 的 DMA 发送（单次）与 DMA 接收（循环 + 半满回调）
  • 解释为什么 DMA 缓冲不能是栈上的局部数组
  • 偶发丢字节或乱码时，能按缓冲生命周期、NDTR 单位、NVIC、空闲中断四项排查

STM32F407 开发板USB-TTL 串口模块（3.3 V 电平）杜邦线（TX/RX/GND 三根）电脑串口助手逻辑分析仪（可选，看线上字节）

实现步骤

  1. 1① 先把“轮询版”跑通，再上 DMA

    接好 TX/RX/GND，用 HAL_UART_Transmit 轮询发一句 hello，串口助手能看到。为什么先轮询：一次只引入一个变量，确认波特率、接线、电平都对，后面 DMA 出问题时才有对照基准。

  2. 2② 查请求映射表，选对流与通道

    USART1_TX 与 USART1_RX 各接哪条流、哪个通道是芯片固定接好的：F407 上常见 TX = DMA2_Stream7 / Channel 4，RX = DMA2_Stream5 / Channel 4（另一条可选 Stream2），照参考手册的请求映射表核对。选错的表现是“启动返回成功，但一个字节都不出去”。

  3. 3③ 配 DMA 的四个旋钮

    发送：内存→外设、内存自增、外设不自增、8 位、单次模式；接收方向相反、循环模式。直连（FIFO 关闭）模式下两端位宽必须一致，否则数据会错位。

  4. 4④ 关联与开中断

    HAL_DMA_Init 之后紧跟 __HAL_LINKDMA：发送挂 hdmatx、接收挂 hdmarx，它同时把句柄的 Parent 指回 UART。再使能对应流的 NVIC 中断——少这一环，回调永远不来。

  5. 5⑤ 启动发送：异步，返回不等于发完

    HAL_UART_Transmit_DMA 只负责“开始发”，立刻返回；句柄处于 BUSY_TX 时再次调用会返回 HAL_BUSY。缓冲在 TxCpltCallback 之前一个字都不能改。

  6. 6⑥ 启动接收：循环 + 半满，做双缓冲

    HAL_UART_Receive_DMA 配循环模式，半满处理前半、全满处理后半，处理时另一半正在被写，天然不打架。这是不定长接收最省心的骨架。

  7. 7⑦ 用空闲中断切“一帧结束”

    循环接收只知道“搬了多少”，不知道“对方停了”。打开 UART 的空闲（IDLE）中断，线上安静一个字符时间就认为一帧结束，再结合已收到的字节数定位数据。

  8. 8⑧ 验证：计数器 + 分析仪

    让电脑连续发 1 KB 数据，对比串口助手的发送计数与 MCU 收到的字节数；用逻辑分析仪看线上实际字节，确认丢的是“线上就没有”还是“搬进内存时丢了”。

错误现象怎么查 / 怎么改
把栈上的局部数组交给 DMA 发送偶发乱码、只发出前几个字节；改 -O0 或加一句打印又“看起来正常”，极难复现DMA 缓冲必须是 static 全局数组或常驻堆内存，并且要活到 TxCplt 回调之后；发送前先 memcpy 进常驻缓冲再启动。
忘了 __HAL_LINKDMA，或发送/接收挂错方向启动返回 HAL_OK，但一个字节都不出去（接收侧则是一个字节都进不来）检查 huart1.hdmatx / hdmarx 是否分别指向对应句柄，以及句柄的 Parent 是否指回 huart1。发送挂 hdmatx、接收挂 hdmarx，不能互换。
请求映射表选错流或通道NDTR 在减、启动也成功，但外设毫无反应；或数据被搬进了错误的缓冲照 RM0090 的 DMA 请求映射表核对控制器、流、通道、方向四项。F407 上 USART1_TX 常见 DMA2_Stream7/Ch4，USART1_RX 常见 DMA2_Stream5/Ch4（另一可选 Stream2）。
把 NDTR 的单位当成字节16 位宽时只搬了一半数据，或缓冲尾部多出一截旧内容NDTR 是数据项个数：8 位宽时数据项 = 字节；16 位时 64 个数据项 = 128 字节。按“字节数”想问题，按“数据项数”填寄存器。
接收用单次模式，却以为能一直收只收到第一批 len 个字节，之后缓冲不再更新；再启动返回 HAL_BUSY接收改 Circular 模式，或在每次完成回调里重新启动；循环模式下用半满/全满回调切安全区，并用空闲中断处理不定长帧。

第 1 / 6 步

地址自增只在内存侧开启；外设侧固定指向同一个数据寄存器（所以每次请求都读同一个地址）。

步骤 1/6|① 配置 DMA：源、目的、数量

CPU 只写几行配置：源地址（外设数据寄存器，如 USART1->DR）、目的地址（内存数组 buf）、传输数量 NDTR = 16、数据宽度 8 位、内存地址自增。配好后 单次模式，CPU 就可以去干别的了。

第 1 / 12 步
步骤 1/12|空闲：线保持高电平

没有数据时 TX 线保持高电平（空闲态）。接收方一直在等"从高变低"的那个跳变——这就是起始位的意义：它告诉对方"注意，一帧来了"。
