SPI 驱动屏幕

用 SPI 加几根控制线点亮 TFT 屏：先发命令、再开窗口、最后把整块像素交给 DMA。

4 件硬件 8 步默认 STM32F407 / STM32G474（Cortex‑M4F）

目标

  • 说清 SPI 屏为什么比普通 SPI 器件多出 DC、RES 两根线，以及 CS 为什么要覆盖整帧
  • 用 HAL 写出“命令 / 数据 / 开窗口 / 整块填色”四层，让屏先显示纯色块
  • 估算刷一屏要多久，并把整块像素的发送交给 DMA，理解 CPU 只在起止两处参与
  • 遇到白屏、花屏、只画一半时，能按 RES 复位、CS 时序、字节序、分频四项排查

硬件清单

STM32F407 开发板常见 SPI TFT 模块（ST7735 类驱动器，带 CS/DC/RES 引脚）杜邦线若干（尽量短）逻辑分析仪或示波器（验 CS/DC/SCK，可选）

信号MCU 引脚接到器件说明

MOSIPA7屏模块 SDA / MOSI主机发、屏收；屏一般只写不读，MISO 可以省掉不接；按你的板子原理图核对

实现步骤

  1. 1① 先认清屏的接线与驱动器

    看模块丝印与配套例程，确认它是 SPI 接口、带 CS/DC/RES、驱动 IC 属于哪一类（常见 ST7735 类）。为什么第一步是这个：初始化序列是驱动 IC 私有的，换一类屏就得换表，先确认型号才不至于白忙。

  2. 2② 配 SPI1：主机、8 位、Mode 0、保守分频

    SCK / MOSI 配成复用推挽（AF5），CS / DC / RES 配成普通推挽输出。先给几 MHz 量级的分频，把通信跑通；速度是后面再提的事，一上来满速会让“配错”和“跑太快”混在一起。

  3. 3③ 硬复位屏

    先把 RES 拉低几十毫秒量级，再拉高，然后等模块手册要求的稳定时间。为什么不能省：驱动器上电后停在未知状态，不复位就发命令，屏幕大概率一直黑，而 SPI 波形看起来完全正常。

  4. 4④ 写底层三件套：选片、切 DC、发字节

    封装 lcd_select / lcd_release、lcd_write_cmd（DC=0）、lcd_write_data（DC=1）。这一层只有十几行，却决定了后面所有调用对不对；先把它写对，再谈初始化表。

  5. 5⑤ 把模块例程里的初始化表原样搬过来

    初始化是一串“命令 + 若干参数”，不同驱动 IC 不能混用，所以本页只给“怎么把表逐条发出去”的框架，不给具体命令码。数值照你的模块例程或数据手册填，别从别的屏抄。

  6. 6⑥ 开窗口 + 填纯色块，验证坐标与颜色

    先设列范围、再设行范围，最后发“写显存”命令，之后连续写入的像素会按行填满窗口。先填三个纯色块：能验证坐标原点、扫描方向与 RGB565 的高低字节顺序。

  7. 7⑦ 提速：整块像素交给 DMA

    一个像素 2 字节，一屏十几万字节用 CPU 逐字节发会占满主循环。改成“开窗口 → 启动一次 DMA 发送整块缓冲 → 完成回调里再开下一块”，CPU 只在起止两处出现。

  8. 8⑧ 用逻辑分析仪收尾

    量 CS 是否覆盖整帧、DC 是否在命令与数据之间正确切换、SCK 空闲电平是否是低（Mode 0）。这三条对上了，屏还不亮就只剩初始化序列和供电两件事要查。

RGB565 高低字节顺序搞反画纯色块时颜色不对（红变蓝之类），或整体偏色、颜色像被“洗过”高字节先发是常见约定，但屏的字节序由初始化里的设置决定；先画红/绿/蓝三个纯色块验证，再调字节顺序。别靠猜。
CS 在整块像素中途被拉高，或 HAL_SPI_Transmit 长度写成像素数只画出第一条线、只填了半屏，或画面整体错位一格大块像素整段保持 CS 低、DC 高；长度参数是字节数 = 像素数 × 2。用逻辑分析仪数一帧里的 SCK 个数，与“像素数 × 16”对照。
SCK 分频太高，或杜邦线太长短线上正常，换长排线或提高一档分频就花屏、偶发白屏；降速后恢复逐档提高分频直到出错，然后退回一档留余量；缩短走线、让 SCK 远离干扰源。屏是容性负载，边沿变缓后采样点容易错。
换了一块屏，却沿用上一块的初始化序列新屏上电不亮、花屏或颜色异常，而代码“在旧屏上明明是好的”初始化序列绑定驱动 IC，不可混用：看模块丝印/例程确认是哪一类（常见 ST7735 类），换成对应表；顺便核对分辨率与坐标方向设置。

SPI 模式

本实验固定 MOSI 发送 0xA5、MISO 回 0x3C（示意数据），用来观察"同一位同时收发"的全双工特性。

步骤 1/10|① CS 拉低：选中从机

主机先把片选 CS 拉低（多数器件低有效）。多从设备时，每个从机一根独立 CS；只有被选中的从机才会驱动 MISO。

第 1 / 6 步

地址自增只在内存侧开启；外设侧固定指向同一个数据寄存器（所以每次请求都读同一个地址）。

步骤 1/6|① 配置 DMA：源、目的、数量

CPU 只写几行配置：源地址（外设数据寄存器，如 USART1->DR）、目的地址（内存数组 buf）、传输数量 NDTR = 16、数据宽度 8 位、内存地址自增。配好后 单次模式，CPU 就可以去干别的了。
