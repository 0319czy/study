ADC + DMA 采样

让 ADC 连续扫描、DMA 自动搬运，CPU 只在半满和全满时取走数据并换算。

5 件硬件 8 步默认 STM32F407 / STM32G474（Cortex‑M4F）

目标

  • 用 LSB = VREF+ / 2^n 把原始码换算成 mV，并说清读数为什么会跳
  • 配出 ADC1 扫描 + 连续 + DMA2 循环，让两个通道的结果按 Rank 顺序落进数组
  • 用半满 / 全满回调切出“安全区”，保证处理的那一半没被 DMA 改写
  • 读数不准时按参考电压、采样时间、源阻抗、缓冲长度对齐四项排查

硬件清单

STM32F407 开发板10 kΩ 量级电位器（做一路可调输入）热敏电阻或光敏电阻模块（做第二路，可选）万用表（对照读数）杜邦线若干

实现步骤

  1. 1① 先接一个“确定电压”的输入

    用 10 kΩ 量级电位器做 PA0 的输入，两端接 3V3 与 GND。为什么先用电位器：它能给出任意已知电压，等于给整套采样链路配了一把可对照的尺子，后面所有校验都靠它。

  2. 2② 开时钟、把引脚配成模拟模式

    ADC1 挂 APB2、DMA2 与 GPIOA 挂 AHB1；PA0 / PA1 设成 GPIO_MODE_ANALOG，断开数字输入缓冲。配成普通输入或复用会引入额外漏电与干扰，读数会莫名偏低或跳。

  3. 3③ 配 ADC 基础参数

    12 位、扫描、连续、软件触发、右对齐。F4 还要通过 ADC->CCR 的 ADCPRE 决定 ADC 时钟，别超过手册规定的上限——超了不是“算得慢”，而是结果不可信。

  4. 4④ 排序列与采样时间

    Rank 1 = 通道 0，Rank 2 = 通道 1；采样时间先给长档（如 84 个 ADC 周期这一档，编码见手册）。源阻抗越高，采样电容越充不满，读数会系统性偏低——长档就是给电容留时间。

  5. 5⑤ 配 DMA：外设固定、内存自增、半字宽、循环

    DMA2_Stream0 / Channel 0（ADC1 的请求映射，见参考手册），方向外设→内存，外设地址固定为 ADC1->DR，内存地址自增，两端半字宽，循环模式。长度填缓冲元素个数，不是字节数。

  6. 6⑥ 校准，然后启动

    先 HAL_ADCEx_Calibration_Start 补偿内部失调，再 HAL_ADC_Start_DMA。校准期间不要触发转换；省掉校准，输入接地也可能读到几十个码。

  7. 7⑦ 在回调里切“安全区”

    循环模式下缓冲一直被覆盖：半满回调里处理前半，全满回调里处理后半，这样你读的一半保证不是 DMA 正在写的一半。回调里只置标志，换算放主循环。

  8. 8⑧ 用万用表对照，再调参数

    把 mV 结果与万用表读数比对：整体偏低→采样时间或源阻抗；零点偏移→没校准；跳得厉害→参考电压/地不干净。用 adc-sampling 实验看“采样时间不足”的读数长什么样，比背结论直观。

参考电压/模拟地不干净，或拿开关电源的 3.3 V 当基准同一电压重复测差好几个码；电机一转、手一摸板子读数就变查 VDDA/VREF+ 的去耦电容与走线，模拟地与功率地单点连接；有独立 VREF+ 引脚就外接基准。先量参考电压本身稳不稳，再怀疑 ADC。
采样时间太短或源阻抗太高读数系统性偏低；换到下一个通道时，前一个通道的电压“残留”过来（串扰）按 t_s ≥ (R_AIN + R_ADC)·C_ADC·ln(2^(n+1)) 估算（示意），选更长档；源阻抗高就加运放缓冲或在输入端并小电容，别指望软件滤波救回来。
缓冲区长度不是通道数的整数倍大部分数据正常，但每半块交界处有几组数据明显串到另一路；改一下长度又“好了”让 BUF_LEN = 通道数 × 整数，半满/全满才落在通道边界上；再核对 Rank 顺序与数组下标是否一一对应。
多通道扫描却只读一次 DR，或没开 DMA两路读出来几乎一样，或拿到的总是最后一个通道的值扫描模式下所有通道都写同一个 DR，必须用 DMA（或每个 EOC 中断读一次）。用 DMA 时 CPU 不要再读 DR，否则和搬运抢结果。
输入电压超出 0 ~ VREF+ 范围读数饱和在 4095 或 0；输入接 12 V 或负压时芯片发热，甚至整片损坏先分压或运放衰减到量程内，再串限流电阻并加钳位；上电前用万用表逐路确认电压在范围内。ADC 的保护二极管只能兜底，不能当量程用。

第 1 / 5 步

LSB = Vref / 2^12 = 0.806 mV；输入范围 0–3.3 V。

步骤 1/5|① 采样：给采样电容充电

ADC 内部有一个采样保持电路：开关闭合，输入电压给采样电容充电。这个"充电"需要时间——源阻抗越大，需要的采样时间越长，否则采到的电压偏低。

第 1 / 6 步

地址自增只在内存侧开启；外设侧固定指向同一个数据寄存器（所以每次请求都读同一个地址）。

步骤 1/6|① 配置 DMA：源、目的、数量

CPU 只写几行配置：源地址（外设数据寄存器，如 USART1->DR）、目的地址（内存数组 buf）、传输数量 NDTR = 16、数据宽度 8 位、内存地址自增。配好后 单次模式，CPU 就可以去干别的了。
