h₁ = σ(x₁w + 0.4×0.5 − 0.2)；h₂ = σ(−0.8x₁ + 0.4w + 0.1)；p = σ(1.2h₁ − 0.7h₂ + 0.1)。σ(z)=1/(1+exp(−z))。

观察问题：把可调权重改成负数，两个隐藏节点的输出如何变化？

结论提示：每层都是加权组合与激活。偏置让模型能够平移响应；前向传播本身不会更新权重。

DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 普通 RNN 为什么难学长距离依赖？反向传播时具体发生了什么？

    按时间展开后，损失对早期状态的梯度要连乘一串雅可比矩阵，而每个时间步用的是同一个 W_h。若 W_h 的最大奇异值小于 1，连乘 T 次就指数衰减，早期输入的影响趋近于 0；大于 1 则指数放大，训练容易发散。所以问题不是“完全记不住”，而是有效记忆长度被这个系数的大小限制住了。边界：门控结构（LSTM、GRU）用加性通路缓解衰减，梯度裁剪只处理爆炸、不解决消失；任务依赖很短时普通 RNN 仍然够用。

  2. Transformer 训练能并行，是不是说明 RNN 已经没有使用价值了？

    不能这么推。Transformer 的并行主要体现在训练时一次处理整段序列，但自回归生成仍要逐 token 进行，而且全注意力对长度的交互成本是平方级。RNN 的递推在推理时只需保留一个隐藏状态、每步常数级内存，天然适合流式、低延迟、长序列或端侧场景，这也是状态空间模型等路线继续存在的原因。边界：序列较短、算力充足且需要长程依赖时，注意力通常更划算；RNN 的短板在训练难并行和长程梯度，而不在“完全不能用”。

手算小练习

为看清梯度消失，做一个线性简化：忽略激活函数和偏置，隐藏状态按 h_t = 0.5·h_(t−1) + x_t 更新，初值 h_0 = 0，输入序列 x_1 = 2、x_2 = 4、x_3 = 6。请算出 h_1、h_2、h_3，写出从 h_0 传到 h_3 的系数连乘结果，再把系数换成 2 对比一次。

展开分步答案
  1. h_1 = 0.5 × h_0 + x_1 = 0.5 × 0 + 2 = 2。
  2. h_2 = 0.5 × h_1 + x_2 = 0.5 × 2 + 4 = 5。
  3. h_3 = 0.5 × h_2 + x_3 = 0.5 × 5 + 6 = 8.5。
  4. 从 h_0 到 h_3 共跨 3 步，梯度要连乘 3 次系数：0.5³ = 0.125。
  5. 若系数换成 2，连乘结果是 2³ = 8，同样 3 步的距离梯度反而被放大 8 倍。

结论：h_1、h_2、h_3 依次为 2、5、8.5；系数 0.5 让远端影响 3 步后只剩 0.125（换成 2 则放大到 8），这就是梯度消失与爆炸的算术来源。

优点、限制与适用场景

优点

  • 天然表达时间顺序
  • 不同时间步共享参数

限制

  • 普通 RNN 难以学习长距离依赖
  • 时间步依赖限制部分并行能力

常见误区

  • 隐藏状态不是完整逐字存储
  • RNN 并非当前所有序列任务的最佳选择
