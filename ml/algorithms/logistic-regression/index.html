为什么重要，用在哪里？

INTERACTIVE EXPERIMENT

分类边界与阈值

步骤 0：固定模型 p = sigmoid(a(x+y−1))；已检查 0 个点。这里只改变阈值与得分函数，不执行训练。

观察问题：把阈值调高，预测为正类的区域会变大还是变小？

结论提示：阈值更高意味着更难判为正类。分类边界描述决策规则，不保证规则一定正确。

DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 把分类阈值从 0.5 调到 0.8，精确率和召回率通常会怎样变化？

    阈值提高后，只有概率更高的样本才被判为正类，通常精确率上升、召回率下降；但精确率并非每一步都单调上升，因为被新排除的样本里也可能有预测正确的正类。反过来，阈值降低会捞回更多正类，代价是更多误报。阈值没有唯一正确值，应按漏报和误报的业务成本在验证集上选，并报告对应的混淆矩阵。

  2. 逻辑回归输出 0.9，能不能直接理解成“有 90% 的概率是正类”？

    不一定。输出经过 sigmoid 函数压缩到 0 到 1，只有在模型形式、训练目标和数据分布都匹配时，才近似反映真实频率；正则化、类别不平衡或分布漂移都会让概率偏高或偏低。若只按排序选人，概率是否校准影响不大；若要用概率做成本计算，应在独立验证集上画校准曲线，必要时做 Platt 缩放或等渗回归校准，并说明校准也依赖代表性数据。

手算小练习

两个样本的真实标签为 1 和 0，模型给它们的正类概率分别是 0.8 和 0.3。取阈值 0.5，求准确率与平均对数损失（用 ln0.8≈−0.223、ln0.7≈−0.357）。

展开分步答案
  1. 阈值 0.5：0.8≥0.5 预测为 1，与标签一致；0.3<0.5 预测为 0，与标签一致。
  2. 因此准确率 = 2/2 = 1.0。
  3. 样本 1 的损失 = −ln0.8 ≈ 0.223；样本 2 的损失 = −ln(1−0.3) = −ln0.7 ≈ 0.357。
  4. 平均对数损失 = (0.223+0.357)/2 = 0.290。

结论：准确率 1.0，但平均对数损失约 0.290；两次硬分类都对了，概率仍不够自信。

极简示意代码

教学伪代码，仅示意输入、计算与输出；不在浏览器执行。

输入：特征 x，权重 w，偏置 b，阈值 t
z = w·x+b
p = 1/(1+exp(-z))
预测类别 = 1 若 p≥t，否则为 0

优点、限制与适用场景

优点

  • 简单高效，可输出概率
  • 便于解释线性决策边界

限制

  • 原始特征下边界为线性
  • 概率质量仍需用数据检查和校准

常见误区

  • 名字带回归但常用于分类
  • 阈值 0.5 不是所有任务的最佳选择

记住这三句话

  1. 先算得分，再算概率。
  2. 概率与最终类别是两件事。
  3. 阈值应服务于任务目标。
