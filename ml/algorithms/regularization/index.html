DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. L1 和 L2 都在压权重，为什么偏偏 L1 容易把权重压成 0？

    L2 的梯度是 2λw，权重越接近 0 推力也越小，所以它只会不断缩小、很难正好落到 0。L1 的梯度在 w>0 时恒为 λ、w<0 时恒为 −λ，离 0 越近推力并不减弱，绝对值小于步长尺度的小权重会被直接置零。几何上看，L1 的等高线是菱形、顶点落在坐标轴上，最优点更容易撞到“某些权重恰好为 0”的角上。边界：特征高度相关时，L1 会任意保留其中一个，选择不稳定；需要都保留时 L2 或弹性网更合适。

  2. 加了正则化后训练损失变高，怎么判断它是在帮忙还是拖后腿？

    训练损失变高本身是预期结果，因为优化目标里多了惩罚项，不能拿它当判据。要看验证集指标：验证误差下降说明约束压住了噪声；验证误差也升高，说明约束过强、开始欠拟合。做法是在一组 λ 上各跑一次，选验证表现最好的那个，最后用独立测试集确认。边界：验证集很小时，几种 λ 的差别可能落在波动范围内，这时应重复划分或改用交叉验证；如果验证集本身有泄漏，再漂亮的曲线也不可信。

手算小练习

某线性模型有两个候选权重 w = (3, 4) 与 w′ = (0, 5)，在训练集上的数据损失分别为 0.5 与 0.6，正则强度 λ = 0.1。请按 L2（加 λ‖w‖₂²）与 L1（加 λ‖w‖₁）分别算出两个候选的总目标，并判断两种正则各自会选谁。

展开分步答案
  1. w：‖w‖₂² = 3² + 4² = 9 + 16 = 25，L2 总目标 = 0.5 + 0.1 × 25 = 3.0。
  2. w′：‖w′‖₂² = 0² + 5² = 25，L2 总目标 = 0.6 + 0.1 × 25 = 3.1，于是 L2 选 w。
  3. w 的 L1：|3| + |4| = 7，总目标 = 0.5 + 0.1 × 7 = 1.2。
  4. w′ 的 L1：|0| + |5| = 5，总目标 = 0.6 + 0.1 × 5 = 1.1，于是 L1 改选 w′。
  5. 差别的原因：两者平方和同为 25，但 L1 对“两个中等权重”收 7、对“一个大权重”只收 5。

结论：L2 选 w = (3,4)，L1 选 w′ = (0,5)：绝对值之和对稀疏解更便宜，这就是 L1 偏向 0 权重的一步算术（只比较目标值，是教学简化）。

优点、限制与适用场景

优点

  • 可以改善噪声数据的泛化
  • 提供控制复杂度的手段

限制

  • 过强会导致欠拟合
  • 强度和形式需要结合模型选择

常见误区

  • 训练损失升高不一定是坏事
  • 正则化不能修复错误的数据划分

记住这三句话

  1. 训练好不等于泛化好。
  2. 正则化是在拟合与约束之间取舍。
  3. 强度需要用验证数据选择。
