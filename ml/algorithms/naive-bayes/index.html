DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 两个特征高度相关时，朴素贝叶斯会出什么问题？

    条件独立假设被破坏，同一份证据会被乘两次，分数被放大，后验变得过度自信。分类标签常常仍然正确，因为两个特征指向同一侧时，多乘一次只是让倾向更强，排序往往还行；但后验数值不可信，按成本选阈值会失准。失效条件是特征几乎重复且与类别强相关：重复计数会压过先验，类别不平衡时更容易翻错。缓解办法是合并或去掉冗余特征、做特征选择，或对输出做概率校准。

  2. 训练时某个词没出现过，为什么不能直接让概率为零？

    因为后验比较的是各类分数的乘积，某项为零会让整个后验归零，其它词的证据被一票否决，模型对含有这个词的新样本就再无判断力。常用加一平滑把估计改成（次数 + 1）/（总词数 + 词表大小），给未登录词留一个很小的正数。代价是词表很大时平滑质量被摊薄，罕见词的似然被系统性抬高。边界是：某个词在所有类别里都没出现时，它只是一个公共常数，不影响类别比较；推理时完全不在词表里的词通常直接忽略。

手算小练习

训练集共 10 封邮件：垃圾邮件 4 封、正常邮件 6 封，词表只有“免费、会议、报价”三个词。垃圾邮件里“免费”出现 3 次、“会议”1 次，共 6 个词；正常邮件里“免费”0 次、“会议”5 次，也共 6 个词。用加一平滑的朴素贝叶斯，判断一封同时含“免费”“会议”各一次的邮件属于哪一类。

展开分步答案
  1. 先验：P(垃圾) = 4/10 = 0.4，P(正常) = 6/10 = 0.6。
  2. 加一平滑：P(免费|垃圾) = (3+1)/(6+3) = 4/9，P(免费|正常) = (0+1)/(6+3) = 1/9。
  3. 同理 P(会议|垃圾) = (1+1)/9 = 2/9，P(会议|正常) = (5+1)/9 = 6/9。
  4. 垃圾得分 = 0.4 × 4/9 × 2/9 = 3.2/81 ≈ 0.0395；正常得分 = 0.6 × 1/9 × 6/9 = 3.6/81 ≈ 0.0444。
  5. 两类分母相同，直接比分子：3.6 > 3.2，判为正常邮件。

结论：判为正常邮件：3.6 对 3.2，归一化后后验约为 0.53 对 0.47，差距很小。

优点、限制与适用场景

优点

  • 训练和预测高效
  • 适合稀疏高维文本基线

限制

  • 条件独立假设可能不成立
  • 概率常需要校准

常见误区

  • 朴素不是假设特征无条件独立
  • 零频率不表示某事件绝不可能
