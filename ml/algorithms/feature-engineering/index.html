DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 为什么不能直接按“和标签的相关性”挑特征？

    相关性只刻画线性或单调关系，会漏掉非线性和特征之间的交互；更重要的是，在训练集上按相关性挑特征会引入选择偏差，让验证分数虚高。相关性也不等于因果：某个特征可能只是标签的结果（例如“是否已收到催收通知”），上线时根本拿不到。正确做法是把特征选择放进交叉验证内部，并检查每个特征在预测时刻是否真的可得。

  2. 标准化为什么必须放在交叉验证里面做？

    如果先用全量数据算均值和方差，再切分训练与验证，验证集的统计信息就泄漏进了训练过程，交叉验证分数会偏乐观，小样本或分布差异大时尤其明显。正确做法是把标准化写进处理流程，让每一折只用训练折拟合均值与方差，再作用到验证折。树模型对单调缩放不敏感，但线性模型、KNN、SVM 和神经网络都依赖尺度。

手算小练习

三个样本的特征值为 x = [1, 2, 3]，用总体标准差做 z-score 标准化。请算出 x=2 的标准化值，并说明另两个样本的结果。

展开分步答案
  1. 均值 = (1 + 2 + 3) / 3 = 2。
  2. 偏差平方和 = (1−2)² + 0² + (3−2)² = 2，方差 = 2/3 ≈ 0.667。
  3. 标准差 = √0.667 ≈ 0.816。
  4. 对 x=2：z = (2 − 2) / 0.816 ≈ 0.000。

结论：x=2 的标准化值约为 0（它正好等于均值）；x=1 约为 −1.225，x=3 约为 +1.225。

优点、限制与适用场景

优点

  • 可改善有效信息表达
  • 可让输入符合模型假设

限制

  • 错误构造可能泄漏目标
  • 类别、缺失和尺度变化需要维护

常见误区

  • 标准化不是所有模型的必选项
  • 预测时拿不到的信息不能作为合法特征
