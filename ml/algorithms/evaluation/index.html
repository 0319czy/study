DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 准确率 99% 的模型，能直接上线吗？

    不能，先看类别比例和两类错误的代价。若正例只占 1%，把所有样本都判成负类也能得到 99% 的准确率，但这样的模型没有任何检出能力。要同时看混淆矩阵、精确率、召回率、F1，以及按业务成本选阈值后的表现；不平衡严重时用 PR 曲线比 ROC 曲线更敏感。还要确认评估用的是时间切分或分组切分，而不是把训练数据当验证集。

  2. ROC-AUC 很高，但业务效果很差，可能是什么原因？

    AUC 衡量的是排序能力，不保证某个固定阈值下的精确率与召回率满足业务要求；类别极不平衡时，大量负样本会让 ROC-AUC 看起来仍然漂亮。也可能是阈值与成本不匹配，或者线上数据分布已经漂移，使得分分布整体偏移。还有一种常见问题是评估时对负样本做了采样，线上没有同样采样，导致概率校准失真。排查时应给出阈值—成本曲线，并做线上分桶对照。

手算小练习

某个二分类模型在 20 个样本上给出混淆矩阵：TP=7、FP=5、TN=5、FN=3。请算出准确率、精确率、召回率与 F1（保留三位小数）。

展开分步答案
  1. 先核对总数：7 + 5 + 5 + 3 = 20，与实际样本数一致。
  2. 准确率 = (TP + TN) / 总数 = (7 + 5) / 20 = 0.600。
  3. 精确率 = TP / (TP + FP) = 7 / (7 + 5) = 7/12 ≈ 0.583。
  4. 召回率 = TP / (TP + FN) = 7 / (7 + 3) = 0.700。
  5. F1 = 2×TP / (2×TP + FP + FN) = 14 / (14 + 5 + 3) = 14/22 ≈ 0.636。

结论：四项指标依次为 0.600、0.583、0.700、0.636；正类只有 10 个样本，所以准确率与召回率要分开看。

优点、限制与适用场景

优点

  • 让模型比较有统一依据
  • 把误报与漏报的差别显式化

限制

  • 单个指标无法反映全部成本
  • 不同测试分布的分数不能直接公平比较

常见误区

  • 准确率高未必适合稀有正类任务
  • ROC AUC 应使用连续得分，不能只看一个硬阈值
