DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 注意力打分里为什么要除以 √d_k？直接点积会出什么问题？

    点积是 d_k 项乘积之和。若 Q、K 的各分量近似独立、均值为 0、方差为 1，点积的方差就约为 d_k，维度越高得分的绝对值越大。得分一大，softmax 会饱和成接近 one-hot 的分布，梯度随之变得很小，训练不稳定。除以 √d_k 把方差拉回 1 量级，让不同维度下的“温度”大致一致。边界：这是基于独立同分布的粗略假设，输入已归一化或 d_k 很小时影响有限；它只控制数值尺度，不解决掩码错误、位置信息缺失等问题，也替代不了合适的学习率。

  2. 自注意力权重很高，就能说明模型是在看那个词吗？

    不一定。注意力权重只描述某一层某一次聚合时分配的比例，输出还要经过值投影、多头拼接、残差和后续前馈层，最终预测是所有层混合的结果；某位置权重高，也不代表把它去掉预测就不变。可靠的做法是做消融、遮挡或梯度归因，观察输出变化。边界：在某些浅层、单头的设置里，权重与证据确实相关，可以当线索用；但把它当因果解释、或据此判断模型“理解”了什么，属于过度解读。

手算小练习

单头自注意力，键维度 d_k = 4，因此缩放用 √d_k = 2。一个查询 q = [2,0,0,0]；两个键 k1 = [1,0,0,0]、k2 = [0,1,0,0]；对应值 v1 = [10,0]、v2 = [0,10]。请算出缩放后的两个得分、softmax 权重与最终输出向量（取 e ≈ 2.718）。

展开分步答案
  1. 点积 q·k1 = 2×1 = 2，q·k2 = 2×0 = 0；各自除以 √4 = 2 后，得分为 1 和 0。
  2. 取指数：e¹ ≈ 2.718、e⁰ = 1，两者之和为 2.718 + 1 = 3.718。
  3. softmax 权重：2.718 ÷ 3.718 ≈ 0.731，1 ÷ 3.718 ≈ 0.269，相加约等于 1。
  4. 输出 = 0.731 × [10,0] + 0.269 × [0,10] = [7.31, 2.69]。

结论：缩放得分是 1 与 0，权重约 0.731 与 0.269，输出约为 [7.31, 2.69]：与查询更匹配的 v1 被汇总得更多。

weights = 按行 softmax(scores)
context = weights×V

优点、限制与适用场景

优点

  • 内容相关的信息交互
  • 训练时许多位置运算可并行

限制

  • 标准全注意力随长度有平方级交互成本
  • 需要位置相关信息与合适的掩码

常见误区

  • 自注意力权重不等同于因果解释
  • 自回归生成仍逐 token 进行，不能把训练并行等同于生成全并行
