DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 如果房价数据里混进一套远高于其他样本的天价房，最小二乘拟合会受什么影响？

    平方损失会把大残差放大成平方，天价房会把拟合线明显拉向自己，其他样本的预测因此变差，这就是高杠杆点的影响。先判断它是录入错误还是真实极端值：录入错误应修正或删除；真实值且业务关心，可改用平均绝对误差或 Huber 损失（对极端残差更不敏感），或对目标做对数变换。直接删除会改变总体定义，必须记录理由。

  2. 两个特征高度相关时，线性回归的系数还能分别解释为各自的影响吗？

    不能直接这样解释。高度相关时，模型可以把同一份贡献在两者之间来回分配，系数数值和正负号都可能随样本小幅变化，但整体预测未必变差。若目标是解释，先看相关系数与方差膨胀因子，合并特征、删掉冗余项或加正则化，并报告联合效应；若只做预测且验证稳定，可以保留，但要说明单个系数不可单独解读。

手算小练习

给定三个样本 (x,y)=(1,2)、(2,4)、(3,5)，用最小二乘拟合直线 ŷ=wx+b。请写出 w、b、三个预测值和训练集 MSE。

展开分步答案
  1. 先算均值：x̄=(1+2+3)/3=2，ȳ=(2+4+5)/3=11/3≈3.667。
  2. 中心化后求斜率：Σ(x−x̄)(y−ȳ)=(−1)(−5/3)+0+(1)(4/3)=3，Σ(x−x̄)²=1+0+1=2，所以 w=3/2=1.5。
  3. 求截距：b=ȳ−w x̄=11/3−3=2/3≈0.667。
  4. 代入预测：x=1→13/6≈2.167，x=2→11/3≈3.667，x=3→31/6≈5.167。
  5. 残差为 −1/6、1/3、−1/6，MSE=(1/36+4/36+1/36)/3=1/18≈0.056。

结论：拟合线为 ŷ=1.5x+0.667，训练集 MSE=1/18≈0.056。

优点、限制与适用场景

优点

  • 计算高效，便于作为基线
  • 权重可帮助解释线性关联

限制

  • 难以直接表达复杂非线性
  • 异常值可能明显影响平方损失

常见误区

  • 线性关联不代表因果关系
  • 训练拟合好不能代替独立测试
