结论提示：距离目标随更多中心通常更容易变小；簇数仍需结合用途判断。固定初始化方便对比，真实任务常用多次初始化。

DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. KMeans 聚类每次结果都不一样，工程上怎么处理？

    先承认它给的是局部最优：多组随机初始化各跑一遍，保留簇内平方误差 J 最小的一组；初始化可用 k-means++，按距离加权抽中心，减少坏解。固定随机种子，方便复现和对比。边界是：多起点只是缓解，不保证全局最优；K 仍然要靠外部判断；数据量大时可在样本上估计中心或改用小批量（MiniBatch）版本，但别把抽样得到的中心直接当成全量结论。

  2. 簇内平方误差 J 更小的聚类，就一定更有用吗？

    不一定。J 随 K 增大单调不增，把 K 从 2 提到 10 几乎总能压得更低，所以跨 K 比较 J 没有意义；J 还会被量纲放大或缩小，换了缩放数值就不可比。J 变小也可能只是把一个真实簇劈成两半。判断有没有用要看任务：分组能否解释、换一批数据是否稳定、结论能否复现；必要时用轮廓系数等指标辅助，但最终仍要回到业务口径上验证。

手算小练习

8 个二维点：(0,0)、(2,0)、(0,2)、(2,2)、(8,8)、(10,8)、(8,10)、(10,10)。KMeans 取 K=2，初始中心 μ1=(0,0)、μ2=(10,10)。请完成一轮“分配—更新”，写出新中心与这一轮的簇内平方误差 J。

展开分步答案
  1. 算初始距离：前四点离 μ1 的平方距离是 0、4、4、8，离 μ2 是 200、164、164、128，都归簇 1。
  2. 后四点离 μ1 是 128、164、164、200，离 μ2 是 8、4、4、0，都归簇 2。
  3. 更新中心：μ1 = ((0+2+0+2)/4, (0+0+2+2)/4) = (1,1)；μ2 = ((8+10+8+10)/4, (8+8+10+10)/4) = (9,9)。
  4. 算 J：每个点到本簇中心的平方距离都是 2，共 8 个点，J = 8 × 2 = 16。
  5. 用新中心重新分配：前四点距 (1,1) 为 2，距 (9,9) 至少 98；后四点反之，分组不变，算法收敛。

结论：一轮后中心变为 (1,1) 与 (9,9)，簇内平方误差 J = 16；再分配一次分组不再变化，中心保持不动。

优点、限制与适用场景

优点

  • 原理简单，速度通常较快
  • 中心便于概括分组

限制

  • 需要先选 K，对尺度与初始化敏感
  • 不擅长非球状或密度差异大的簇

常见误区

  • 簇编号没有天然业务含义
  • 更低的簇内误差不一定更有业务价值
