DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 做主成分分析（PCA）之前要不要标准化？判断依据是什么？

    看量纲和方差的含义。PCA 最大化投影方差，若一个特征以“元”为单位、数值动辄上万，另一个是“个数”，前者方差压倒性更大，第一主成分基本只反映它，其它特征被动忽略；量纲不同时必须标准化或先统一单位。若各维量纲相同、方差本身有业务含义，保留原始尺度更合理。反过来的陷阱是：各维噪声水平差异大时，标准化会放大噪声维，所以缩放方式要结合测量可靠性决定，不能默认打开。

  2. 保留 95% 方差之后，还需要检查什么？

    95% 只是启发式阈值，方差大不等于对预测有用，区分类别的方向可能恰好方差小，压掉它会让下游指标变差。要比较保留不同主成分数时验证集上的任务表现，而不是只看方差占比。另外 PCA 的均值和方向只能在训练集上拟合，否则验证信息会泄漏。边界是：高维稀疏数据里 95% 可能要几百维，压不动；有明显非线性结构时，线性投影本身就不合适。

手算小练习

两个特征已中心化、量纲相同，协方差矩阵为 [[2,1],[1,2]]。请算出它的两个特征值、各自解释的方差占比，并判断只保留第一主成分会损失多少信息。

展开分步答案
  1. 列特征方程：det([[2−λ,1],[1,2−λ]]) = (2−λ)² − 1 = 0。
  2. 解得 λ1 = 3、λ2 = 1；可用迹 2+2 = 4 与行列式 2×2 − 1×1 = 3 核对。
  3. 总方差等于迹 4，第一主成分占比 3/4 = 75%，第二主成分 1/4 = 25%。
  4. 只保留第一主成分，等于丢掉 25% 的方差。
  5. 方向核对：λ = 3 时 (2−3)a + b = 0 得 b = a，第一主成分沿 (1,1)，单位化后为 (1/√2, 1/√2)。

结论：特征值为 3 与 1，第一主成分保留 75% 的方差，只留一维会损失 25% 的信息。

优点、限制与适用场景

优点

  • 可压缩相关数值特征
  • 输出方向正交

限制

  • 方差大不代表最有预测价值
  • 线性投影可能丢失非线性结构

常见误区

  • PCA 不使用类别标签
  • 降到二维不保证保留全部信息
