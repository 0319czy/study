DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 训练数据里缺少某些群体，会发生什么？

    模型在这些群体上见到的样本少，预测误差更大，也更可能把与群体相关的无关特征当成捷径，表现为某些群体的召回明显更低。如果模型参与资源分配或风控，这种差异会被放大成实际伤害。补救不只是加样本量：还要检查采样方式、标签来源的标注偏差、评估时是否按群体分报告结果。有时正确的结论是“这个决定不该交给模型”。

  2. 把敏感属性从特征里删掉，模型就公平了吗？

    不一定。邮编、消费记录、设备型号这类代理变量可以间接恢复敏感属性，所谓“公平丢弃”常常无效。而且公平有多种互不兼容的定义：群体均等、机会均等、个体公平，满足其中一个往往牺牲另一个。更可行的流程是先明确这个决定要保护谁、用什么指标衡量伤害，再做取舍，并保留申诉与人工复核的通道。

手算小练习

两个群体的贷款拒绝数据：A 组 800 人中有 40 人被误拒，B 组 200 人中有 20 人被误拒。请算出两组误拒率、相对差异，并说明整体误拒率会掩盖什么。

展开分步答案
  1. A 组误拒率 = 40 / 800 = 5%。
  2. B 组误拒率 = 20 / 200 = 10%。
  3. 绝对差异 = 10% − 5% = 5 个百分点；相对差异 = 10% / 5% = 2 倍。
  4. 整体误拒率 = (40 + 20) / (800 + 200) = 60 / 1000 = 6%。

结论：A 组 5%、B 组 10%，B 组被误拒的概率是 A 组的两倍；只看整体 6% 会把这一差异掩盖掉。

优点、限制与适用场景

优点

  • 及早发现不均衡影响
  • 让使用边界与责任更清楚

限制

  • 不同公平目标可能冲突
  • 小群体估计可能很不稳定

常见误区

  • 删去敏感字段不保证消除代理偏差
  • 一个公平指标相等不等于全面公平
