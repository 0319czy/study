再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 随机森林的袋外估计为什么能当验证集用？前提是什么？

    每棵树用有放回抽样训练，一个样本约有 36.8% 的概率不被某棵树抽中；对所有未包含该样本的树做预测并汇总，就得到它的袋外预测，相当于免费的交叉验证。前提是样本近似独立同分布、预处理没有在划分前泄漏，并且树的数量足够多。时间序列、同一用户多条记录等分组数据会破坏独立性，袋外估计可能过于乐观；数据很少时它也会很吵，仍应保留独立测试集。

  2. 树的数量从 100 增加到 1000，验证误差为什么不一定继续下降？

    增加树主要降低方差，但树之间并不独立：它们共享同一批数据和特征，相关性会让方差有一个下界，不能靠无限加树消除。验证误差还会受单棵树的深度、每次分裂的特征子集和噪声影响，这些属于偏差或数据本身的问题。实际做法是观察袋外误差或验证曲线，在趋于平台后停止；继续加树通常只会增加训练和推理成本，收益很小。

手算小练习

自助采样从 4 个样本中有放回抽 4 次。对某个固定样本，求它一次都没被抽中的概率，并估计 4 个样本中平均有多少个成为袋外样本。

展开分步答案
  1. 一次抽取不命中该样本的概率 = 1−1/4 = 3/4。
  2. 4 次都不命中 = (3/4)^4 = 81/256 ≈ 0.316。
  3. 所以每个样本成为袋外样本的概率约 31.6%。
  4. 4 个样本的袋外数期望 = 4×81/256 = 324/256 ≈ 1.27。

结论：该样本袋外概率约 31.6%，4 个样本平均约 1.27 个袋外。

优点、限制与适用场景

优点

  • 通常比单棵树更稳定
  • 能够捕捉非线性与交互

限制

  • 模型体积和推理成本更高
  • 整体解释比浅树困难

常见误区

  • 树越多不意味着效果无限提高
  • 特征重要性不等同于因果影响
