查看本实验的精确计算规则

h₁ = σ(x₁w + 0.4×0.5 − 0.2)；h₂ = σ(−0.8x₁ + 0.4w + 0.1)；p = σ(1.2h₁ − 0.7h₂ + 0.1)。σ(z)=1/(1+exp(−z))。

步骤 0：准备输入 x₁ 和固定输入 x₂ = 0.4。

观察问题：把可调权重改成负数，两个隐藏节点的输出如何变化？

结论提示：每层都是加权组合与激活。偏置让模型能够平移响应；前向传播本身不会更新权重。

DEEPER QUESTIONS

再来一问与手算练习

这些追问没有背诵答案：先给结论，再讲清为什么与适用边界；算完请对照分步过程。

  1. 训练损失一直降，验证损失却回升，你先查什么？

    先查切分和泄漏：验证集是否被用来调参、特征里是否混进了预测时刻拿不到的信息、样本是否按时间或用户分组切分。这比直接加正则更优先，因为泄漏会让验证曲线失真。确认是过拟合后，再按代价从低到高处理：早停、权重衰减或随机丢弃（dropout）、减小模型、补充数据。边界是：若训练损失本身也很高，那是欠拟合，应加容量或调学习率；验证集太小时曲线会抖，不能凭一次回升就下结论。

  2. 为什么隐藏层权重不能全部初始化为 0？

    因为对称性。同一层隐藏单元若权重全为 0，输入、输出和梯度完全一样，更新后仍然一样，等于只训练了一个神经元，宽度白加了。随机初始化负责打破这种对称，Xavier、He 这类做法只是按扇入扇出定好随机尺度。偏置可以初始化为 0，输出层权重在很多结构里也可以。边界是：初始尺度过大会让激活饱和或梯度爆炸，过小会让信号逐层衰减，网络越深越敏感。

手算小练习

单样本输入 x=1、目标 y=3。网络为 h = ReLU(w1·x + b1)（ReLU 把负数截成 0）、ŷ = w2·h + b2，当前 w1=2、b1=−1、w2=1、b2=0，损失 L = (ŷ − y)²，学习率 0.1。请做一次前向、求 w1 与 w2 的梯度、更新参数，再算新的损失。

展开分步答案
  1. 前向：z1 = 2×1 − 1 = 1，ReLU 后 h = 1；ŷ = 1×1 + 0 = 1。
  2. 损失：L = (1 − 3)² = 4；对输出的偏导 ∂L/∂ŷ = 2 × (1 − 3) = −4。
  3. 梯度：∂L/∂w2 = −4 × h = −4；z1 = 1 > 0 时 ReLU 导数为 1，所以 ∂L/∂w1 = −4 × w2 × 1 × x = −4。
  4. 更新：w1 = 2 − 0.1 × (−4) = 2.4，w2 = 1 − 0.1 × (−4) = 1.4。
  5. 重新前向：z1 = 2.4 − 1 = 1.4，h = 1.4，ŷ = 1.4 × 1.4 = 1.96，L = (1.96 − 3)² ≈ 1.08。

结论：一步更新后 w1 = 2.4、w2 = 1.4，预测从 1 变为 1.96，损失从 4 降到约 1.08。

优点、限制与适用场景

优点

  • 能学习复杂非线性
  • 可组合出适合不同数据的结构

限制

  • 常需要较多数据和调参
  • 解释与稳定训练可能较难

常见误区

  • 网络不是越深越好
  • 前向传播与训练参数更新不是一回事
