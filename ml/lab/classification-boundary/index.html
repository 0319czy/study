INTERACTIVE EXPERIMENT

分类边界与阈值

步骤 0：固定模型 p = sigmoid(a(x+y−1))；已检查 0 个点。这里只改变阈值与得分函数，不执行训练。

观察问题：把阈值调高，预测为正类的区域会变大还是变小？

结论提示：阈值更高意味着更难判为正类。分类边界描述决策规则，不保证规则一定正确。
