METRICS / 分类与回归

评估指标

同一个模型，换个阈值指标就会变；同一个回归误差，换个口径也会变。本页所有数字都由本地固定样本实时计算，不是预先编好的结果。 打个比方：阈值像报警器的灵敏度，调得越敏感越容易报警，误报和漏报此消彼长；ROC 记录的就是把所有灵敏度都试一遍之后的结果。

学习目标

能读懂混淆矩阵，并说清精确率、召回率、F1 各自关注什么代价。

能解释 ROC 曲线为什么要扫很多阈值，以及 AUC 为什么与阈值无关。

能说清多分类（multi-class）里 macro 与 micro 平均的差别，以及 micro-F1 为什么等于 accuracy。

能亲手把 R² 调成负数，并说明它和 MSE、MAE 的区别。

RANKING

ROC 与 AUC：曲线来自真实阈值扫描

横轴 FPR 是「实际负类中被误报为正」的比例，纵轴 TPR 是「实际正类中被找出来」的比例。 曲线由全部不同得分逐个当作阈值后连成，而不是拿一个硬分类点冒充。

AUC = 0.725（梯形积分）；扫描点 20 个，不同得分 19 个，并列得分 1 组、涉及 2 个样本。

把滑块从 0.9 拖到 0.2，精确率与召回率会变，但 ROC 曲线和 AUC 不变：它们描述的是整条排序，而不是某个阈值。 并列得分无法被任何阈值拆开，本页把它们合并到同一步；AUC 的成对比较口径把并列记半分（当前成对口径 0.725，与梯形积分一致）。

REGRESSION

回归指标：MSE、MAE 与可以为负的 R²

12 个本地合成点近似在一条直线上。拖动斜率和截距改变预测线，再拖动异常点偏移，观察误差怎样被放大； MSE 对平方敏感，MAE 与目标同单位，R² 则相对「始终预测均值」这条基线。

合成数据：目标约为 0.12 + 0.68x 再加一点固定波动，只用于演示计算，不代表任何真实业务。

预测线 ŷ = 0.70x + 0.15；MSE = 0.002，MAE = 0.037， R² = 0.96；实际目标均值 0.463。

R² 可以为负：它的定义是 1 − 残差平方和 / 目标平方和，分母来自目标本身。当预测比「始终预测均值」还差时， 比例大于 1，R² 就小于 0。负 R² 不是程序错误，而是模型连均值基线都没超过。

均方误差（Mean Squared Error）：误差先平方再平均，大误差被放大，单位是目标的平方。

记住这三句话

  1. 阈值不是固定的：移动阈值会改变精确率、召回率与 F1，但不会改变 ROC 曲线与 AUC。
  2. ROC 必须用连续得分扫多个阈值；得分并列时只能合并处理，AUC 把并列记半分。
  3. R² 可以为负；异常点会同时抬高 MSE 与 MAE，但平方项对它的惩罚更重。
