电路与 PCB 设计:从原理图到可打样

这个方向要交付的不是"一张能布通的板",而是一条可复核的链路:需求与功耗预算 → 原理图与 ERC → 封装/BOM → 布局 → 布线 → DRC 零违规 → Gerber/BOM/坐标 → 打样回板测试。本页用载流计算器把"线宽"从经验数字 变成可计算、可验收的尺寸,并给出一块 STM32 传感器小板的完整方向项目。

3. 原理与图示

3.1 线宽不是审美:载流、温升与压降

电流通过铜线会发热,允许温升 ΔT 决定最小截面积;截面积再除以铜厚得到线宽。长度不改变"最小载流线宽", 但会通过电阻影响压降与功耗——所以"能载流"和"压降合格"是两道独立检查。

IPC-2221 常用的经验式(宽度单位 mil,面积单位 mil²):

A[mil²] = ( I[A] / ( k · ΔT[℃]^0.44 ) ) ^ (1 / 0.725)
W[mil]  = A / ( 1.378 × 铜厚[oz] )          // 1 oz = 1.378 mil = 35 µm
W[mm]   = W[mil] × 0.0254
k = 0.048(外层) / 0.024(内层)

电阻与压降(用于第二道检查):
R = ρ(T) · L / (W · t),  ρ(25℃) ≈ 1.72×10⁻⁸ Ω·m, 温度系数 ≈ 0.0039/℃
Vdrop = I · R,  P = I² · R,  压降预算常取电源电压的 3%

注意:ΔT 是"允许的铜温升",不是室温;R 里的温度用环境温度 + ΔT 估算。工程推荐线宽还应叠加余量, 并满足"电源 ≥0.4mm、信号 ≥0.15mm"的本机验收下限。

3.2 布局决定布线:先分区,再放关键器件

原则具体做法验收信号
模块化分区电源区、数字区、接口区物理分开,区间留 ≥3mm 隔离带;模拟/数字尤其要分开。能一眼指出每个功能区;电源环路不穿数字区。
先结构后功能先放螺丝孔、连接器、板边接口;M3 螺丝孔 4mm 内不放元件。连接器不悬空、不越板边;禁布区为空。
主 IC 在枢纽按飞线流向放主控,给晶振/去耦/下载口留空间。关键网络短、少交叉;晶振靠近 MCU。
去耦紧贴引脚100nF 距 IC 电源脚 <5mm,就近打地过孔;大电容在电源入口。每个电源脚都有本地去耦;地回路短。
晶振包地晶振靠近 MCU,远离发热/大电流;周围铺地并打过孔。晶振下方无数字走线;负载电容靠近。
接口保护靠边USB/排针靠板边;ESD/TVS 在干扰进板前;CC 电阻按 Type-C 规范。插拔应力不直接传到芯片;保护器件在接口与芯片之间。

3.3 布线规则:把"能布通"变成"可验收"

规则本机验收口径为什么
拐角只允许 135° 钝角;用两段 45° 折线,禁止 90°/锐角/任意角。减少阻抗突变与酸角蚀刻问题,便于目视检查。
等宽同一网络全程等宽;差分对内间距恒定。避免载流瓶颈与阻抗不连续。
间距普通信号 ≥0.15mm;高速/时钟/差分对按 3W(中心距 ≥3×线宽)。抑制串扰;给板厂留蚀刻余量。
过孔外径 0.3mm / 钻孔 0.15mm;普通信号每段 ≤2 个,高速/时钟 ≤1 个。兼顾载流、工艺与阻抗连续性。
电源顺序先电源、再信号、最后 GND 铺铜;关键时钟/差分先手布。电源路径决定回流;铺铜放最后避免反复重布。
板边/焊盘走线到板边 ≥0.3mm;到非同网络焊盘/过孔 ≥0.15mm。铣边公差与焊接桥连风险。
这些是"本机项目的验收口径",不是所有板厂/所有产品的唯一标准。高电压、射频、高速总线要按相应标准重新定规则; 但"先定规则、再布线、最后用 DRC 证明"的顺序不变。

3.4 从原理图到打样的闭环

需求/功耗预算 → 原理图 + ERC → 封装/BOM 核对 → 布局(分区/去耦/晶振/接口)
      → 布线(电源 → 信号 → GND 铺铜) → DRC 0 违规 → Gerber/BOM/坐标 → 打样
      → 回板目视/短路/上电/下载/功能/温升 → 验收或复盘

任何一步发现问题,回到上一步修,而不是"先打样再说"。DRC 0 是必要条件,不是充分条件。

3.5 gcc 核算证据 compiled

下面的 C 程序按 3.1 的公式生成线宽表并检查压降。它在本机用 gcc 13.3.0 -O2 -Wall -Wextra -std=c11 编译,0 warning,输出原样贴出。 计算器采用同一组常数,所以 1A / 1oz / 10℃ / 外层应复现 0.300mm。

展开 trace_width.c 源码(与上面输出逐行对应) 
#include <stdio.h>
#include <math.h>

#define OZ_MIL 1.378
#define RHO20  1.72e-8
#define ALPHA  0.0039

static double area_mil2(double amps, double dT, int internal)
{
    double k = internal ? 0.024 : 0.048;
    return pow(amps / (k * pow(dT, 0.44)), 1.0 / 0.725);
}

static double width_mm(double area, double oz)
{
    return area / (OZ_MIL * oz) * 0.0254;
}

static double resistance_ohm(double width, double oz, double len_mm, double temp_c)
{
    double t_m = oz * 35e-6;
    double w_m = width * 1e-3;
    double l_m = len_mm * 1e-3;
    double rho = RHO20 * (1.0 + ALPHA * (temp_c - 20.0));
    return rho * l_m / (w_m * t_m);
}

int main(void)
{
    const double currents[] = {0.5, 1.0, 2.0, 3.0};
    const double rises[] = {10.0, 20.0, 30.0};
    int i, j;

    printf("IPC-2221 width check | external k=0.048, 1 oz, dT=10 C\n");
    printf("%-6s %-10s %-10s %-10s\n", "I(A)", "A(mil2)", "W(mil)", "W(mm)");
    for (i = 0; i < 4; i++) {
        double a = area_mil2(currents[i], 10.0, 0);
        double w = width_mm(a, 1.0);
        printf("%-6.1f %-10.2f %-10.2f %-10.3f\n", currents[i], a, w / 0.0254, w);
    }

    printf("\ninternal vs external | I=1 A, 1 oz, dT=10 C\n");
    for (i = 0; i < 2; i++) {
        double a = area_mil2(1.0, 10.0, i);
        double w = width_mm(a, 1.0);
        printf("%-9s A=%6.2f mil2  W=%.3f mm\n", i ? "internal" : "external", a, w);
    }

    printf("\ncopper thickness | I=1 A, dT=10 C, external\n");
    {
        const double oz[] = {0.5, 1.0, 2.0};
        for (i = 0; i < 3; i++) {
            double w = width_mm(area_mil2(1.0, 10.0, 0), oz[i]);
            printf("%-4.1f oz -> W=%.3f mm\n", oz[i], w);
        }
    }

    printf("\nrise budget | I=2 A, 1 oz, external\n");
    for (j = 0; j < 3; j++) {
        double w = width_mm(area_mil2(2.0, rises[j], 0), 1.0);
        printf("dT=%2.0f C -> W=%.3f mm\n", rises[j], w);
    }

    printf("\nvoltage drop | 1 A, 1 oz, 20 mm trace, 25 C\n");
    {
        const double widths[] = {0.20, 0.30, 0.40};
        for (i = 0; i < 3; i++) {
            double r = resistance_ohm(widths[i], 1.0, 20.0, 25.0);
            printf("W=%.2f mm -> R=%6.2f mOhm  Vdrop=%6.2f mV  P=%6.2f mW\n",
                   widths[i], r * 1e3, r * 1.0 * 1e3, r * 1e3);
        }
    }
    printf("\nexpected: 1 A / 1 oz / 10 C external ~= 0.30 mm\n");
    return 0;
}

编译运行时间:2026-11-27;主机:x86_64 Linux;gcc 13.3.0。这里的"compiled"只证明公式实现与数值一致, 不证明你的板子在真实散热条件下一定不超过 ΔT。

推荐值 = max(1.5 × IPC 最小线宽, I≥1A 时 0.4mm, 否则 0.15mm),向上取 0.05mm。 这是本项目口径,不是 IPC 强制值;高可靠/高温场景应继续加余量或改铺铜。

做三个小实验并记录数字: ① 1A / 1oz / 10℃ / 外层,读 IPC 最小线宽,应约 0.300mm,与 3.5 的 compiled 输出一致; ② 只把层切成内层,线宽应约 0.781mm,解释 k 的变化; ③ 固定 2A / 1oz / 外层,把 ΔT 从 10℃ 调到 30℃,线宽应从约 0.781mm 降到约 0.401mm。 再试 3A / 1oz / 外层 / 200mm / 5V,观察压降占比是否超过 3% 预算。
