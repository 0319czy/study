DIRECTIONS · 阶段 07

方向进阶:四个方向,按项目需要选

完成采集监控项目后,按兴趣或项目需要选方向。每个方向都有:一个可执行项目、验证材料清单和交付要求; 内容按 8 段组织,证据标识真实(principle / compiled / hardware-pending)。

01

嵌入式 Linux 系统构建

已上线
交叉编译工具链、Buildroot 配置、内核与根文件系统、镜像烧录、启动日志分析。项目:构建最小 rootfs + 交叉编译设备程序 + 烧录跑通。
前置:Linux 用户态证据:compiled + hardware-pending交付:镜像 + 构建脚本 + 启动日志
进入方向 → 深入:Buildroot 与启动 补 Linux 用户态
02

ROS 2 机器人应用

已上线
节点、话题、服务、TF、导航。项目:让一个节点发布传感器数据、另一个节点订阅并做 TF 变换,用 RViz/命令行验证。
前置:C 与 Linux证据:compiled + hardware-pending交付:包源码 + launch + 运行记录
进入方向 → ROS 实验室
03

电路与 PCB 设计

已上线
原理图、封装、布局、布线、DRC、打样与焊接验证。项目:从原理图到打样的完整流程,DRC 零违规,焊接后上电检查。
前置:数字电路证据:principle + compiled + hardware-pending交付:工程文件 + DRC 报告 + 实物照片
进入方向 → 补数字电路
04

边缘 AI 模型部署

已上线
模型量化(FP32→INT8)、内存/延迟/精度权衡、推理框架选型、部署到 MCU 或 Linux 板卡。项目:把一个小模型量化部署,给出精度/延迟/内存三张对照表。
前置:机器学习 + MCU证据:compiled + hardware-pending交付:模型 + 推理程序 + 三张对照表
进入方向 → 补机器学习
