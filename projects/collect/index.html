M0 采集:能读到数据,并解释它

多传感器采集与监控系统的第一阶段。目标不是"读出一个数",而是能说清楚:这个数的单位是什么、 多久采一次、误差从哪来。完成 M0 才进入 M1 通信。

前置课程:C 与工程工具 · 数字电路入门 · Linux 用户态入门

3. 原理与接线

ADC 把电压转成数字码:code = round(Vin / Vref × (2^N − 1)),反算 Vin = code × Vref / (2^N − 1)。

参数取值(以 STM32F103 为例)说明
分辨率 N12 位量化台阶 Vref/4095
参考电压 Vref3.3 V决定量程与误差
采样周期10 ms(100 Hz)与任务周期一致,避免抖动
传感器分压Vout = Vin × R2/(R1+R2)注意阻抗匹配,ADC 输入阻抗有限
接线(无板模式跳过;有板模式按下表):
STM32F103 3V3  → 传感器 VCC
STM32F103 GND  → 传感器 GND
PA0 (ADC1_IN0) → 传感器信号输出
注意:先共地,再上电;3.3V 传感器不要接 5V。

5. 代码骨架(STM32 HAL,principle)

uint32_t adc_read(uint32_t ch)
{
    ADC_ChannelConfTypeDef sConfig = {0};
    sConfig.Channel = ch;
    sConfig.Rank = ADC_REGULAR_RANK_1;
    sConfig.SamplingTime = ADC_SAMPLETIME_55CYCLES_5;
    HAL_ADC_ConfigChannel(&hadc1, &sConfig);
    HAL_ADC_Start(&hadc1);
    HAL_ADC_PollForConversion(&hadc1, 10);
    uint32_t code = HAL_ADC_GetValue(&hadc1);
    HAL_ADC_Stop(&hadc1);
    return code;
}

float to_voltage(uint32_t code)
{
    return (float)code * 3.3f / 4095.0f;
}

说明:此骨架为标准 HAL 调用模式,属 principle;需你在 STM32CubeMX 工程中编译(`hardware-pending` 实物验证)。

7. 故障排查

现象检查步骤预期结果下一分支
读数一直是 0查 GND 是否共地、PA0 是否配置为模拟输入GND 连通、PA0 = Analog仍为 0 → 查 CubeMX ADC 时钟与通道
读数满量程(4095)测传感器输出是否超过 3.3VVout ≤ 3.3V超压 → 加分压或换 3.3V 传感器
读数跳动 ±20查电源纹波、是否靠近电机/继电器纹波 < 10 mV加滤波电容/软件中值滤波
换算后物理量不对核对 Vref 是否为实测值、分压比取值公式与实测吻合用万用表实测 Vref 后重算
