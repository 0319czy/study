第一条路线:多传感器采集与监控系统

从传感器到网页仪表盘的完整链路:传感器 → STM32 HAL → FreeRTOS → 串口通信 → Linux 网关 → 数据存储 → 网页仪表盘。分阶段增加能力,每一步都有可检查的结果。

阶段与验收

阶段能力可检查结果状态
M0 采集能读到传感器数据解释单位、采样周期、误差已上线 →
M1 通信串口协议跑通协议说明 + 错误帧/超时识别已上线 →
M2 多任务采集/通信/显示互不阻塞运行时序可观测(任务周期、优先级)已上线 →
M3 网关Linux 端接收与存储能记录、查询设备数据已上线 →
M4 展示网页仪表盘实时值、历史曲线、设备状态已上线 →
M5 交付完整交付物接线图、源码、运行步骤、测试记录、故障排查表已上线 →

M0–M5 页面均已上线,可按顺序学习并在每页完成结果检查。学习档案、全站深链预渲染、sitemap、搜索分片已交付; M3 的 API 客户端适配已就绪(真实网关待接);实物验证保持 hardware-pending。
