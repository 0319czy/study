M4 展示:网页仪表盘

目标:把设备数据变成能看的东西——实时值、历史曲线、设备状态。数据链路: 设备 → M1 协议帧 → M3 网关存储 → 查询接口 → 本页仪表盘。本页用内置样例数据模拟整条链路,并支持粘贴 M3 导出的 CSV。

3. 原理与图示

刷新率(页面多久取一次数)和采样率(设备多久采一次)是两件事:采样率决定数据密度,刷新率决定视觉流畅度;刷新率高于采样率时只是在重复显示同一批数据。

设备采样 10ms → 网关聚合/存储 → 查询接口(如 /api/latest?limit=60)
                                      ↓
页面每 1s 拉一次最新值 → 实时卡片 + 历史曲线 + 状态灯

状态判定(示例):
  在线: 最近心跳距今 < 500ms(与 M1 超时一致)
  告警: 温度 > 阈值(默认 28℃)且连续 3 个采样点
  离线: 最近心跳距今 ≥ 500ms 或 M3 记录断档

告警"连续 N 点"是为了避免单点噪声抖动;断线用 M1 的 500ms 心跳超时,不用"页面多久没刷新"判断。
