数字电路入门:从电平和按键到 ADC 采样

目标

schema: goalObjectives · 可验证动词

学完这一课,你应该能独立完成下面这些事(都能在下文找到对应讲解与练习):

  • 读懂接线图:看到一张按键或传感器接线图,能指出 VDD、GND、信号节点、上拉或下拉电阻,并判断按键按下时引脚是高还是低。
  • 判断电平兼容:对照数据手册,判断 3.3V 与 5V 器件能否直连;说出 TTL / CMOS 门限差异、绝对最大额定值风险,以及电平转换、电阻分压、5V 容忍引脚三种处理方式。
  • 解释浮空与选电阻:说明"浮空输入"为什么会误触发,并为按键/开关选择 4.7kΩ–10kΩ 级别的上拉或下拉,算出按下时的电流与功耗。
  • 估算去抖:用 τ = R·C 估算 RC 去抖的延迟与稳定时间,说出硬件 RC 与软件消抖各自的适用场景和代价。
  • 算 ADC 误差:由位数 n 与参考电压 Vref 算出 LSB 与量化误差,判断 ±1～3 LSB 的读数跳动是否正常。
  • 用仪器:用万用表和示波器完成 4 个基本测量(直流电压、通断、按键波形、ADC 输入),并说出至少 3 个"测不准"的常见原因。
课程边界:本课不涉及 PCB 布局、EMC 整改、模拟滤波器设计细节。文中门限、抖动时间、ADC 参数多为教材 / 数据手册典型值, 具体设计必须回归你手上那颗器件的数据手册。

3.1 数字输入只认两个区间:低电平与高电平 principle

数字芯片内部把电压"翻译"成 0/1,但翻译不是理想的开关。每个输入都有两个门限: VIL(输入低电平最大电压)与 VIH(输入高电平最小电压)。 低于 VIL 稳定判为 0,高于 VIH 稳定判为 1,两者之间是不确定区——不能依赖。

标准 / 器件族供电VIL 最大VIH 最小VOL 最大VOH 最小说明
5V TTL(74LS 系列)5V0.8V2.0V0.4V2.4V门限基本不随 VDD 比例变化,历史标准
5V CMOS(74HC 系列)5V1.5V(0.3 VDD)3.5V(0.7 VDD)≈0.1V≈4.9V门限按 VDD 比例,输入几乎不吃电流
3.3V LVTTL(多数 MCU 引脚)3.3V0.8V2.0V0.4V2.4V很多 MCU 按 TTL 门限设计,以手册为准
3.3V CMOS(74LVC 等)3.3V≈0.99V(0.3 VDD)≈2.31V(0.7 VDD)——输入结构是 CMOS;部分 MCU 引脚也用 0.7 VDD 门限

表中是常见典型值,目的是建立直觉,不是选型依据。同一个器件的输入门限(VIL/VIH)和输出保证(VOL/VOH)也不对称; 设计时要同时满足"输出高 ≥ 对方 VIH"和"输出低 ≤ 对方 VIL",并留噪声余量。

把门限用到接线:3.3V 与 5V 互连

  • 3.3V 推挽输出 → 5V TTL 输入:3.3V > VIH 2.0V,通常能识别高电平;但仍要评估驱动能力、线长与边沿,不能只看门限。
  • 3.3V 输出 → 5V CMOS 输入:3.3V < VIH 3.5V,高电平不可靠,必须电平转换。
  • 5V 输出 → 3.3V 输入:先看绝对最大额定值,不是 VIH。多数 3.3V 引脚只能承受 VDD + 0.3V;只有 datasheet 明确标注 5V 容忍(如 STM32 的 FT 引脚)时才可能直连,且要确认注入电流与上电顺序。
  • 5V TTL 输出 → 3.3V TTL 输入:VOH 2.4V > VIH 2.0V,逻辑上可,但余量只有 0.4V;长线/噪声环境需要缓冲或整形。

确认必须转换时,有三条路可走:

  1. 专用电平转换芯片:如 74LVC1T45(单路双向)、TXS0108E(多路)。注意方向控制、速率与上电顺序。
  2. 电阻分压(仅低速):5V → 3.3V 可用 10kΩ + 20kΩ,输出约 3.33V;代价是输出阻抗高、边沿变慢、负载会改变分压比。
  3. 5V 容忍输入:查 datasheet 的 FT 标注、绝对最大额定值与注入电流限制;不要因为"别人这么接过"就默认安全。
分压:Vout = Vin × R2 / (R1 + R2)
5V × 20kΩ / (10kΩ + 20kΩ) = 3.33V;输出阻抗 ≈ R1∥R2 = 6.67kΩ
只适合低速信号;高速时钟/串口请用专用电平转换芯片。
逻辑兼容 ≠ 电气安全:5V 高电平进 3.3V 引脚时,即使输入级"看起来"能读,超限电流也可能经 ESD 二极管灌入电源, 造成发热、闩锁甚至永久损坏。上电前用万用表确认传感器输出高电平,并查 MCU 的绝对最大额定值;这一步本文未在真板执行, 标 hardware-pending。

3.2 上拉 / 下拉:给高阻输入一个确定状态 principle

CMOS 输入本质上是高阻节点(输入漏电流通常只有 nA～µA)。如果什么都不接,引脚电压由寄生电容、漏电和空间干扰共同决定, 这就是浮空:读数随机、易误触发中断、还会因输入级长时间停在中间电平而增加功耗。 上拉电阻把默认状态拉到 VDD,下拉电阻把默认状态拉到 GND。

配置按键引脚电压通过电阻的电流备注
上拉 10kΩ松开≈VDD(高)≈0(仅输入漏电)默认高电平
上拉 10kΩ按下≈0V(低)VDD / R = 0.33mAactive-low
下拉 10kΩ松开≈0V(低)≈0默认低电平
下拉 10kΩ按下≈VDD(高)VDD / R = 0.33mAactive-high
不接(浮空)松开不确定≈0禁止依赖
不接(浮空)按下≈0V(低)≈0只有按下瞬间才勉强确定
电阻电流:I = VDD / R　　功耗:P = VDD² / R
3.3V / 10kΩ = 0.33mA,P ≈ 1.09mW;3.3V / 4.7kΩ = 0.70mA,P ≈ 2.32mW
分压(仅低速、且确认可接受负载时):Vout = Vin × R2 / (R1 + R2)
5V → 3.3V 示例:R1 = 10kΩ,R2 = 20kΩ,Vout = 5 × 20 / 30 = 3.33V

阻值怎么选?按键场景常用 4.7kΩ～10kΩ:太小则按下电流和功耗大、触点负担重;太大则抗干扰差, 并且与引脚输入电容形成 RC,边沿变慢。MCU 内部上拉(典型几十 kΩ)可以省外部电阻,但阻值离散、噪声环境下偏弱; 长线、强干扰或低功耗唤醒场景仍建议外部上拉 + 软件复核。

别把 I²C 上拉照搬到这里:I²C 的上拉由总线电容、速率和上升时间决定(常见 1.5kΩ～10kΩ,高速时更小), 和按键上拉不是同一套算法。两者都要算,但公式和约束不同。

hardware-pending具体 MCU 的内部上拉阻值、输入漏电流,请在 datasheet 的 "I/O static characteristics" 表里确认; 本文的 4.7kΩ～10kΩ 是常见经验区间,不是强制值。

3.3 按键抖动与去抖:为什么按一次会"跳"很多次 principle

机械触点在闭合和断开的瞬间不会一次到位,而是在几毫秒内反复通断,这叫抖动(bounce)。 教材与常见轻触按键的典型抖动时间是 5～20ms(具体看器件和使用寿命)。对 MCU 来说, 每一次通断都可能是一个有效边沿:中断进多次、计数器多加 1、状态机乱跳。

硬件 RC 去抖

在按键节点上加一个 RC 低通,让电压变化变慢,抖动的快速跳变被"抹平"。设门限为 VTH, 从 0 充电到门限的时间约为:

时间常数:τ = R × C　　(Ω × F = 秒;10kΩ × 1µF = 10ms)
充电到门限:t ≈ τ × ln( VDD / (VDD − VTH) )
以 VTH = 0.7 VDD 为例:t ≈ 1.20τ;到 0.5 VDD 则约 0.69τ。工程上常说"3～5τ 基本稳定"。

RC 只负责"变慢",不负责"变干净":缓慢的边沿会让数字输入在门限附近停留很久,可能反复翻转或增加功耗。 所以 RC 之后通常要接施密特触发器(如 74HC14)把慢边沿整形成干净的数字边沿。RC 参数要同时满足两件事: 稳定时间覆盖抖动(一般 ≥ 抖动持续时间的 1～2 倍),又不能慢到按键响应不可接受(按键通常 10～50ms 可接受)。

软件消抖

更常见的做法是定时采样 + 连续多次一致才确认。例如每 5ms 采样一次,连续 3 次读到低才认为"按下", 确认延迟约 10～15ms;也可以写成状态机(空闲 → 疑似按下 → 确认 → 等待释放),在 1ms 或 10ms 定时器里推进。 软件消抖灵活、可调、支持多按键,代价是占用定时器和中断,并引入确认延迟。 不要在中断里用 delay() 等抖动过去:那会阻塞整个系统。

方式做法优点代价 / 坑适用
硬件 RCR + C 低通,后接施密特触发器不占 CPU,能压住毛刺边沿变慢、参数固定、需要整形单键、强干扰、低功耗唤醒
软件消抖定时采样,连续 N 次一致才确认灵活可调,多键成本低占定时器/中断,有确认延迟;禁止阻塞延时多按键、矩阵键盘、可配置设备
两者结合RC 粗滤 + 软件确认抗干扰最强,边沿干净元件与代码都多长线、工业现场、强干扰

下一节的实验 2 会动态展示:τ 太小时门限在抖动期间被反复跨越;τ 太大时稳定时刻被拖到几十甚至上百毫秒。

3.4 采样与量化:ADC 读到的数字代表什么 principle

ADC 把连续电压变成离散码值,分三步:采样保持(内部采样电容充电并保持)→ 量化(把电压切成 2n 份)→ 编码(输出整数码)。n 位 ADC 的最小分辨单位叫 LSB:

LSB = Vref / 2n　　码值上限 2n − 1
例:Vref = 3.3V,n = 12 → LSB = 3.3 / 4096 ≈ 0.8057mV,码值 0～4095
截断式量化:code = floor(Vin / LSB),回算电压 Vq = code × LSB,误差 e = Vin − Vq
理想中心化量化的最大误差约 ±0.5 LSB;截断时误差落在 0 ～ −1 LSB。满量程输入通常饱和在 2n−1。
位数 nVref = 3.3V 时 LSB±0.5 LSB 量化误差说明
8 位12.89mV±6.45mV粗略检测(电位器、光敏电阻阈值)
10 位3.223mV±1.61mV一般传感器趋势
12 位0.8057mV±0.403mVSTM32 等常见分辨率,注意噪声往往大于量化误差
16 位50.35µV±25.2µV高精度测量,对参考、地、布局要求高

例子:3.3V、12 位、输入 1.000V → 1.000 / 0.0008057 ≈ 1241.1 → 码值 1241 → 回算 0.999829V, 误差约 +0.17mV(约 0.21 LSB)。输入恰好 1.650V 时码值 2048,回算正好 1.650V,误差为 0。

一次读数跳动,通常来自下面几项叠加,而不是"ADC 不准":

  • 量化误差:理想 ±0.5 LSB,无法消除,只能提高位数或接受。
  • 参考电压噪声:Vref 的纹波直接按比例进入结果;1 个 LSB 在 12 位 / 3.3V 下只有 0.8mV,参考必须干净。
  • 地噪声与电源纹波:模拟地和数字地处理不当,或 ADC 供电纹波大,读数会整体晃动。
  • 源阻抗 / 采样时间:采样保持电容充电不足,读数偏低;源阻抗高时要延长采样时间或加缓冲。
  • 软件平均:N 次平均对随机噪声约降 √N;但对周期性干扰和混叠无效。

3.5 采样定理与混叠:数字"看不到"的部分 principle

采样是每隔 Ts = 1/fs 读一次电压。要无失真地恢复最高频率 fmax,必须满足 fs > 2 fmax(奈奎斯特条件);工程上通常取 5～10 倍并配合模拟抗混叠低通。 如果采样太慢,高频信号会"伪装"成低频,这叫混叠(aliasing):

折叠到 0～fs/2 的可见频率:falias = | f − k × fs |,其中 k = round(f / fs)
例:f = 900Hz,fs = 1000Hz → k = 1,看到 |900 − 1000| = 100Hz
例:f = 45Hz,fs = 40Hz(fs < 2f)→ k = 1,看到 5Hz
关键:混叠一旦发生,软件滤波无法区分真实频率和它的"伪装",必须在采样前用模拟低通把 f > fs/2 的成分压掉。

除了混叠,ADC 还有两个常被忽略的边界:采样保持充电时间(源阻抗太高或采样周期太短,读数偏低)与 参考电压质量(Vref 抖 1mV,12 位结果就抖 1～2 个码)。datasheet 里对应的参数通常是 RAIN 最大值、采样周期数、VREF 范围与噪声。第 4 段的实验 3 可以直观看到混叠。

3.6 仪器:万用表与示波器看到的是什么 principle

仪器 / 档位怎么接能测什么最容易踩的坑
万用表 直流电压档并联在两点之间供电电压、静态电平、分压节点输入电阻典型 10MΩ,测高阻节点会"加载"改变原电压
万用表 通断 / 二极管档并联,必须断电导线通断、按键触点、焊点带电测量读数不可信,甚至损坏表
万用表 电流档串联进回路整条支路电流误当电压表并联 → 短路电源、烧保险
示波器探头尖端接信号,地夹接电路参考地波形、边沿、抖动、纹波、PWM 频率/占空比地夹不是"随便夹";浮地测量需差分探头或隔离
探头输入阻抗(典型)带宽适用
1X≈1MΩ ∥ ≈100pF较低(常见 6～10MHz)低频、电源纹波(配合短地)
10X≈10MΩ ∥ ≈15pF高(随探头,常见 100～500MHz)时钟、PWM、快速边沿;读数记得 ×10

几个能立刻提升测量可信度的习惯:

  • 示波器带宽 ≥ 5 × 信号频率,采样率 ≥ 5～10 × 带宽;否则看到的边沿是"假圆角"。
  • 测电源纹波用 AC 耦合 + 短地弹簧 + 20MHz 带宽限制;长地线会把振铃当成纹波。
  • 探头第一次使用先接校准方波,调补偿电容,方波应平直无过冲。
  • 测按键抖动用单次触发抓下降沿,时间轴放到 5～20ms/格;测 ADC 输入时同时看 Vref 和地。
  • 万用表测 PWM 通常得到平均值或频率,不能直接读占空比;真有效值表也只能给出 RMS 电压,占空比要用示波器看。

实验步骤与观察记录
  1. 保持"上拉"、松开按键,记录电压(≈3.30V)与逻辑(HIGH)。此时电流为什么接近 0?(输入高阻,电阻上几乎没有电流)
  2. 点击"按下按键":电压应变为 0V、逻辑 LOW,电流约 0.330mA。说明按键把节点短接到 GND,电流从 VDD 经电阻和按键流回地。
  3. 切到"下拉",重复松开/按下:松开为低,按下为高,有效电平反过来了(active-high)。
  4. 切到"浮空"、松开:电压显示"浮动(??)"、逻辑不确定。再按下:变成低——因为按键把节点强行短到 GND,但一松手又回到不确定。
  5. 在纸上把 R 换成 4.7kΩ:按下电流 = 3.3V / 4.7kΩ ≈ 0.70mA,功耗 ≈ 2.32mW;与 10kΩ 的 0.33mA / 1.09mW 对比。

结论:电平由"电阻的默认拉向 + 按键的强制拉向"共同决定;浮空时默认态不存在,只有按下那一刻才确定。实际电路还有输入漏电、寄生电容与 ESD,本模型忽略。

实验步骤与观察记录
  1. 默认 R = 10kΩ、C = 1µF → τ = 10ms。观察滤波电压在抖动结束后约十几毫秒稳定,门限只被穿越 1 次。
  2. 把 R 调到 1kΩ、C 调到 0.1µF → τ = 0.1ms。观察门限在 0～7ms 抖动期间被反复跨越,采样点出现多个高/低。
  3. 慢慢增大 τ 到 2～5ms,找到"门限穿越次数 = 1 且稳定时刻可接受"的区间。
  4. 把 R = 100kΩ、C = 10µF → τ = 1000ms。观察 100ms 窗口内是否稳定,思考按键响应会变成什么样。
  5. 记录:你能接受的稳定延迟是多少?按键通常 10～50ms,低功耗唤醒键可能要求更短。

结论:RC 去抖是用"时间"换"稳定";τ 要与抖动持续时间同量级或略大,同时不能大到影响交互。RC 之后应接施密特触发器整形,或用软件消抖做第二道保险。

实验 3

采样与混叠:为什么看到的频率是假的

simulated

调整信号频率 f 与采样率 fs,观察采样点连线如何"变成"另一个低频波形。模型为理想正弦 + 瞬时采样,不含量化、噪声、采样保持。

真实信号 采样点 采样点连线(你"看到"的波形)
实验步骤与观察记录
  1. 默认 f = 45Hz、fs = 40Hz(低于 2f = 90Hz):真实虚线是 45Hz,但采样点连线只有约 5Hz。
  2. 点"正常采样"(fs = 200Hz):每周期约 4.4 个采样点,连线与真实波形基本一致。
  3. 把 fs 从 200 慢慢拖到 40,观察越过 90Hz 后波形"突然变慢";在 90Hz 附近处于临界状态,结果不可靠。
  4. 把 f 调到 60Hz、fs 调到 50Hz,自己算 falias = |60 − 50| = 10Hz,再与读数对照。
  5. 思考:只给采样数据,你能分辨"45Hz 真实信号"和"5Hz 真实信号"吗?不能——这正是混叠不可逆的原因。

结论:采样率必须高于 2 倍最高信号频率(工程上 5～10 倍),并且要在 ADC 之前用模拟低通抗混叠。提高软件采样率不能挽救已经被混叠的数据。

故障排查

schema: troubleshooting · 现象 → 检查步骤 → 预期结果 → 下一分支
通用顺序:先断电用通断档查接线 → 上电测供电与共地 → 查引脚配置(输入/上拉/复用)→ 用示波器看波形 → 最后才改软件。 跳过前两步,很容易在软件里"修"一个接线问题。
按键不按也乱跳 / 手一碰就触发(误触发)
可能原因
输入浮空或上拉缺失;上拉阻值过大;长线像天线一样拾取干扰;按键触点氧化接触不良。
检查步骤
万用表 DC 电压档测引脚:松开、按下各一次;查原理图与 PCB 是否真有上拉/下拉;查 MCU 引脚配置是否为输入且上拉使能;示波器单次触发看边沿。
预期结果
松开稳定在 ≈VDD 或 ≈0V,按下稳定在另一端;抖动段 ≤ 20ms 且之后不再变化。
下一分支
电压稳定但软件仍多次触发 → 软件消抖;
电压停在 1～2V 中间区 → 上拉缺失/阻值过大/焊接;
长线干扰 → 缩短线、加 RC + 施密特或改成低阻抗驱动。
按键按下没反应,松开反而正常
可能原因
按键接成了常闭;上拉接到了 VDD 而按键也接 VDD;引脚复用/配置错;按键损坏或焊点虚焊。
检查步骤
断电,用通断档测按键两脚:按下应导通(< 1Ω),松开应断开;测按键到 GND/VDD 的连线;对照原理图确认是上拉还是下拉;查引脚是否被配置成输出或复用功能。
预期结果
按键通断正常;引脚电压随按下/松开翻转;逻辑与代码里的有效电平一致(active-low 还是 active-high)。
下一分支
按键本身不通 → 换键;
按键正常但引脚不变 → 查焊接与配置;
电平翻转但程序无响应 → 查中断边沿/轮询周期/去抖逻辑。
ADC 读数跳动很大(几十个 LSB),或短接输入也不归零
可能原因
Vref/VDDA 纹波大;地噪声;采样时间不足或源阻抗过高;输入悬空;软件没有等待转换完成;通道配置错。
检查步骤
把 ADC 输入短接到 GND,连读 100 次看跳动;示波器 AC 耦合测 Vref 与 VDDA 纹波;万用表测实际输入电压与 Vref;把采样时间加长再测;检查 ADC 通道与引脚映射。
预期结果
短接 GND 时码值应在 0 附近小幅跳动(几个 LSB 内);已知输入电压换算后的码值与读数一致(误差在量化 + 噪声范围内)。
下一分支
短接仍跳很大 → 查参考、供电、地、ADC 配置;
短接正常但接传感器跳 → 源阻抗/滤波/线长,加缓冲或延长采样;
有周期性干扰 → 软件平均 + 硬件滤波,查开关电源频率。
接上 5V 传感器后 IO 发烫、板子复位或引脚损坏
可能原因
5V 推挽输出直接进 3.3V 引脚,超过绝对最大额定值;电流经 ESD 二极管灌入电源;上电顺序/断电顺序导致反灌。
检查步骤
查传感器输出高电平(推挽还是开漏、是否有上拉到 5V);查 MCU datasheet 的绝对最大额定值与"5V 容忍"标注(如 STM32 的 FT 引脚);断电用万用表测引脚对 VDD/GND 阻抗;上电用示波器测实际高电平。
预期结果
引脚高电平 ≤ 绝对最大额定值(常见 VDD + 0.3V);若标注 5V 容忍,仍需确认注入电流与上电顺序;不满足就不能直连。
下一分支
不满足 → 加电平转换(如 74LVC1T45)或电阻分压 + 保护(仅低速);
已损坏 → 更换芯片/板卡并加保护;
开漏输出 → 只需上拉到 3.3V,不要上拉到 5V。
示波器测 PWM / 时钟,频率或占空比与代码对不上
可能原因
1X 探头带宽不足;地线过长引入振铃;触发设置错误;采样率不够;探头未补偿;测的是引脚复用前的信号或错误通道。
检查步骤
换 10X 探头并补偿;用短地弹簧;确认触发源/边沿/电平;看示波器采样率是否 ≥ 5× 信号;用万用表/逻辑分析仪交叉验证频率;查引脚复用与时钟配置。
预期结果
上升沿干净、无明显振铃;周期与代码配置一致;占空比误差在时钟/分频误差内。
下一分支
波形振铃 → 缩短地线、加串联阻尼、检查布局;
频率差整数倍 → 查时钟树/预分频;
完全无输出 → 查引脚复用、定时器使能、输出比较配置。
采到的频率/振动读数明显偏低或"看起来在慢速摆动"
可能原因
采样率低于 2 倍信号频率,发生混叠;定时采样抖动大;信号本身有低频包络或拍频。
检查步骤
算 f 与 fs:是否 fs > 2f(工程上 5～10 倍)?把 fs 提高 10 倍看读数是否改变;用示波器直接看原始信号;检查定时器采样周期是否稳定。
预期结果
提高 fs 后读数稳定且与信号源一致;或加上模拟低通后混叠成分消失。
下一分支
提高 fs 后读数改变 → 确认是混叠,加抗混叠低通;
提高后仍偏 → 查传感器带宽/机械频率/采样定时;
读数周期性摆动 → 查拍频与电源干扰。

schema: quiz · 5 题,页面内判分并给解析

选完 5 题后点"提交答案"。判分只用于自检,答错请回到对应小节。

Q1上拉 10kΩ、按键另一端接 GND。按键松开时,引脚电平是?
解析:上拉电阻把节点默认拉到 VDD,按键到 GND 只在按下时把节点拉低。所以松开 = 高、按下 = 低(active-low)。
Q212 位 ADC、Vref = 3.3V,1 个 LSB 约为?
解析:LSB = Vref / 2n = 3.3V / 4096 ≈ 0.8057mV。0.403mV 是 ±0.5 LSB 的量化误差,不是 LSB 本身。
Q35V 传感器推挽输出接 3.3V MCU 的普通 GPIO,最稳妥的做法是?
解析:"能识别高电平"是逻辑问题,"能承受 5V"是绝对最大额定值问题。多数 3.3V 引脚绝对最大为 VDD+0.3V;串电阻只限流,仍可能经 ESD 二极管灌入并抬高电源;把供电改成 5V 可能损坏其他 3.3V 外设。正确做法是查手册,按需做电平转换(或确认 5V 容忍并加保护)。
Q4按键抖动持续约 8ms,RC 去抖取 τ = 1ms,最可能的结果是?
解析:τ = 1ms 时,滤波电压约 1.2τ ≈ 1.2ms 就到达 0.7VDD 门限,而抖动持续约 8ms,所以门限会在抖动期间反复被跨越。τ 通常需要与抖动持续时间同量级或更大,并用施密特触发器整形。
Q5信号 900Hz,采样率 1000Hz,从采样数据里会看到多少 Hz?
解析:fs = 1000Hz < 2f = 1800Hz,发生混叠;falias = |900 − 1000| = 100Hz。提高软件采样率不能恢复已混叠的数据,必须在采样前加模拟低通或提高 fs。
