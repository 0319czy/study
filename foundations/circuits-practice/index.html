数字电路实战:采样、去抖与电平

把带抖动的传感器信号变成可靠数字输入:上拉/下拉、RC 去抖、软件去抖与 ADC 采样量化,参数都能算出来。

1. 目标与成果

项内容
能力能把带抖动的传感器信号变成可靠的数字输入,并解释上拉、去抖、采样与量化误差
可检查结果算出一组 RC 去抖参数;记录一组 ADC 采样率与量化误差;在 M0 模拟器上复现
证据标识principle · hardware-pending(真实板卡由你验证)

2. 前置知识

需要会用在哪去哪补
逻辑门与电平高/低、阈值、上拉/下拉数字电路入门
RC 与时间常数τ=RC、充电曲线数字电路入门

3. 原理与图示

机械按键在按下/松开瞬间会抖动 1–20ms。硬件去抖用 RC 低通(τ=RC),软件去抖用"连续 N 次采样一致才确认"。

ADC 量化误差 = 满量程 / 2^位数 / 2;例如 12 位、3.3V 量程,理论分辨率约 0.4mV,但噪声与参考电压误差会让实际误差更大。

采样定理:采样率至少是信号最高频率的 2 倍;工程上通常取 5–10 倍。

去抖时间常数:τ = R × C
示例:R = 10kΩ, C = 100nF → τ = 1ms;确认时间取 5τ ≈ 5ms

4. 操作实验

  1. 打开 M0 采集,把模拟器采样率设为 1kHz,阈值设为 20℃,记录 30 个点。
  2. 计算:若按键抖动 8ms,软件去抖每 2ms 采样一次,至少需要连续几次一致?
  3. 用 12 位 ADC、3.3V 量程,计算 1LSB 对应电压与 25℃ 附近 0.1℃ 需要的位数。
  4. 把参数与结论写进 /archive/ 的笔记。
去抖次数 = ceil(抖动时间 / 采样间隔) + 1
= ceil(8ms / 2ms) + 1 = 5 次

5. 结果检查

检查项预期
去抖参数τ≈1ms、确认 5 次可覆盖 8ms 抖动
采样率1kHz 采样对 50Hz 信号有 20 倍余量
量化误差12 位 3.3V:1LSB≈0.806mV;0.1℃ 需约 0.4mV 分辨率(实际受噪声限制)

6. 故障排查

现象检查步骤预期结果下一分支
按键误触发多次是否只做了软件消抖但采样太慢?采样间隔 ≤ 抖动时间/3加 RC + 提高采样率
输入电平悬空是否缺上拉/下拉?空闲时电平确定加 10kΩ 上拉或下拉
ADC 读数跳动大参考电压/地线/采样保持时间短接输入时读数稳定加滤波电容、延长采样时间

证据边界:参数计算为 principle;真实按键/ADC 波形需在板卡上复测(hardware-pending)。
