FOUNDATIONS · 阶段 01

工程基础:三门最小课

这是学习路线阶段 01 的内容。三课按顺序学:先能写 C 并编译调试,再看懂电平与采样, 最后在 Linux 用户态里读写文件、读串口、管进程。学完就进入采集监控项目 M0。

01

C 与工程工具

已上线
指针与数组、位操作、编译链接四个阶段、Git 基础、用 gdb / printf 调试。目标:能编译、调试并解释一个小工程。
前置:无成果:小工程可编译可调试证据:principle + compiled
开始学习(C 子站)→ 进阶:内存与调试 C 学科首页 环境准备
02

数字电路入门

已上线
3.3V/5V 电平、上拉/下拉、按键去抖、采样与 ADC 量化、仪器使用。目标:能看懂接线图并解释电平与误差。
前置:C 与工程工具成果:能解释按键与 ADC 电路证据:principle + simulated
开始学习(数字电路子站)→ 进阶:采样与去抖 数字电路学科首页 先复习 C
03

Linux 用户态入门

已上线
Shell 与权限、进程/线程与信号、文件 I/O、串口 termios(115200 8N1)、定时与日志。目标:能写设备端应用并读串口数据。
前置:C 与工程工具成果:能读串口、管进程证据:compiled + simulated
开始学习 → 进入项目 M0

学完这三门,你能做什么

能力验收方式
编译并调试一个 C 小工程能跑通示例、说出四个编译阶段产物
看懂传感器接线与电平能判断上拉/下拉、解释 ADC 量化误差
在 Linux 上读串口并处理数据能用 termios 程序读取模拟串口数据并统计
进入项目实战完成 M0 采集:解释单位、采样周期、误差

课程证据标识

标识含义
principle原理示意与讲解,不代表真实运行结果
compiled代码在指定工具链/版本下真实编译通过(页面写明命令与版本)
hardware在具体型号硬件上实测通过(需用户实机验证,页面不冒充实测)
simulated用模拟数据/教学模拟完成流程
