字符设备入门
LED Character Device

LED 字符设备

从设备号、cdev、file_operations 到 /dev 节点，完成一个可读写的 LED 字符设备最小闭环。

SoC GPIO 驱动一颗 LED；GPIO 极性以原理图为准。
你会练到
  • 注册字符设备并自动创建 /dev 节点
  • 用 read/write 控制亮度/开关
  • 验证卸载清理顺序
展开设备树、驱动骨架与验证
验证顺序
  1. dmesg 看到 major/minor 与 probe 日志
  2. ls -l /dev/led_demo
  3. echo 1 > /dev/led_demo 后量测 GPIO
常见坑
  • class_create 参数随版本变化
  • 忘记检查 device_create 的 ERR_PTR
  • 卸载顺序反了导致残留节点

GPIO 引脚、极性与寄存器地址必须按板级原理图与 SoC 手册替换；本案例未在真实板卡编译验证。

中断入门
GPIO Key Interrupt

GPIO 按键中断

按键触发 GPIO 中断，上半部只做最小确认，下半部完成消抖与事件上报。

按键接 GPIO，按下拉低；需要上拉/消抖按硬件设计。
你会练到
  • 用 gpiod_to_irq + request_irq 注册中断
  • 用 workqueue/threaded IRQ 做消抖
  • 处理共享中断与返回值
展开设备树、驱动骨架与验证
验证顺序
  1. cat /proc/interrupts 看计数
  2. 按按键后 dmesg/事件计数增加
  3. 卸载后中断不再触发
常见坑
  • 上半部睡眠
  • 共享中断返回错误
  • 消抖时间与硬件不匹配

GPIO 编号与中断触发方式必须按板级设计；中断共享/唤醒配置需实测。

总线进阶
I2C Temperature & Humidity

I2C 温湿度读取

在 I2C 总线上匹配传感器，读取 ID 与测量寄存器，处理 ACK、错误码与上电时序。

I2C 温湿度传感器，7 位地址与寄存器表以数据手册为准。
你会练到
  • 写 i2c_driver 与 of_match_table
  • 用 smbus/i2c_transfer 读取寄存器
  • 用 i2cdetect/i2cget 分步验证
展开设备树、驱动骨架与验证
验证顺序
  1. i2cdetect -y 1 看到 0x48
  2. i2cget -y 1 0x48 0x00
  3. 驱动 probe 日志与读数合理
常见坑
  • 把 8 位写地址当 7 位地址
  • 寄存器命令写错
  • probe 签名与目标内核不一致

传感器型号、地址、寄存器与转换公式必须按数据手册；示例 ID 为虚构。

总线进阶
SPI Display Panel

SPI 屏幕驱动

通过 SPI 发送初始化序列与像素数据，重点处理 mode、片选、速率与传输缓冲生命周期。

SPI 显示屏，CS/SCLK/MOSI 及可选 DC/RST 引脚按模块手册。
你会练到
  • 设置 SPI mode/速率/bits
  • 组合多个 spi_transfer
  • 用逻辑分析仪验证 CS/SCLK/MOSI
展开设备树、驱动骨架与验证
验证顺序
  1. 逻辑分析仪看 CS/SCLK/MOSI
  2. 降低速率验证
  3. 屏幕初始化命令无 NACK 概念，但需看返回码
常见坑
  • mode 与从设备不匹配
  • 片选编号错
  • 传输缓冲在完成前被释放

屏幕初始化序列与引脚定义因模组而异；示例不是完整显示驱动。

平台驱动进阶
Platform Driver + DT

平台驱动 + 设备树

用 compatible 匹配平台设备，在 probe 中获取寄存器/中断/时钟，并设计可回滚的失败路径。

SoC 片上外设，寄存器与中断号来自 SoC 手册与 dts。
你会练到
  • of_match_table 匹配
  • platform_get_resource/platform_get_irq
  • probe 失败回滚与 remove 顺序
展开设备树、驱动骨架与验证
验证顺序
  1. /sys/bus/platform/devices 出现设备
  2. driver 目录绑定成功
  3. probe/remove 日志与资源释放正确
常见坑
  • compatible 不匹配
  • 资源索引错
  • remove 签名/顺序错误

寄存器地址、中断与时钟必须按 SoC 手册；probe 代码为骨架，不保证跨版本编译。

阻塞 IO进阶
Blocking Read with Wait Queue

等待队列阻塞读

无数据时让进程睡眠，中断到来后唤醒；同时支持 O_NONBLOCK 与 poll。

任意会产生数据的中断/传感器；示例用软件生产者。
你会练到
  • 实现阻塞/非阻塞读
  • 避免丢失唤醒
  • poll 注册等待并报告就绪
展开设备树、驱动骨架与验证
验证顺序
  1. 阻塞 read 在无数据时挂起
  2. 写入数据后 read 返回
  3. O_NONBLOCK 下立即返回 -EAGAIN
常见坑
  • 唤醒丢失
  • 条件不与锁配合
  • 非阻塞返回 0 被误判 EOF

示例省略锁与缓冲管理；真实驱动需处理并发消费者与关闭竞态。

DMA进阶
DMA UART Transfer

DMA 串口搬运

用 DMA 把串口 FIFO 数据搬到内存，完成中断后同步、解除映射并唤醒读者。

支持 DMA 的 UART 控制器；通道与请求线来自 SoC 手册。
你会练到
  • 正确映射 DMA 缓冲
  • 处理完成中断与错误
  • 在释放前停止 DMA
展开设备树、驱动骨架与验证
验证顺序
  1. 大流量下无丢字节
  2. DMA 完成中断计数与长度一致
  3. 卸载时无 UAF
常见坑
  • 方向/同步错误
  • 设备仍写时释放缓冲
  • IOMMU 地址未用 DMA API

DMA 通道、请求线、缓存一致性与 UART 寄存器必须按 SoC 手册；示例不含完整控制器驱动。
