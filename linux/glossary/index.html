基础VFS

虚拟文件系统

Virtual File System

内核中的文件操作抽象层。它让 read/write 等调用不必关心底层是磁盘、字符设备还是网络文件系统。

相关：
基础syscall

系统调用

System Call

用户程序请求内核服务的受控入口，例如 read、write、ioctl、mmap。它会触发从用户态到内核态的切换。

相关：
基础

用户态

User Space

普通应用程序运行的权限级别。不能直接访问内核内存或执行特权指令，必须通过系统调用进入内核。

相关：
基础

内核态

Kernel Space

内核代码运行的权限级别，可以访问硬件与全部内存。驱动的大部分回调运行在这里。

相关：
基础

设备驱动

Device Driver

内核中把统一接口翻译成具体硬件操作的代码。它通常通过总线与设备模型注册，并在 probe 中初始化硬件。

相关：
基础cdev

字符设备结构

Character Device

内核用来表示字符设备的结构体，把设备号与 file_operations 关联起来。用户通过 /dev 节点访问它。

相关：
基础

文件操作表

file_operations

驱动向 VFS 注册的一组回调，例如 open、read、write、release、unlocked_ioctl、poll、mmap。

相关：
基础

设备节点

Device Node

/dev 下代表设备的特殊文件。主设备号定位驱动，次设备号区分同一驱动下的不同实例。

相关：
设备模型

用户态设备管理器

udev

根据内核 uevent 在 /dev 下创建设备节点、设置权限与别名的用户态程序。不同发行版实现可能不同。

相关：
设备模型

探测回调

probe

总线或设备模型确认 device 与 driver 匹配后调用的初始化回调。probe 成功才表示驱动真正接管了设备。

相关：
设备模型

设备树

Device Tree

描述板级硬件的数据结构，源文件为 dts/dtsi，编译后为 dtb。compatible 属性用于驱动匹配。

相关：
设备模型

兼容性字符串

compatible

设备树节点中的字符串列表，用来声明“我兼容哪些驱动”。驱动侧通过 of_match_table 提供对应字符串。

相关：
设备模型

系统文件系统

sysfs

挂载在 /sys 的虚拟文件系统，用目录和文本属性展示设备、驱动、总线与内核对象的关系。

相关：
设备模型

内核对象

kobject

设备模型的基础引用计数对象，负责 sysfs 表示、生命周期与 uevent。通常不直接在驱动里裸操作。

相关：
设备模型

用户态事件

uevent

内核向用户态发送的设备变化通知，例如 add/remove。udev 等程序据此创建设备节点或执行规则。

相关：
并发

中断上半部

Top Half

硬中断处理中最先执行的部分，运行在中断上下文，要求短小快速，不能睡眠。

相关：
并发

中断下半部

Bottom Half

把中断中较耗时的善后工作延后执行。常见机制有 tasklet、workqueue、threaded IRQ。

相关：
并发

中断

Interrupt

硬件或软件通知 CPU 暂停当前工作、先处理紧急事件的机制。驱动通过 request_irq 注册处理函数。

相关：
并发

自旋锁

Spinlock

忙等型锁：拿不到锁时原地循环，不睡眠。适合临界区极短且不能睡眠的上下文。

相关：
并发

互斥锁

Mutex

可睡眠的互斥锁：拿不到锁时进程可以睡眠，适合可能阻塞或较长的临界区。不能在中断上下文使用。

相关：
并发

竞态条件

Race Condition

多个执行流并发访问共享数据，最终结果依赖执行顺序。即使概率很低，也可能在压力下稳定复现。

相关：
内存DMA

直接内存访问

Direct Memory Access

让外设与内存直接搬运数据、减少 CPU 参与。驱动需要正确处理地址映射、cache 一致性与完成通知。

相关：
内存

DMA 映射

DMA Mapping

把 CPU 使用的地址转换成设备可访问的 DMA 地址，并处理 cache 与 IOMMU 相关事项。

相关：
内存

输入输出内存管理单元

IOMMU

为设备提供地址转换与隔离的硬件单元。它影响 DMA 地址、映射粒度与安全性。

相关：
并发

等待队列

Wait Queue

让进程在条件不满足时睡眠、条件满足时被唤醒的机制。阻塞读、poll 等场景常用。

相关：
并发

阻塞 IO

Blocking I/O

调用在数据未就绪时让进程睡眠，直到条件满足或被打断。与之相对的是非阻塞 IO。

相关：
并发

多路就绪等待

poll

让一个线程同时等待多个文件描述符的就绪事件。驱动通过 file_operations.poll 提供支持。
