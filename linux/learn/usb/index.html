USB 驱动简介

USB 是主机主导的枚举与传输体系。先分清主机控制器、设备、接口与类驱动，再理解 usb_driver 的 probe 与端点。

学习目标

  • 区分 USB 主机侧与设备侧代码
  • 理解设备描述符、接口、端点与 class driver 的关系
  • 知道 lsusb、usbmon、dmesg 在排查中的位置
ONE SENTENCE

USB 是主机主导的枚举与传输体系；主机侧驱动匹配的是“接口”，数据通过端点与 URB 流动。

生活化比喻

USB 主机是前台，设备是访客，接口是访客能办的功能

访客进门先登记（枚举），说明自己有哪些功能（配置/接口/端点）；前台给每个功能分配窗口。一个 USB 设备可以有多个接口，每个接口由不同的 class driver 接管。

为什么重要 / 用在哪里

  • USB 摄像头、串口、HID、存储、网卡都走同一套主机控制器与枚举流程，但驱动匹配层级不同。
  • USB 驱动绑定的是 interface，不是整个设备；一个设备可能由多个驱动分别接管不同接口。
  • URB 是异步传输的核心对象，提交、完成、取消与内存生命周期必须成对管理。
  • 调试常从 lsusb、dmesg、usbmon 三条线同时入手，单看驱动日志容易迷路。

核心概念

host controller

主机控制器

主板上负责 USB 总线的控制器，如 xHCI。主机侧驱动通常由内核提供；设备侧代码是另一套体系。

device / configuration / interface / endpoint

设备、配置、接口、端点

设备描述整体；配置是一组接口；接口代表一个功能；端点是最底层的数据通道。驱动通常绑定 interface。

usb_driver

USB 驱动

提供 probe/disconnect 与 id_table。VID/PID 或 class 匹配成功后，内核把接口交给驱动。

USB Request Block

URB

USB 传输任务对象。提交后异步完成，完成回调可能运行在不可睡眠的上下文；取消与回收要小心。

control transfer

控制传输

用于枚举、读写描述符、发送类请求。usb_control_msg 是同步封装，可能睡眠，不能在硬中断上下文调用。

class driver

设备类驱动

按功能而不是具体 VID/PID 匹配，例如 HID、CDC-ACM、UAS。class driver 让同一类设备共用驱动。

最小 usb_driver 骨架

API 逐个解释
usb_driver.probe进程上下文
int (*probe)(struct usb_interface *intf, const struct usb_device_id *id);

参数：intf：匹配到的接口；id：命中的 id_table 项

返回：成功返回 0；失败返回负 errno。

注意：一个 USB 设备可能有多个接口；不要假设 probe 一次就接管整个设备。

usb_driver.disconnect进程上下文
void (*disconnect)(struct usb_interface *intf);

参数：intf：被拔出的接口

返回：无返回值。

注意：停止 URB、注销接口、释放资源；不要在 disconnect 里继续使用已断开的端点。

USB_DEVICE编译期匹配表
USB_DEVICE(vend, prod)

参数：vend：16 位 Vendor ID；prod：16 位 Product ID

返回：展开为 usb_device_id 初始化项。

注意：ID 必须来自 lsusb/设备手册；class 驱动可用 USB_INTERFACE_INFO 等宏。

常见错误与排查

01

lsusb 能看到设备，但驱动 probe 不执行。

常见原因
VID/PID 不匹配、驱动只匹配 device 而未匹配 interface、class driver 已抢先绑定，或驱动未注册。
排查 / 修复
用 lsusb -v 看 interface/class；检查 id_table；看 /sys/bus/usb/drivers 与 dmesg；确认没有被其他驱动绑定。
02

提交 URB 后完成回调里崩溃或休眠。

常见原因
完成回调上下文不能睡眠；URB 内存在完成前被释放；取消/回收顺序错误。
排查 / 修复
完成回调只做短小工作，耗时处理转 workqueue；确保 URB 缓冲生命周期覆盖传输；用 usb_kill_urb 等待取消。
03

USB 设备频繁断开重连，日志刷屏。

常见原因
供电/线缆/端口问题，或驱动配置导致设备复位；也可能是枚举描述符异常。
排查 / 修复
换端口/线缆/供电；看 dmesg 与 usbmon；确认设备固件与描述符；不要先怀疑驱动逻辑。
