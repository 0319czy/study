实战案例

五个案例，把知识串成项目

从 40 分钟的 turtlesim，到需要几小时的建图、导航、抓取流程。每个案例都有目标、步骤、关键命令和常见坑。 所有命令都是学习示意，请在你自己的 ROS 2 环境里执行。

  1. 1

    1. 启动仿真节点

    turtlesim_node 是一个画着小乌龟的二维仿真器，它会发布 /turtle1/pose 并订阅 /turtle1/cmd_vel。

  2. 2

    2. 看系统结构

    另开一个终端，先 source，再列节点与话题，确认两者都在。这是每次接手陌生系统的第一个动作。

  3. 3

    3. 手动发速度指令

    直接往 /cmd_vel 发一条 Twist，小乌龟会动。这一步证明「通信链路是通的」，之后才怀疑算法。

  4. 4

    4. 观察位姿反馈

    打印 /turtle1/pose，能看到 x、y、theta 的变化。这就是「控制 → 执行 → 反馈」的最小闭环。

  5. 5

    5. 调用服务与改参数

    用 spawn 服务生成第二只乌龟，再用 param set 改背景色，体会服务与参数的区别。

常见坑

  • · 忘记 source 导致 ros2 run 找不到包
  • · 消息类型写错（geometry_msgs/msg/Twist 写成 geometry_msgs/Twist）
  • · 旧终端 vs 新终端环境不一致
