状态反馈与观测器

u=−Kx、极点配置、Luenberger 观测器与分离原理:只测位置也能估速度。

1. 目标与成果

项内容
能力状态反馈极点配置与可控性;观测器误差动态
会做K 与 L 的极点位置,权衡收敛与噪声
可检查结果误差收敛曲线与噪声放大

2. 前置知识

需要会用在哪去哪补

3. 原理与公式

符号含义单位作用
K状态反馈增益随量纲反馈
L观测器增益随量纲估计
x̂状态估计同 x观测器
e估计误差同 x收敛
反馈:u = −Kx(或 −Kx̂ + 参考前馈)
闭环:A − B K,极点由 K 配置(需可控)
观测器:x̂′ = A x̂ + B u + L(y − C x̂)
误差:e′ = (A − L C)e
分离原理:LTI 系统可分别设计 K 与 L
  1. 对 x′=Ax+Bu 选期望闭环极点,求 K。
  2. 对给定 C 设计 L,使 A−LC 极点更快。
  3. 组合 u=−Kx̂,验证分离原理。
  4. 加入测量噪声,观察 L 的权衡。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

图示

详细讲解

直观理解:状态反馈给每个状态配阻尼/弹簧,把闭环极点放到位;观测器用测量反推未测状态;二者可分开设计。

推导:u=−Kx → A−BK;K 由期望特征多项式定。x̂′=Ax̂+Bu+L(y−Cx̂);e′=(A−LC)e。

权衡:L 大收敛快但噪声放大;K 大响应快但饱和风险大。

例题与误区

例题 1

例 1:双积分期望 −2,−3,K?

解答:s²+k2 s+k1 对比 (s+2)(s+3):k1=6,k2=5。

例题 2

例 2:A−LC 为何收敛?

解答:特征值全负 → e→0。

例题 3

例 3:分离原理边界?

解答:LTI;非线性/饱和需重新验证。

  • 误区:观测器能用但噪声下不可用(权衡 L 与滤波)。
  • 误区:忽略执行器限幅。
  • 误区:参考输入与调节混为一谈(需前馈/积分)。

进一步讲解

分步推导(补)

  1. 定期望闭环极点。
  2. 由特征多项式求 K。
  3. 定观测器极点更快,求 L。
  4. 组合 u=−Kx̂,验证分离。

数值算例(补)

双积分、期望 −2,−3:A−BK 特征 s²+k2 s+k1=(s+2)(s+3) → k1=6,k2=5;观测器 −5,−6 → l1=11,l2=30(A−LC)。

应用与考法(补)

常见考法:极点配置求 K;Luenberger 求 L;误差动态;分离原理条件;噪声权衡。

进阶专题

Ackermann 极点配置公式

K=[0 … 1]Wc⁻¹ φ(A),φ 为期望特征多项式,Wc 为可控性矩阵。手算小系统可直接对比特征多项式系数。

全维与降维观测器

全维观测器估计全部状态,实现简单;降维只估计不可测部分,阶数更低但实现复杂。工程多用全维 + 滤波。

参考输入与积分作用

u=−Kx+N r 做参考前馈;要消稳态误差可加积分状态或扰动观测器。N 的选择使闭环直流增益为 1。

观测器带宽与噪声

观测器极点通常比控制器快 2–5 倍;太快会放大测量噪声,导致控制抖动。需要与滤波、采样率一起权衡。

鲁棒性与模型误差

极点配置对模型误差敏感;参数漂移、延迟、饱和会改变闭环极点。设计后要扫参数/延迟,确认裕度。
