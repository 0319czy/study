状态反馈与观测器

u=−Kx、极点配置、Luenberger 观测器与分离原理:只测位置也能估速度。

1. 目标与成果

项内容
能力设计状态反馈增益与观测器,理解分离原理
可检查结果观测器误差收敛曲线与噪声权衡

2. 前置知识

需要会用在哪去哪补
现代控制基础A/B/C/D、可控可观/control/state-space/
线性代数特征值无

3. 原理

状态反馈 u=−Kx 把闭环极点放到期望位置(需可控)。观测器 x̂′ = A x̂ + B u + L(y−C x̂),误差 e′=(A−LC)e。分离原理:反馈与观测可分开设计(线性时不变)。参考输入与调节是两件事。

4. 操作实验

  1. 对位置/速度模型设计 K 与 L。
  2. 用只测位置估计速度,画真实/估计与误差。
  3. 改变观测器增益,看收敛速度与噪声放大。

5. 结果检查

检查项预期
闭环极点与设计一致
误差收敛e→0
噪声高增益放大噪声

6. 故障排查

现象检查步骤预期结果下一分支
误差不收敛(A−LC) 不稳定重设 L检查可观性
控制抖噪声放大降低 L/滤波
