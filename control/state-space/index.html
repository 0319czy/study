现代控制基础

状态、A/B/C/D、平衡点与线性化、可控性与可观性:从传递函数到内部状态。

1. 目标与成果

项内容
能力状态空间模型与物理量对应;测量量≠状态
会做位置/速度、电机等系统的 A/B/C/D
可检查结果可控性/可观性矩阵与秩

2. 前置知识

需要会用在哪去哪补

数学建模微分方程/control/modeling/
反馈原理闭环/control/feedback/

3. 原理与公式

符号含义单位作用
x状态向量随物理量内部状态
u输入执行器单位控制
y输出传感器单位测量
A/B/C/D系统矩阵随物理量模型
x′ = A x + B u
y = C x + D u
平衡点:x′=0;局部线性化用雅可比
可控性:[B AB A²B …] 满秩
可观性:[C; CA; CA²; …] 满秩
  1. 选状态(位置/速度/角度)。
  2. 按物理方程写一阶微分方程组。
  3. 整理成矩阵 A/B/C/D。
  4. 检查可控性/可观性矩阵的秩。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

图示

详细讲解

直观理解:传递函数只看输入输出,状态空间写出内部状态;位置/速度、电流/转速都是状态,传感器只测一部分。

推导:x′=Ax+Bu、y=Cx+Du;平衡点 x′=0;线性化用雅可比;可控 [B AB…] 满秩;可观 [C;CA;…] 满秩;特征值定稳定。

工程:可控=能不能驱动到目标;可观=能不能从测量估计状态;共同决定控制器/观测器可行性。

例题与误区

例题 1

例 1:双积分可控?

解答:[B AB]=[0 1;1 0],满秩 2。

例题 2

例 2:只测位置可观?

解答:[C;CA]=[1 0;0 1],满秩。

例题 3

例 3:测量量=状态?

解答:传感器只测部分组合;速度需模型/观测器估计。

  • 误区:传递函数覆盖所有内部行为(可能隐藏不可观/不可控模态)。
  • 误区:可控=稳定。
  • 误区:只测输出就能估所有状态(可观是前提)。

4. 操作实验

  3. 测位置+速度,再算秩,对比。

参考实现(可复现)

# A/B/C/D(双积分,只测位置)
A=np.array([[0,1],[0,0]])
B=np.array([[0],[1]])
C=np.array([[1,0]])
# 可控性
Wc=np.hstack([B, A@B])
print("rank Wc", np.linalg.matrix_rank(Wc))
# 可观性
Wo=np.vstack([C, C@A])
print("rank Wo", np.linalg.matrix_rank(Wo))
