现代控制基础

状态、A/B/C/D、平衡点与线性化、可控性与可观性:从传递函数到内部状态。

1. 目标与成果

项内容
能力状态空间模型与物理量对应;测量量≠状态
会做位置/速度、电机等系统的 A/B/C/D
可检查结果可控性/可观性矩阵与秩

2. 前置知识

需要会用在哪去哪补
线性代数矩阵、秩、特征值无
数学建模微分方程/control/modeling/
反馈原理闭环/control/feedback/

3. 原理与公式

符号含义单位作用
x状态向量随物理量内部状态
u输入执行器单位控制
y输出传感器单位测量
A/B/C/D系统矩阵随物理量模型
x′ = A x + B u
y = C x + D u
平衡点:x′=0;局部线性化用雅可比
可控性:[B AB A²B …] 满秩
可观性:[C; CA; CA²; …] 满秩
  1. 选状态(位置/速度/角度)。
  2. 按物理方程写一阶微分方程组。
  3. 整理成矩阵 A/B/C/D。
  4. 检查可控性/可观性矩阵的秩。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

图示

详细讲解

直观理解:传递函数只看输入输出,状态空间写出内部状态;位置/速度、电流/转速都是状态,传感器只测一部分。

推导:x′=Ax+Bu、y=Cx+Du;平衡点 x′=0;线性化用雅可比;可控 [B AB…] 满秩;可观 [C;CA;…] 满秩;特征值定稳定。

工程:可控=能不能驱动到目标;可观=能不能从测量估计状态;共同决定控制器/观测器可行性。

例题 1

例 1:双积分可控?

解答:[B AB]=[0 1;1 0],满秩 2。

例题 2

例 2:只测位置可观?

解答:[C;CA]=[1 0;0 1],满秩。

例题 3

例 3:测量量=状态?

解答:传感器只测部分组合;速度需模型/观测器估计。

  • 误区:传递函数覆盖所有内部行为(可能隐藏不可观/不可控模态)。
  • 误区:可控=稳定。
  • 误区:只测输出就能估所有状态(可观是前提)。

进一步讲解

分步推导(补)

  1. 选状态变量。
  2. 写一阶微分方程组。
  3. 整理 A/B/C/D。
  4. 算可控/可观矩阵的秩。

数值算例(补)

双积分 A=[[0,1],[0,0]],B=[[0],[1]]:可控矩阵 [B AB]=[[0,1],[1,0]] 满秩;只测位置 C=[[1,0]],可观矩阵 [[1,0],[0,1]] 满秩;特征值 0,0(临界)。

应用与考法(补)

常见考法:写 A/B/C/D;判断可控/可观;特征值判稳定;测量量≠状态。

进阶专题

相似变换与对角化

x=Tz 后 A→T⁻¹AT,B→T⁻¹B,C→CT。特征值不变;可对角化时模态解耦。数值上避免病态 T;工程多用 Schur/QR。

模态与稳定性

特征值实部决定衰减/增长;复极点给振荡;模态可观/可控决定该模态能否被控制或观测。不可控不稳定模态是致命问题。

可控/可观分解

用可控性矩阵/可观性矩阵构造变换,把系统分成可控可观、可控不可观、不可控可观、不可控不可观四块;只有可控可观部分能设计反馈+观测器。

输出反馈 vs 状态反馈

输出反馈 u=−Ky 受 C 限制,不能任意配置极点;状态反馈需全部状态,实际用观测器重构。输出反馈常配合积分/前馈。

连续系统离散化

x[k+1]=Ad x[k]+Bd u[k],Ad=e^(ATs),Bd=∫e^(Aτ)Bdτ。用矩阵指数计算;采样周期影响离散稳定性。

4. 操作实验

项内容看什么
模型x″=u(双积分)x=[位置,速度]
输出只测位置/测位置+速度C 不同
可观性判断能否估计速度二阶只测位置通常可观
仿真labs 观测器验证估计
  1. 对双积分对象写 A/B/C/D,验证维度。
  2. 只测位置,计算可观性矩阵的秩。
  3. 测位置+速度,再算秩,对比。
  4. 用 labs 的观测器实验观察估计误差收敛。

参考实现(可复现)

# A/B/C/D(双积分,只测位置)
A=np.array([[0,1],[0,0]])
B=np.array([[0],[1]])
C=np.array([[1,0]])
# 可控性
Wc=np.hstack([B, A@B])
print("rank Wc", np.linalg.matrix_rank(Wc))
# 可观性
Wo=np.vstack([C, C@A])
print("rank Wo", np.linalg.matrix_rank(Wo))
