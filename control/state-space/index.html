CONTROL · 现代控制基础

现代控制基础

状态、A/B/C/D、平衡点与线性化、可控性与可观性:从"传递函数"到"内部状态"。

1. 目标与成果

项内容
能力写出位置/速度模型的状态空间,判断可控/可观
可检查结果两个传感器布置的可观性判断

2. 前置知识

需要会用在哪去哪补
线性代数矩阵、特征值无
数学建模微分方程/control/modeling/

3. 原理

x′ = A x + B u,y = C x + D u。平衡点处线性化;特征值决定稳定性;可控性矩阵 [B AB …] 满秩可控;可观性矩阵 [C;CA;…] 满秩可观。测量量不等于状态。

变量与单位:x 为状态向量、A/B/C/D 随物理量;特征值 rad/s。假设平衡点处 LTI。

4. 操作实验

  1. 对位置/速度模型写 A/B/C/D。
  2. 比较只测位置 vs 测位置+速度的可观性。
  3. 从初始状态观察输出能否区分。

5. 结果检查

检查项预期
A/B/C/D维度与物理量一致
可控矩阵满秩
可观只测位置仍可观速度(二阶)

6. 故障排查

现象检查步骤预期结果下一分支
矩阵写错量纲/符号按物理方程逐项/control/modeling/
可观性判断错C 矩阵重算秩
