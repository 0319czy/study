LQR 最优控制入门

Q/R 权衡、Riccati 方程与反馈增益:调节到原点的"代价最小"。

1. 目标与成果

项内容
能力二次代价 J=∫(xᵀQx+uᵀRu)dt 的权衡
会做解 Riccati 得 P 与 K=R⁻¹BᵀP
可检查结果Q/R 预设对轨迹/输入的影响与限幅边界

2. 前置知识

需要会用在哪去哪补
状态反馈极点配置/control/state-feedback/
线性代数矩阵方程无
稳定性闭环极点/control/stability/

3. 原理与公式

符号含义单位作用
Q状态权重对称半正定压状态
R控制权重对称正定省控制
PRiccati 解对称正定代价
K反馈增益随量纲u=−Kx
J = ∫₀∞ (xᵀQx + uᵀRu) dt
Riccati:AᵀP + PA − P B R⁻¹ Bᵀ P + Q = 0
K = R⁻¹ Bᵀ P,u = −Kx
Q↑:更强压状态;R↑:更省控制
离散:dlqr(A,B,Q,R) 得 K
  1. 选 Q 与 R(对角、量纲对齐)。
  2. 解连续 Riccati 得 P。
  3. 算 K=R⁻¹BᵀP。
  4. 仿真验证轨迹/输入/代价;检查限幅。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

图示

详细讲解

直观理解:LQR 给状态偏差与控制量定价:Q 说状态多贵,R 说控制多贵;解 Riccati 得最优增益,把调参变成调权重。

推导:J=∫(xᵀQx+uᵀRu);Riccati AᵀP+PA−PBR⁻¹BᵀP+Q=0;K=R⁻¹BᵀP;离散 dlqr。

边界:限幅、采样、模型不确定性让"最优"打折;超出线性化范围停用/换非线性。

例 1:双积分 Q=I、R=1,K 趋势?

解答:闭环极点左移;可用工具求 K。

例 2:Q×10 控制量?

解答:通常更大,饱和风险升。

例题 3

例 3:为何要限幅检查?

解答:最优解未考虑输入约束。

  • 误区:LQR 自动保证稳定(需可控/模型内)。
  • 误区:Q/R 越大越好(量纲匹配)。
  • 误区:忽略观测器(输出反馈需 LQG)。

进一步讲解

分步推导(补)

  1. 选 Q/R(量纲对齐)。
  2. 解 Riccati 得 P。
  3. K=R⁻¹BᵀP。
  4. 仿真验证并检查限幅。

数值算例(补)

双积分 Q=diag(q1,q2)、R=r:可用工具求 K;q1 增大→位置权重高,K 更压位置;r 增大→K 变小、控制更省。代价 J=∫(q1 x1²+q2 x2²+r u²)dt。

应用与考法(补)

常见考法:Q/R 趋势;Riccati 形式;K 与极点关系;LQR+LQE=LQG;限幅/线性化边界。

进阶专题

LQR 与极点配置的关系

LQR 得到的闭环极点是 Riccati 方程的解,通常具有良好裕度(PM≥60°、GM 无穷对 SISO);极点配置可任意放,但可能脆弱。

离散 LQR

离散 Riccati:P=Q+AᵀPA−AᵀPB(R+BᵀPB)⁻¹BᵀPA;K=(R+BᵀPB)⁻¹BᵀPA。采样周期影响代价与增益。

权重选择策略

先按物理量归一化状态/输入;Q 大压状态、R 大省控制;从保守(大 R)开始逐步加 Q,观察饱和与噪声。Bryson 规则:Qii=1/xmax²,Rii=1/umax²。

LQG:估计 + 最优反馈

LQG = Kalman 滤波 + LQR;分离原理保证 LTI 下可分开设计。注意环路传递恢复(LTR)与鲁棒性;观测器噪声模型不准会退化。

约束、饱和与线性化边界

LQR 不考虑输入/状态约束;饱和会让实际闭环偏离设计。可加抗饱和、参考管理或改用 MPC;超出线性化范围要切换模型。

参考实现(可复现)

# LQR(可用 scipy 或手算双积分解析)
import numpy as np
from scipy.linalg import solve_continuous_are
A=np.array([[0,1],[0,0]]); B=np.array([[0],[1]])
Q=np.eye(2); R=np.array([[1]])
P=solve_continuous_are(A,B,Q,R)
K=np.linalg.inv(R)@B.T@P
print("K=",K)  # 可对照 labs 预设
