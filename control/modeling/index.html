数学建模

从物理量到传递函数:一阶/二阶模型、时间常数与阻尼比。会建模,才能解释"为什么改了参数曲线会这样"。

1. 目标与成果

项内容
能力质量-弹簧-阻尼、电机速度的一阶/二阶模型
会做由微分方程经拉氏变换得到 G(s)
可检查结果从阶跃曲线量 τ、ζ、ωn,并与公式对照

2. 前置知识

需要会用在哪去哪补
微积分微分方程、拉氏变换无
反馈原理框图与闭环/control/feedback/
复变基础s 平面、极点无

3. 原理与公式

符号含义单位作用
m质量kg惯性
c阻尼N·s/m耗散
k刚度N/m回复力
τ时间常数s一阶快慢
ζ阻尼比无量纲超调
ωn自然频率rad/s振荡快慢
mx″ + cx′ + kx = F
→ G(s) = 1/(ms² + cs + k)
二阶标准形:G(s)=ωn²/(s²+2ζωn s+ωn²)
ωn=√(k/m),  ζ=c/(2√(km))

一阶:τy′+y=Ku → 阶跃 y(t)=K(1−e^(−t/τ))
t=τ 时到 63.2%;t=3τ 约 95%
  1. 把物理方程写成"输入—输出"形式。
  2. 零初始条件下做拉氏变换。
  3. 整理成 G(s)=输出/输入。
  4. 与标准形对比,读出 τ 或 ζ/ωn。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

详细讲解

直观理解:建模把物理世界翻译成输入到输出的数学关系;同一电机忽略电感是一阶,保留电感接近二阶。模型越细参数越多,验证成本越高。

推导要点:写微分方程→零初始拉氏变换→G(s)=输出/输入。一阶快慢由 τ,二阶形状由 ζ、快慢由 ωn。

适用范围:线性模型只在工作点附近;大信号、饱和、摩擦会偏离。保留 20% 裕量并用阶跃/扫频验证。

例题与误区

例题 1

例 1:m=1、k=4,ωn?

解答:ωn=√(k/m)=2 rad/s。

例题 2

例 2:c=4、m=1、k=4,ζ?

解答:ζ=c/(2√(km))=1,临界阻尼。

例题 3

例 3:τ=0.5s,2s 后阶跃到?

解答:4τ → 1−e⁻⁴≈98.2%。

  • 误区:τ 当成到稳态时间(3τ≈95%)。
  • 误区:忽略初始条件(传递函数要求零初始)。
  • 误区:二阶只看 ζ 不看 ωn。

进一步讲解

分步推导(补)

  1. 写牛顿/基尔霍夫方程。
  2. 零初始拉氏变换。
  3. 整理 G(s)=输出/输入。
  4. 与标准形对比读 τ/ζ/ωn。

数值算例(补)

m=1、c=2、k=4:ωn=2 rad/s,ζ=c/(2√(km))=0.5,欠阻尼;阶跃超调约 16%。若 c=4:ζ=1,无超调。若 c=0.8:ζ=0.2,超调约 52%。

应用与考法(补)

常见考法:由物理参数写 G(s);给阶跃图求 τ/ζ;判断"改进阻尼该动哪个参数"。注意单位与初始条件。

参考实现(可复现)

# 二阶阶跃:ζ 与超调
import math
wn=2.0
for zeta in (0.2,0.7,1.0):
    t=0; y=0; v=0; Ts=0.001; peak=0
    for k in range(5000):
        a = wn*wn*(1-y) - 2*zeta*wn*v
        v += a*Ts; y += v*Ts; peak=max(peak,y)
    print(zeta, "峰值", round(peak,3), "超调%", round((peak-1)*100,1))
