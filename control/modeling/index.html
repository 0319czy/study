CONTROL · 数学建模

数学建模

从物理量、单位、微分方程到传递函数:一阶/二阶模型、时间常数与阻尼比。

1. 目标与成果

项内容
能力能把质量-弹簧-阻尼或电机速度写成传递函数
可检查结果给出一阶/二阶阶跃响应参数与物理解释

2. 前置知识

需要会用在哪去哪补
微积分导数、微分方程无
反馈原理框图/control/feedback/

3. 原理

质量-弹簧-阻尼:m x″ + c x′ + k x = F,拉氏变换得 G(s)=1/(ms²+cs+k)。一阶系统 τ y′ + y = K u,阶跃响应 1−e^(−t/τ)。二阶标准形式 ωn²/(s²+2ζωn s+ωn²),ζ 决定超调。

变量与单位:m kg、c N·s/m、k N/m、F N;τ s、ζ 无量纲、ωn rad/s。假设线性、零初始条件。

4. 操作实验

  1. 对一阶对象做阶跃,量出 63% 时间作为 τ。
  2. 对二阶对象改阻尼比,记录超调与调节时间。
  3. 把物理参数代入公式,与曲线对照。

5. 结果检查

检查项预期
一阶 τ63% 时间与 RC/时间常数一致
二阶 ζζ<1 有超调,ζ≥1 无超调
单位参数与曲线量纲一致

6. 故障排查

现象检查步骤预期结果下一分支
曲线与公式不符初始条件/非线性小信号线性化重新建模
τ 估计偏差未到稳态延长记录重测
