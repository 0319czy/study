3. 原理与公式

符号含义单位作用
p极点rad/s 或 s⁻¹稳定性
ωc穿越频率rad/s0dB 点
PM相位裕度°离 −180° 多远
GM幅值裕度dB离 0dB 多远
K增益无量纲/单位影响裕度
闭环特征方程:1 + G(s)H(s) = 0
稳定 ⇔ 所有闭环极点 Re(p) < 0

Routh:特征方程系数表首列不变号
PM = 180° + ∠G(jωc),GM = −20log|G(jω180)|
工程经验:PM ≥ 45°、GM ≥ 6dB 较稳
  1. 写出开环 G(s)H(s) 与特征方程。
  2. 用 Routh 判断右半平面极点数。
  3. 画 Bode,读 ωc、ω180 与 PM/GM。
  4. 改变增益 K,观察极点/裕度移动方向。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

详细讲解

直观理解:稳定性是被推一下能否回平衡:极点实部负则衰减,正则放大,虚轴附近慢或等幅。频域裕度回答"离不稳多远"。

推导要点:Routh 用系数表判右半平面极点数;Bode 的 PM=180°+∠G(jωc),GM 是 −180° 处幅值余量。

工程:PM 45–60°、GM 6–12dB 兼顾速度与稳健;延迟、采样、未建模动态会吃裕度。

例题与误区

例题 1

例 1:s³+3s²+2s+K=0 稳定范围?

解答:Routh 首列 1,3,(6−K)/3,K → 0

例题 2

例 2:PM=30°、GM=3dB 风险?

解答:超调大、振荡,扰动/延迟下易失稳。

例题 3

例 3:延迟为何降稳定性?

解答:e^(−sTd) 只加相位滞后,等效降低 PM。

  • 误区:开环稳定就闭环稳定(看 1+GH)。
  • 误区:只看幅值(相位同样关键)。
  • 误区:条件稳定当绝对稳定。

进阶专题

根轨迹规则

起点开环极点、终点开环零点(或无穷远);实轴段右侧极点+零点数为奇数;渐近线角度 (2k+1)180°/(n−m);与虚轴交点用 Routh 或令 s=jω。根轨迹回答"K 增大时极点怎么走"。

Nyquist 判据

Z=N+P:P 为开环右半平面极点数,N 为包围 −1 的圈数,Z 为闭环右半平面极点数。稳定要求 Z=0。适合开环不稳定或含延迟系统。

裕度与超调的经验关系

PM≈60° 对应超调约 10%,PM≈45° 约 25%,PM≈30° 明显振荡。GM≥6dB 常作稳健下限;延迟会按 ωTd 吃掉 PM。

条件稳定与增益安全区

有些系统只在某段增益稳定(条件稳定);增益过小或过大都可能失稳。设计时要给出安全增益范围与延迟/参数漂移裕度。

延迟的相位代价

延迟 Td 在频率 ω 处带来 −ωTd 弧度相位。例:Td=0.05s、ω=20rad/s → 1 rad≈57°,足以把 PM 从 60° 降到临界。

4. 操作实验

项内容看什么
对象G(s)=K/(s(s+1)(s+2))K=1/5/20
Bode读 PM/GMK 大裕度小
时域阶跃响应振荡与裕度对应
仿真labs 改 Kp 观察振荡与频域结论一致
  1. 对 G(s)=K/(s(s+1)(s+2)) 写特征方程,Routh 求稳定 K 范围。
  2. 画 K=1 的 Bode,读 PM/GM。
  3. 把 K 调到临界附近,观察时域振荡。
  4. 记录"不稳定/裕度不足"的预设条件与现象。

参考实现(可复现)

# Routh 判据(手算对照)
# 特征方程 s^3 + 3s^2 + 2s + K = 0
# 首列:1,3,(2*3-K)/3,K;K<6 且 K>0 时稳定
for K in (1,5,6,7):
    ok = K>0 and K<6
    print("K=",K,"稳定" if ok else "不稳定")
