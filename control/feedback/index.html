反馈原理

开环与闭环的区别不是"有没有控制器",而是"输出有没有被测量并参与决策"。本课用同一对象对比开环与闭环,定义上升时间、超调、调节时间与稳态误差。

1. 目标与成果

项内容
能力开环/闭环/负反馈的框图与信号(参考、误差、控制量、扰动、测量)
会做用阶跃响应量出上升时间、超调、调节时间、稳态误差
可检查结果同一对象加负载:开环偏差 vs 闭环抑制,能解释差别

2. 前置知识

需要会用在哪去哪补
代数框图合并、比例关系无
微积分导数、一阶响应/control/modeling/
基础物理质量-弹簧-阻尼无

3. 原理与公式

符号含义单位作用
r参考输入随对象(如 rad/s)期望值
y输出同 r被控量
e = r − y误差同 r反馈核心
u控制量执行器单位驱动对象
d扰动输入侧单位负载等
闭环框图(单位负反馈):
y = G(s)u,  u = C(s)(r − y)
→ y/r = G C / (1 + G C)
→ y/d = G / (1 + G C)   (扰动抑制)

阶跃指标:
上升时间 tr: 10% → 90% 稳态值
超调 Mp = (ymax − yss)/yss × 100%
调节时间 ts: 进入 ±2%(或 ±5%)并保持
  1. 写出开环传递函数 G(s) 与控制器 C(s)。
  2. 令扰动 d=0,求参考到输出的闭环传递函数。
  3. 令参考 r=0,求扰动到输出的传递函数。
  4. 比较 1+GC 在低频的增益:越大,扰动抑制越强,但可能牺牲稳定性。

假设与边界:线性时不变、传感器噪声可忽略或已建模;超出范围需回到建模或非线性方法。

详细讲解

直观理解:控制器不是"输入一个固定电压",而是持续观察输出与目标的偏差并修正。开环像"按菜谱放盐",闭环像"尝一口再补盐";闭环能在对象变化/扰动下维持目标,但测量噪声与延迟会被放大成振荡。

推导要点:y=G u、u=C(r−y) → y=GC/(1+GC)r;扰动抑制 y=G/(1+GC)d。低频 |GC|≫1 时跟踪好、扰动被压;穿越频率附近相位决定稳定性。

指标:tr 快不快;Mp 冲不冲;ts 多久稳;ess 准不准。四者互相牵制,不能全靠增益。

例题与误区

例题 1

例 1:一阶 K=1、τ=0.5s、Kp=4,闭环 τ 与 ess?

解答:τc=τ/(1+KpK)=0.1s;ess=1/(1+4)=20%。

例题 2

例 2:开环加负载为何一直偏低?

解答:无测量,负载改变对象特性,偏差不被修正。

例题 3

例 3:PM=30° 会怎样?

解答:超调大、振荡明显;一般希望 ≥45°。

  • 误区:有控制器就是闭环(没有测量仍是开环)。
  • 误区:闭环能消除所有扰动(噪声/饱和/延迟限制上限)。
  • 误区:只看超调百分比不看时间尺度。

进一步讲解

分步推导(补)

  1. 设对象 y=G(s)u,控制器 u=C(s)(r−y)。
  2. 消去 u:y=GCr/(1+GC)。
  3. 令 r=0:y=Gd/(1+GC),说明扰动抑制。
  4. 低频 |GC|≫1 时 y≈r;中高频相位决定稳定性。

数值算例(补)

取 G=1/(0.5s+1)、C=4:闭环 Gc=4/(0.5s+5)=0.8/(0.1s+1),τc=0.1s;阶跃 ess=1/(1+4)=20%;若加 I,ess→0 但可能超调。

应用与考法(补)

常见考法:给框图求闭环传递函数;给阶跃曲线读 tr/Mp/ts;判断"加负载后是否回零"。工程上先看测量与反馈通路是否闭合,再看带宽与裕度。

进阶专题

反馈的四种连接

串联:G1·G2;并联:G1+G2;反馈:前向 G、反馈 H,闭环 G/(1+GH);前馈:把参考或扰动直接加到控制量。考试常给框图要求化简,先找反馈环,再由内向外。

灵敏度与鲁棒性

灵敏度 S=1/(1+GC),补灵敏度 T=GC/(1+GC),S+T=1。S 小表示对对象变化不敏感,但 T 接近 1 时参考跟踪好。设计是在 S 与 T 之间折中;低频希望 S 小(抑制扰动),高频希望 T 小(抑制噪声)。

稳态误差与系统类型

类型行为备注
0 型阶跃有差,1/s 输入发散ess=1/(1+Kp)
1 型阶跃无差,斜坡有差ess=1/Kv
2 型阶跃/斜坡无差,抛物线有差ess=1/Ka

二阶指标与阻尼比

超调 Mp=e^(−πζ/√(1−ζ²)):ζ=0.2→52%,0.5→16%,0.7→4.6%,1→0。调节时间 ts≈4/(ζωn)(±2%)。知道 Mp 反推 ζ,再由 ts 定 ωn。

带宽与响应速度

闭环带宽越大,响应越快、对扰动抑制越好,但噪声/延迟敏感性上升。工程上带宽通常取穿越频率附近,并保证 PM≥45°。

  3. 改变 Kp=1/4/10,记录 tr、Mp、ess,填入下表。

参考实现(可复现)

# 一阶闭环阶跃:对比 Kp
import numpy as np
Ts=0.01; tau=0.5; K=1.0
y=0.0
for Kp in (1,4,10):
    y=0.0; ys=[]
    for k in range(300):
        u=Kp*(1-y)
        y += ((u*K)-y)/tau*Ts   # 一阶对象放这里
        ys.append(y)
    print(Kp, "稳态", round(ys[-1],3), "超调", round(max(ys),3))

公式速查

#知识点要点/公式
1开环与闭环y=GC/(1+GC) r — 开环无测量,闭环用误差修正;闭环抗扰但引入稳定性与噪声问题。
2负反馈的代价S=1/(1+GC) — 负反馈降低灵敏度,但会放大测量噪声、要求更大控制量。
3框图化简G1G2/(1+G1G2H) — 先内环后外环;串联相乘、并联相加。
4系统类型ess=lim s→0 sE(s) — 0/1/2 型由开环积分环节数决定稳态误差。
5一阶响应y=K(1−e^(−t/τ)) — τ 决定快慢,3τ≈95%。
6二阶指标Mp=e^(−πζ/√(1−ζ²)) — ζ 决定超调,ωn 决定快慢。
7上升时间估算tr≈2.2τ — 一阶 tr≈2.2τ;二阶随 ζ 增大先减后增。
8调节时间ts≈4/(ζωn) — ±2% 约 4/(ζωn)。
9带宽|Gc(jω)|=1/√2 — 闭环 −3dB 频率,越大越快、越易受噪声影响。
10扰动抑制y/d=G/(1+GC) — 低频 |GC| 大则扰动被压。
11测量噪声T=GC/(1+GC) — 高频 T 接近 1 会放大噪声;需低通/降带宽。
12延迟影响∠e^(−jωTd)=−ωTd — 延迟在穿越频率处产生相位滞后,降低 PM。
13前馈u=Gff r — 按参考/扰动模型直接补偿,减轻反馈压力。
14串级外环输出=内环参考 — 外环慢、内环快,内环抑制扰动。
15饱和与积分风抗饱和:冻结/回算 — 执行器饱和时积分继续累积,退出时超调。
16灵敏度函数S+T=1 — S 与 T 互补,设计在两者间折中。
17相位裕度经验PM=180°+∠G(jωc) — PM≥45° 较稳;PM 30° 明显振荡。
18增益裕度GM=−20log|G(jω180)| — GM≥6dB 常作稳健下限。
19参考跟踪Gc(0)=1 — 闭环直流增益应为 1(或加积分)。
20抗扰与跟踪分离e=r−y — 反馈同时做两件事,但设计目标不同。
21工具与验证— — 用阶跃/扫频验证;记录参数与现象。
22常见误区— — 只看超调不看时间尺度;忽略测量噪声。
