LEARNING PATH

学习路线:从工程基础到设备交付

目标不是"看完课程",而是能独立完成一条设备系统:需求分析 → 电路与接口 → MCU 固件 → RTOS → Linux 应用与驱动 → 通信联网 → 数据展示 → 调试与交付。七个阶段按依赖排序,每阶段都有必须产出的成果。

七个阶段 (标注"待建"的课程在第一批建设)

01

工程基础 已上线

C 语言与指针、位操作、Git、编译链接、基本电路、仪器使用。这是后面所有阶段的底座。
成果:能编译、调试并解释一个小工程
C 与工程工具 数字电路基础 基础课总览
02

MCU 与外设 已有

STM32 HAL、GPIO、定时器、ADC、DMA、UART / I2C / SPI / CAN 等通信协议与电气特性。
成果:独立完成传感器采集与通信
MCU Playground 学习路径 GPIO UART
03

RTOS 已有

任务、队列、同步、中断协作、内存、看门狗——把单线程采集做成稳定运行的多任务设备。
成果:完成稳定运行的多任务设备
RTOS Lab 学习路径
04

嵌入式 Linux 部分上线

Shell、交叉编译、进程与线程、文件与网络、启动流程。先学用户态应用,再进内核。
成果:完成设备端应用与系统镜像
Linux 用户态入门 交叉编译与系统镜像 · 待建
05

驱动与硬件协同 已有

设备树、字符设备、总线驱动、并发与调试——把用户态应用和硬件连成一条数据通路。
成果:完成应用到硬件的数据通路
驱动实验室 学习路径 动画实验室
06

联网与交付 待建

协议设计、网关、API、数据存储、可视化、升级与恢复——交付一套可部署、可维护的设备系统。
成果:完成一套可部署、可维护的设备系统
M0 采集 M1 通信 M2 多任务 M3 网关 M4–M5 · 待建
07

方向进阶 部分已有

ROS 2、控制、电路与 PCB、边缘 AI——按项目需要选择方向,完成方向项目与作品说明。
成果:完成方向项目与作品说明
ROS 学习实验室 知机 · 机器学习 PCB 与边缘 AI · 第四批

第一条完整路线:多传感器采集与监控系统

传感器 → STM32 HAL → FreeRTOS → 串口通信 → Linux 网关 → 数据存储 → 网页仪表盘。 分阶段增加能力,每一步都有可检查的结果(M0–M5)。
